# 结构补边：单独降低防泛亮权重

## 目的与实验边界

在完整完成的`boundary_structure`五轮实验上，只将`mass_weight`由0.05降至0.005。
该系数控制自由走廊里新增响应的惩罚，用于防止整片泛亮；上轮冻结e5梯度检查发现，
它在所查八批中压过并反向抵消了补线路径项。
本轮检验降低这一项能否恢复有效补线，而不把原强线误改、双线或内部碎块显著放大。

0.005的依据是已存梯度校准：当前0.05的八批均与补线方向相反，
改为0.005后八批均同向，最差方向余弦0.9424。
这是冻结位置的一阶诊断，不是新模型效果，不能提前宣布扫参获胜。
上轮完整结果及局限见[结构监督分析](BOUNDARY_STRUCTURE_20261025.md#五轮完成后的分析)。

### 训练修复了哪一层，仍卡在哪一层

原0.05下的路径项与防泛亮项在八批中合计反向；0.005训练后的e5八批都恢复同向。
这验证了此前局部梯度诊断指出的内部竞争，不能据此推出天然补边必然改善。

旧0.05 e5对应响应变化+0.004995、路径缺额95.805。
早期的小幅天然弱界收益没有保持到正式e5；不据测试图选择早期epoch替代正式对照。
固定两份完整identity monitor的4,473路径位置，原N0弱点73，
两组e5均为76；它同样不支持天然漏界稳定改善。

新的e5原样N0输入四批中，旧自损伤base与补线路径梯度方向余弦为-0.699至-0.531；
base范数3.646–4.152，路径项仅0.0191–0.0486，总梯度仍几乎沿base且与path反向。
原弱走廊确实已释放直接自复制损失，不能说漏做了释放；这里是共享参数还要服务大量其它
保持任务而发生的梯度竞争。该冻结快照支持继续检查弱界监督的独立归一／相对贡献，
不是对全部Adam训练步骤的因果重放。317条诊断路径仍全部为开放局部链，
不能以链上损失下降代替两端接续和最终实例分隔。
因此，不建议继续降低mass或仅延长当前配方；内部竞争存在，但修好这一项尚不足解决主目标。
