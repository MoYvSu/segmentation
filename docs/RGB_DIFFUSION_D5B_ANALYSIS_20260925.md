# D5b完成分析：短链减轻退化，尚未实现逐步改善

2026-09-25。D5b完整完成从零、全1000源图、60轮／15000次更新，零失败。
结论：自身状态短链监督改善第2、3次预测相对D5a的误差，但两者仍均以首步最好；
D5b首步未改善，不单独生成黑盒包，不替换D5a或旧v4。
随后执行固定最终实例划分、交换语义来源的定位实验，采用已有官方回分的D5a作为修复端。

## 新FP32配对诊断

复用D5a分析协议：32张等间隔训练源图，1024等比letterbox后中心512裁块；
每张在线生成均匀sigma3、旧空间场、强弱端点共存场。退化随机种子
`SeedSequence([240924, source_index, 17])`，采样种子`314159 + source_index`。
两模型严格同输入、同噪声、同FP32，e60权重。图像源已参与训练，以下是重建诊断而非独立泛化验证。

首步误差相对D5a（负值才表示改善）：

| 合成退化／区域 | RGB L1 | 梯度L1 | MSE |
|---|---:|---:|---:|
| 均匀模糊／全图 | +0.269% | +0.125% | +0.817% |
| 旧空间模糊／全图 | +0.135% | +0.082% | +0.465% |
| 端点共存／全图 | +0.175% | +0.090% | +0.522% |
| 端点共存／弱区sigma≤1.5 | +0.041% | +0.010% | −0.265% |
| 端点共存／强区sigma≥4 | +0.347% | +0.166% | +0.851% |

端点全图首步绝对RGB／梯度误差：D5a `0.01929569 / 0.02276155`；

## 真实图观察与判断

四张既有固定真实图使用原100图排序采样种子、相同缩放与左右ROI，展示D5a/D5b首步及D5b完整选定步数。
首步外观相近，没有看到足以支持“新增有效补边”的明确证据；后续步骤仍改变纹理和边缘。
真实图没有清晰GT，像素变化或目检锐利程度都不能证明边界正确。

因此可保留短链监督作为减少自身误差累积的实验记录，但当前权重不晋级，
不把第3步“比D5a第3步更好”误作“比首步更好”。无需为微小首步变化占用黑盒提交。
下一步优先完成后端类别来源定位；如果后续继续多步重建，应另立实验检验后续状态能否
修正剩余误差，不能只加训练轮数或凭多步名称预期更好。
