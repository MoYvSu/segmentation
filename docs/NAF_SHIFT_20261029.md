# 单通道NAF的平移一致性

2026-10-29。用户授权无RGB试验。以已完成T8＋显式擦断的afc1bbaa组为唯一训练控制，
不重训控制，不继承已训练NAF或RGB组权重。
这里要求“输入移动，预测边界相应移动”，再将输出逆向移回比较，通常称为平移等变。

新增标量为`0.1 × [0.5 mean_band(abs(p-p_shift_back)) + 0.5 mean_interior(abs(p-p_shift_back))]`。
空组记0，不放大另一组；微批使用完整有效batch的各组分母，背景数量不稀释边界带。
GT不因位移补标签，也不额外对移位分支增加一份有标签监督。

## 对称梯度与显存

两侧预测都接收正则梯度。先算原前向及无梯度的移位参考，在原监督/GAN/正则原分支反传后，
重算移位分支，对固定原预测反传另一侧梯度，最后合并clip并只更新一次G。
两个方向各使用完整0.1系数，损失日志只计一次实际标量，不把同一项重复计价或额外减半。

NAF没有BN、dropout或谱归一化G状态，顺序重算与完整双图反传在CPU测试中等价；
代码显式拒绝这些有状态G，且每步核对移位参考与重算输出最大误差不超过1e-6。
这样保留原micro16，不靠缩小batch混入另一项实验变化。

### 下一组建议：只替换上采样，不叠新约束

当前代码四级上采样为`Conv1x1(C→2C) + PixelShuffle(2)`，与
[NAFNet官方实现](https://github.com/megvii-research/NAFNet/blob/main/basicsr/models/archs/NAFNet_arch.py)一致。
[PixelShuffle](https://docs.pytorch.org/docs/2.8/generated/torch.nn.PixelShuffle.html)本身重排通道到空间，
前置卷积给四个子像素位置独立的权重；本任务的实例读出会放大这种高低交替。

建议以旧单通道擦断组为控制，单独替换四级上采样为：

```text
低分辨率1×1通道投影 C→C/2
→ 双线性插值放大2倍（align_corners=False）
→ 原skip相加与原NAF decoder
```

先投影再放大减少计算，原decoder已有3×3深度卷积，不同时加额外大卷积。
按当前四级C=768/384/192/96实际核算，G参数17,632,273→16,457,233；
四个up卷积的MAC/256裁块约1.208G→0.302G，此数不含插值及其余网络，不能直接当完整耗时。
对照只换上采样，先不叠本轮平移loss，不改原目标、T8、擦断、数据计划、后端和读出。
公共骨干用同一随机张量，新up块独立随机初始化；新块形状改变，不能宣称全G同初态，
不能用宽松权重加载掩盖不匹配，也不直接替换已有权重中的层进行正式部署。

[双线性插值](https://docs.pytorch.org/docs/2.8/generated/torch.nn.functional.interpolate.html)可以减少独立相位自由度，
也可能平滑薄弱边，四级stride2仍在，不能保证完全平移等变。
只需重训NAF，不重训SAM2/LoRA或分割头；仍须用自然断口、人工实际分隔和最终小实例共同验收。
