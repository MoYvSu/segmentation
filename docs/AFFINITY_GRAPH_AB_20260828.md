# E10a 单语义 + 方向 affinity 图切分 A/B

## 目的

固定 E10a 为唯一语义来源、固定 G4b checkpoint，仅替换实例几何解码，判断 8 通道
same-instance affinity 是否应直接用于图连通切分，而不是先压成一张 boundary 再分水岭。
本实验完全 GT-free。先在 10 张预先选定的困难测试图上筛查，再对晋级的 `short=0.40`
完成 68 张测试图全量推理；测试集只用于盲目检和生成待提交候选，不参与训练或 checkpoint 选择。

## 阈值含义

图阈值作用于 `P(same instance)`，与融合边界阈值方向相反。当前 boundary `0.65` 大致对应
affinity 连接阈值 `1 - 0.65 = 0.35`，因此扫描短程通道 `0.30/0.35/0.40`；距离 2/4 通道
分别固定为更严格的 `0.55/0.65`，降低长边跨越细小断口造成合并的风险。

初版把每个低 affinity 晶界像素也当作独立图节点，`test_003` 在 428×512 网格产生
32,193 个原始分量，逐片合并既慢又无物理意义。修正版只保留达到面积要求的 affinity
核心，其余晶界带按最近核心做确定性 Voronoi 回填，保证每个像素唯一归属且实例 ID ≤255。

## 结果

| 几何臂 | 10 图实例总数 | 相对 E10a watershed | 结论 |
|---|---:|---:|---|
| E10a + G4b watershed | 1350 | 基线 | 保留 |
| graph short 0.30 | 1603 | +18.7% | 召回过激，碎裂与大块合并并存 |
| graph short 0.40 | 1482 | +9.8% | 目检优于初步判断，晋级全量验证 |

所有图切分臂均满足像素唯一归属，`unassigned_pixels=0`。复核实例图与原图后，`0.30` 的
主要问题不只是实例数偏多：部分粗暗晶界自身沿线保持连通并达到核心面积门槛，随后被 E10a
投票成珠光体，形成全图可见的蓝色细横带伪实例。提高到 `0.40` 后，这些沿边连接更容易断成
不足面积的小分量并被回填给邻近真实核心，同时弱真实晶界上的连接也被切断，因此既减少伪边界
实例，又能缓解一部分欠分割。`0.35` 单图臂因明显过碎提前淘汰。

### 68 图全量 `short=0.40`

| 项目 | E10a watershed | graph 0.40 | 差异 |
|---|---:|---:|---:|
| 图像数 | 68 | 68 | 0 |
| 实例总数 | 6178 | 7559 | +1381（+22.35%） |
| 每图平均实例增量 | - | - | +20.31 |
| 每图实例增量中位数 | - | - | +13 |
| 实例数下降图像 | - | 2 | `test_049=-3`、`test_061=-1` |
| 达到 255 上限 | 0 | 2 | graph: `test_010`、`test_055` |
| 未分配像素 | - | 0 | 满足唯一归属 |

目检表明，0.40 的新增切缝多数落在原图晶界上，在弱而密集晶界处通常比分水岭基线更贴合，
因此不能再归类为“明显劣于分水岭”。但全量实例数增幅高于 10 图子集，且 `test_010` 触发了
255 合并上限；在没有 GT 的测试集上不能仅凭实例数证明提升，最终仍需官方黑盒的 mIoU 与
铁素体平均面积项共同裁决。G4b watershed 在此之前保留为稳定回退。

10 图报告位于服务器 `outputs/experiments/e10a_graph_ab_v2/graph_ab_summary.json`。68 图报告、
实例结果和对比图位于 `outputs/experiments/e10a_graph_040_full/`；本地下载位于忽略跟踪的
`downloads/e10a_graph_040_full/`。可提交包为 `e10a_graph040_full.zip`。

## 下一步约束

固定 E10a 为唯一语义来源，优先提交 graph 0.40，以官方黑盒结果决定是否取代 G4b watershed：

1. 不再继续扫描 0.30 一侧，避免重新引入粗暗晶界珠光体细带；
2. 严守每图实例 ID `<=255`，但不强制固定实例数或平均面积；
3. 若 0.40 黑盒 mIoU 或面积项明显下降，再退回 watershed 并研究只在泄漏处使用 affinity 的
   局部补缝，而不是凭无 GT 目检提前否决整图图切分；
4. 若 0.40 晋级，再把 E10a semantic decoder 与 G4b affinity decoder 的统一 checkpoint 接入
   单入口图切分推理，消除多 checkpoint 搭管线的复现负担。
