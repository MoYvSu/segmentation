# NAF单轮与递归恢复的小样本对照

## 结论

保留旧最高20a59＋S0的**单轮部署**。当前直接递归不支持推广：旧最高第二轮有局部补边收益，第三轮明显碎化；NoGAN较平稳，但额外轮次同样增加贴边小区，尚未取得能抵消这些变化的可靠收益。

本轮仅进行两恢复器、五例、各1／2／3轮的缓存推理与机制分析，未训练、未重算上游、未运行150图或制作黑盒包。没有新官方成绩，也不计算本地竞赛代理分。

## 补边与小环

116预登记的两个内点，旧组第一轮同实例、第二轮起分开；左缺口点响应约.068→.672→.972。局部图支持第二轮确有划分变化，但无测试GT，不能只凭异ID认定整条边都正确。

NoGAN在该处第一轮已分开。其第二／第三轮没有新增这项分隔收益，左缺口响应.607→.644→.266，而上方开口.024→.128→.938，分隔路径也发生变化。不能把第三轮更强的上方响应单独当成改善。

旧组第三轮在轮廓图形成大量沿原线附着的小区；NoGAN较缓，但同样累积小环和局部额外分隔。旧组第二轮新增<200px小F中，113个区域到原分隔线的像素距离中位数≤4px、67个在4–12px、11个>12px；第三轮分别566／1352／212。NoGAN第三轮分别65／113／10，说明主要风险集中在原边界邻域。

原始热图与最终实例必须分开：旧组以.65二值化的<200px封闭孔洞合计1→0→0，但最终小F暴增；NoGAN原始小孔则698→3378→6902。不能统一解释为网络直接画出了全部完整小环；模型输出与固定的弱边重建、连接、细化、种子生成及分水岭共同影响终态。

进一步对169第三轮做了只读阶段追踪，不运行新模型或分水岭：旧组原高阈值／弱边重建后的背景8连通闭孔均为0，经bridge1变为4089；reflect细化后1750，再扩宽1像素后3055。50–199px微腔在细化后为176，扩宽后增至1374；最终S0保留1973种子，与保存的marker像素／ID和最终实例数完全一致。NoGAN同图的50–199px微腔也从细化后的1增至扩宽后的191。

这定位了**该例中模型微结构被读出封成小腔**的过程。旧组高阈值图仍有71146个背景4连通微孔，暗区沿对角相通；不能因8连通闭孔为0便称输出干净。该追踪仅覆盖两模型169第三轮，不足以认定单轮全150图具有同一主因。

## S0、细通路与小晶粒

新增小F实际保留种子均有原N1低边界响应支撑；二轮支撑比例中位数约25%，三轮约51%／52%。S0检查种子是否落在原N1的低响应处，无法检验围住它的新边是否正确。内部误切形成的小岛同样可能获得充分支撑，不能把它们都当作仅靠一个偶然像素过筛。

细F骨架只统计基线预测窄区域在候选中仍为F、变P或变0，不能称为真实通路断裂率。共同坐标局部图中没有看到稳定的额外细通路收益，部分区域增加附着小块。

原有小F并非全部保留：旧组第一轮28个<500px小F中，第二轮有5个参与合并，另1个高覆盖对应区域翻类；NoGAN第一轮34个中，第二轮4个参与合并，第三轮5个参与合并、另2个高覆盖翻类。这些都是原预测小F，不是已证实的真实小晶粒。

另保留三轮纯T8、不经过网络的空循环。它本身不幂等，会移动或改变部分像素，但三张测试图的封闭孔洞略减，未出现模型递归的碎区膨胀。它不足以单独解释本轮现象。
