工程与真实GPU预检已通过，正式1000更新进程已启动；首步推进以文末实际回执为准。

## 目的与唯一主要变化

原20a59控制只读T8：原N1边界概率经0.5阈值、整图骨架化和8号椭圆核扩宽。
候选同时读取同一张未二值化的float32 N1边界概率。两路原生坐标相同，
整图生成一次T8之后才同步crop、D4和reflect，不再次模糊或调整亮度。
这用于检验二值化丢掉的强弱信息是否有用，不能将响应大小直接称为正确概率。

| 项目 | 旧控制与候选的关系 |
| --- | --- |
| 公共G/D | 共同随机初态；候选不继承训练后20a59或任何GPU短测权重 |
| 新分支 | 原单通道intro不动；新增无bias、零初始化3×3卷积读取连续B，特征相加 |
| 参数 | 旧G 17,632,273；新增432；候选G 17,632,705 |
| skip | 全局logit跳连仍只使用T8 |
| 数据 | 原32份处理后新GT与同源封存N1；16000 source/crop/D4计划不变 |
| 优化器与预算 | 1000更新、有效/微批16、原FP32、G LR .001、D LR .0001、53000步日程 |
| 损失 | 原法向±2容差覆盖与可信内部抑制各1；GAN .01，前64步关闭 |
| 固定项 | 旧D5a/N1、encoder/LoRA/affinity、语义、S0、读出及final200不在本轮改变 |
| 控制复用 | 原20a59官方/缓存结果直接复用，不重复训练控制 |

连续B有可能保留弱证据，也可能保留噪声。本轮不预设补边或抑制小环一定改善。
最终阶段须按原C读出比较，官方评分前不晋级部署。

## 输入与checkpoint合同

- `models/boundary_dual.py`：`BoundaryDualNAFNet`，新模型版本`boundary_dual_naf_v1`。
- `data/boundary_dual.py`：`BoundaryDualDataset`，输入顺序`[binary_T8, continuous_N1_boundary]`。
- `config/train/naf_dual.yaml`：显式`input_mode=boundary_continuous`、`input_contract=t8_continuous_v1`。
- `tools/train_naf_dual.py`：训练checkpoint版本`naf_dual_training_v1`，局部替换旧训练入口接口，
  复用原优化器、loss和严格续训循环，不改写旧训练器或旧权重。
- `tools/boundary_dual_monitor.py`：有界单图双输入分窗，保持原概率拼接顺序；不是生产S0加载器。

旧`raw_input_boundary`实际上是二值T，不能当连续输入。新数据从原NPZ浮点字段读取B，
先核数组头、总字节预算与源SHA，再逐源加载，并要求其0.5阈值结果与原T一致。
旧GAN更新器仅在显式`boundary_input_channel=0`时允许双输入；旧默认1/4通道保持。
missing/support仍按T8计算，不能误以第二路连续B重定义诊断分母。

新旧格式严格隔离。生产`infer_boundary_rgb.py`的旧输入断言和S0模型白名单没有放宽；
后继正式出包需为新模型明确接入并做完整输出核验。
