# 固定尺度融合小诊断（2026-10-01）

本轮不训练、不扫描融合比例、不生成100图提交。比较原全图 control、原 p1024 e20 原生1024，以及它们的连续边界概率各50%平均。所有概率拼回原坐标后统一进行一次实例划分，D5a全图几何语义、原图最终类别投票、阈值、后处理均固定。

**此诊断没有使用刚取得新最高官方分数（0.8639，0.8730）的 native balance e20。不能据此推荐替换新最佳。**

样本固定为既有四张训练源，以及test101/test116和从非monitor集合预先随机选出的六张测试图。随机种子20261001。测试图仅用于无标签目检和输出变化统计，没有构造测试GT。

12图的0%/100%融合端点，对既有全图和局部完整输出逐像素及类别JSON严格复现。运行后共享模型、局部头、D5a的全部状态摘要不变；最终PNG为原尺寸单通道uint16，ID上限及类别对应检查通过。CPU融合与错误输入/异常恢复检查6项通过。GPU诊断实际完成，进程exit 0。

## 结论与产物

固定融合具备可复现、合规的实现与部分几何互补信号，但没有足够证据优于两端，更没有与新最佳balance比较。截止期内优先围绕新最高方案进一步辨别真假边界，不因本次小诊断额外消耗黑盒机会。
