# 上下文分隔判别：原标监督与RGB增量对照

日期：2026-10-30。用户授权直接落地，承接[P060收尾](MARKER_HIGH_20261030.md)。
本轮是有监督路线的新关系分类任务，使用既有32张处理后GT；不涉及纯无监督加分方案。

## 目标与范围

固定主线N1、旧20a59 NAF、几何语义与原C后处理，判断两个已分开且相邻的预测区域应保留分隔还是合并。
首轮仅输出关系评分，不自动改实例、不重建整张热图，不跑150图或出黑盒包。
它主要检验误切过滤和真界保护，不能给没有第二候选种子的大粘连区域凭空增加分隔。

候选取C的**最终200过滤后几何**，不是大量仍会被原200规则自动并掉的pre200小区。
相邻关系只取原生四邻接正ID，或正ID之间恰有一像素WS零缝；多路交会不作为裁块锚点。
几何所需global semantic必须沿用固定C源；末端raw语义票不改变实例ID，不作为本轮监督或输入。
如果补捕获只生成几何数据，不能冒充完整原raw类别已复现；以既有两参考的最终ID精确桥接验证。

## 可信监督合同

原标、filled、residual_unknown分开。使用`build_trusted_cores(radius=4,min_component_pixels=64)`
生成两侧归属参考；未知和填补都不作为GT核。merge所用原标连通组件另从未侵蚀的
`original_covered & same_GT_ID`计算，不与侵蚀后的核组件混用。

| 项目 | 冻结定义 |
| --- | --- |
| 每侧支持域 | 预测区域内缩2px、距全共享缝≤24px、原图有效域的交集 |
| 支持数 | 每侧至少32个可信GT核像素 |
| 覆盖率 | 可信核支持／上述完整侧域≥.8；不先去掉unknown／filled |
| 主ID纯度 | 主GT的核支持／该侧全部可信核支持≥.95 |
| 保留分隔 | 两侧符合条件且主GT ID不同；界面中心可以filled，不据此删除真界 |
| 合并参考 | 两侧主GT相同，且该pair全部实际A端点—零缝—B端点接触像素均为同GT、original、同未侵蚀原标组件 |
| 走廊 | 全共享缝膨胀2px的完整走廊内，该原标组件占比≥.95；分母包含未知、填补和其他GT |
| 其他 | Ignore并记录主要拒绝原因；不按面积、小或浅直接赋merge |

走廊外围最多5%的容差不放行穿过实际接触的未知细线；任一接触不可靠，不能只凭当前256裁窗给整pair打merge。
“合并”是对已有人工原标的保守参考，不是物理假边的认证；原GT仍可能漏标。

## 两组与模型

| 组别 | 输入差异 | 其他条件 |
| --- | --- | --- |
| maps控制 | RGB三通道置归一化后的0，仅使用原N1／NAF及区域池化 | 与RGB组同结构、同完整随机初态、同样本顺序和D4增强 |
| rgb候选 | 加入真实原图RGB | 只改变RGB信息可用性 |

新模型211865参数，三层24／48／96通道下采样，GroupNorm＋SiLU，无上采样、GAN或旧修复权重。
编码器输入RGB、N1、NAF五通道；另有预测A／B／共享缝／原图有效范围四mask。
GT覆盖或可信核mask绝不作为feature。区域池化后用两侧和、绝对差、共享缝与区域并集特征分类，
交换A／B输出完全相同；不靠随机交换近似对称。

原生256方块不缩放；图框处RGB与概率reflect padding，区域mask与有效范围零padding。
所有训练可用标签参加，不新划人工留出。固定monitor中的训练样本仍属于已见数据，不能当独立验证。
测试monitor没有GT，label=255仅预测，不参与loss或准确率。

各先五轮，AdamW、有效batch64、LR3e-4按五轮cosine降至3e-5、weight decay1e-4、FP32。
类平衡BCE的`pos_weight=Nmerge/Nkeep`；sigmoid仅是这个训练设定下的keep评分，未经概率校准。
这里的keep=1／merge=0是关系标签，和材料语义的铁素体=1／珠光体=0是不同任务，不能混用。
保存共同随机初态、完整optimizer／LR步数／RNG／数据与配方身份；monitor覆盖e0至e5，保存时隔离RNG与模式。
候选patch一次读入RAM，cap16GiB，不从慢fs逐batch读，也不复制大图到剩余约3.27GiB的快盘。
