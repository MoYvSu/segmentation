# affinity距离任务与门控融合定位

## 实验范围

用户于2026-10-02授权落实P100分析提出的两项定位：长距离连接是否为最终边界提供有益信息，
以及不同距离任务是否在共享参数上相互牵制。先完成只读诊断，再依证据选择一个训练方向；
不预设Cshort有益、不改最高分部署，不直接密扫新参数。

当前官方最佳为用户回报mixed balance e20／原生1024的0.8629／0.8774（87.015）。
control bundle `outputs/affinity_balance/mixed/final.pt`，SHA
`43da103c95c7f85149bd0533fd116d26f0a81c91d793db7e8938b7d4ae80e434`。
共同初态由原Stage1／joint-v3链重建，不能把随机新头或control末态当作原初态。

## 固定合同与输入

- 不训练，不调用优化器或累积`.grad`，D5a、encoder／LoRA、语义、阈值和实例后处理固定。
- 原32人工与64确认SAM2登记必须匹配已评分control；不给测试图制作标签。
- fusion检查全部32人工源及预先随机固定的8个SAM2源，各自whole／native1024、clean／blur，
  共160输入；沿用原读图、裁块、在线退化与几何增强，两profile的裁窗和监督位置精确一致。
- 梯度检查人工预选8源与上述8个SAM2源，四输入条件，在共同初态和control e20各求一次，
  共128头前向诊断。D5a和encoder只计算一次共享冻结特征，两个头复用。
- 随机选择种子20261002；人工梯度索引6／9／15／16／20／23／28／29，SAM2索引
  6／8／13／20／49／56／59／62，均在运行前声明，不按效果挑样本。
- fusion精度口径只使用人工`original_covered & ids>0`，未知、padding和covered–uncovered忽略。
  SAM2只是确认过的无类别几何候选；不能把候选一致性当人工真值精度。
- 梯度目标使用现有completed canonical训练目标，保留来源的原空间权重／归一化；
  它与fusion可信域单独存放并同步几何变换，不能混用。

## 两项检查

### 同一可信短程目标下的融合贡献

同一control logits固定比较short(top2)、原gated、仅距离2辅助、仅距离4辅助。
统一标量真边界为任一可信短程跨实例关系，anchor需全部四短程关系可信。
深内部域进一步要求八个关系均可信且同实例，真边界定义不变。

汇总8192格直方图，在保留90%／95%／97%／98%真分界时比较内部误边界。
固定0.45／0.65统计加入长程后新增或移除的真／假边界，以及连续分数增强／削弱；
这些阈值只用于诊断，不改变正式部署。

另用既有四张已见GT做完整原生1024 short／gated最终推理，只切fusion mode：
连续边界拼接后全图划分，语义路径和raw最后投票固定。
gated必须精确复现缓存最终PNG／类别与GT指标，两路固定语义摘要一致。
比较旧匹配得失、共同集合IoU、误切和粘连，未知区域保持ignore。

### 共享参数上的距离梯度

分别计算四短程／两距离2／两距离4的现有类别归一化损失，对
`affinity_decoder.affinity_head[0].weight`求参数梯度；报告各组范数、两两方向余弦、
原组合与Cshort组合的方向及短程投影。方向余弦为负表示两个任务要求同一参数向相反方向改。
不使用最后八通道独立输出行判断竞争，也不用logits范数冒充参数贡献。

实际有效通道数决定组合分母，原组损失／梯度必须重构直接全通道目标。
Cshort固定每通道1／0.5／0.25；权重施加在原通道分类归一化之后。
零范数、缺乏监督或与所选参数不连接时方向为None，不伪造“零冲突”。
affinity取训练模式，D5a／encoder保持冻结；进入和退出保存／恢复模式、requires-grad、
缓冲区、Torch随机状态及浮点计算设置，最终完整模型张量摘要必须不变。
梯度诊断前向／反向只在局部上下文使用严格FP32、关闭TF32；正式融合与最终推理保留原设置。
现有GroupNorm无Dropout，同一严格FP32条件的train／eval logits须精确相同，否则先查模式差异。
记录control梯度前向与原部署前向的数值最大差，不能假装精度变化不存在。

## 完成结果与判断

### 共享梯度不支持现在启动Cshort

共同初态64条件的short–d2、short–d4方向全部为正；control e20的short–d2也全部为正。
control的short–d4仅2／64为负，而且都来自同一个SAM2源train_014的native裁块，
clean为−0.0716、blur为−0.1591。不能把重复条件算作两个独立来源的冲突。
control总体short–d2／short–d4方向余弦中位数为0.8459／0.2884；
原组合与short方向余弦中位数0.9330，最低0.8362，均仍朝向短程目标。

Cshort增加short份额后，control短程投影中位增加19.02%，这是权重改变的预期结果，
不足以证明解决了普遍竞争。所选共享层只有73,728个参数；本次覆盖16源、两个时点，
不能排除其他层或训练中期的竞争，但预先设定的“多来源、blur/native一致冲突”条件未成立。
因此本轮不启动Cshort，不用提高short比例的数学事实代替训练收益证据。

### 融合存在真实边界与内部误响应的取舍

下表是在同一可信短程目标下，分别把阈值调至保留95%真分界后的内部误边界率。
阈值只作诊断，正式部署仍固定；SAM2行只表示几何候选一致性，不是人工真值精度。

| 来源／视野／输入 | short | 原gated |
|---|---:|---:|
| 人工／whole／clean | 11.3071% | 12.1543% |
| 人工／whole／blur | 11.9290% | 12.6731% |
| 人工／native1024／clean | 7.2027% | 7.4132% |
| 人工／native1024／blur | 7.8281% | 8.0295% |
| SAM2／whole／clean | 12.4882% | 13.2529% |
| SAM2／whole／blur | 14.7886% | 15.7372% |
| SAM2／native1024／clean | 13.9105% | 14.6321% |
| SAM2／native1024／blur | 14.1983% | 14.9214% |

八个汇总条件的short均较好，但不是每个来源都改善，人工native clean／blur分别19／32与17／32。
在更严格的深内部域，人工native两条件的gated等召回误边界率反而微低约0.027／0.059个百分点。
本次种子和增强与P100旧诊断不同，不能把两份报告的绝对百分数直接作模型改进比较。

固定正式阈值0.65时，人工native clean的short→gated真分界保留率90.971%→89.493%，
内部误边界率4.650%→4.308%。加入长程移除了699处真响应、28,835处假响应，
同时新增39处真响应、4,011处假响应。blur呈相似取舍：真分界90.210%→88.819%。
原gated确实压制了一部分假边界，也削弱真实弱边界；不能概括为“长程只制造假边界”。
训练任务多为同向，部署融合仍可能损失真假边界的区分，二者不能混为一种问题。

## 结果如何决定训练

- 多来源、blur/native条件出现一致共享梯度冲突，同时短程能降低误边界而未明显损害真实弱边界，
  四图最终划分也未明显反向退化：可再实施一组Cshort，原初态、β0.5、20轮1280更新和部署固定。
- 只有融合引入误边界而无共享梯度冲突：优先研究融合，减长程训练权重不是直接修复。
- 两类检查均不支持，或条件间取舍明显：不盲训Cshort，另研究实际gated边界监督等独立机制。

以上是受限机制定位，不是独立泛化或官方涨分依据。距离单位为512输出格点；Cshort的
72.7%／18.2%／9.1%训练组份额不能称作与部署门控和top2的精确权重匹配。
