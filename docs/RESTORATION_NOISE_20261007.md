| 分析方法 | 结论与限制 |

## 预先固定的实验设计

六张图：test088、101、116、141、166、167。101／116 为既有典型图；其他四张由
NumPy default_rng(20261007) 从剩余98张预随机选择，预测前固定。

每图八个种子偏移为 `0, 1, 17, 101, 1009, 10007, 104729, 130363`。
全图基础种子仍由完整100图编号决定；局部种子仍为全图种子＋100000＋1024×1000＋窗口序号。
不会因只推理六图重新编号。第0个种子是同一控制，分析时不视为额外独立重复。

| 组别 | 唯一变化 | 固定项 |
| --- | --- | --- |
| control | 无；固定4090噪声协议 | 完整原部署 |
| local_s0…s7 | 局部恢复噪声种子 | 全图几何语义、原图末端语义 |
| global_s0…s7 | 全图恢复噪声种子 | 局部边界、原图末端语义 |
| both_s0…s7 | 对应两路同时变化 | 原图末端语义 |
| local/global/both_zero | 对应恢复网络接收零噪声 | 仍执行真实去噪网络，不绕过恢复 |
| local/global/both_pair | 同一噪声及其相反数各恢复一次，裁剪前 x0 平均 | 首步 schedule、后端及最后范围裁剪 |
| local_mean | 八次局部连续边界概率平均，再统一划分一次 | 两路全图语义固定；不平均实例 ID |

control／local／global／both 同时构成同一偏移的 2×2 分支交换对照，可检查两路交互。
每图32组，共192组最终实例及类别输出；重复 s0 保留显式契约，但不增加独立种子数。
pair 和 local_mean 的计算次数不同，不能据此单独归因“在哪一级平均更好”。

四张训练原图另用 default_rng(20261008) 预随机选择原生1024裁块，分别生成清晰、
均匀高斯σ1.2、平滑空间σ0.8→4.5三条件。single／pair 共用前三个偏移，zero 一次，
共84条重建诊断。全部区域是真实有效内容，无 padding 监督。
这些源图参与过恢复器训练，只用于定位机制，不作为留出验证或实例 GT。

检查 RGB 误差、梯度误差、由清晰参考固定的弱／强梯度方向保留、新增强边缘和平坦区响应。
先对每个源图的多个偏移平均，再对源图等权平均；纹理梯度不能冒充真实晶界标签。
跨偏移的标量 MSE 标准差不等于恢复图逐像素方差。

## 跨卡噪声协议实测

Windows RTX5060 Laptop 与 Linux RTX4090 分别运行随包 compute70 PTX，

正是此前的布局问题，不是固定协议检查失败。

| seed | 两卡相同的张量 SHA256 前缀 | 4090 原生 CUDA 对齐 |

| 314159 | 26055db357df8752 | 逐值相同 |
