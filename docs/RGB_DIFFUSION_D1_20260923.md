# 像素域条件扩散 D1：先过拟合自检，再全量60轮

2026-09-23。用户将正式预算明确改为60 epoch，要求先完成短周期过拟合测试，确认有效后再推进。
本实验不更换分割权重，不解冻SAM2，不恢复有标签分割代理或留出验证。

## 配方和接口

独立的RGB→RGB模块借鉴[ResShift](https://arxiv.org/html/2403.07319v2)的残差迁移过程，
在像素域训练；使用加入时间条件的NAF多尺度骨干，内部输入为当前状态和模糊观测，共六通道，
输出三通道清晰图估计。原始观测在每一步均可见，参数不依赖外部修复权重。
当前实现参数数为3,283,651；全量配置与短测采用相同模型。

这是项目改造，不是原版ResShift复现：采用像素域、小型NAF、RGB L1+0.2梯度L1，
不使用原实现的VQGAN压缩模型或LPIPS。训练数据仅为赛方允许的清晰训练原图，
在线退化沿用v6配方。扩散过程自身的噪声与额外传感器噪声增强是不同概念。

设清晰目标为x、模糊观测为y，正向状态为：

`state_t = (1-eta_t)*x + eta_t*y + kappa*sqrt(eta_t)*noise`

16个时间点，eta_0=0、eta_1=0.001、eta_16=1，kappa=0.1。
因此部署起点与训练终点严格一致，均为`y + kappa*noise`。
平方根eta按幂指数进度递增；配置与完整日程随checkpoint保存。
网络学习随机t下的x估计，采样使用同一过程的高斯后验均值和方差，最后一步无随机项。
状态和系数使用FP32，网络可BF16；内部状态不截断，最终输出才裁剪到[0,1]。

对外仍为RGB `[B,3,H,W]`，`strength=0`立即返回原输入并且不消耗随机数。
新checkpoint显式版本`rgb_restoration_diffusion_v1`，旧RGB/NAF格式继续严格兼容。

## 先行过拟合测试

- 在1000张训练原图的有序列表中均匀取4张，固定512裁块及纯模糊退化；不使用局部掩码。
- 四张全部参与优化，不是保留验证；固定配对内容，仅扩散时间和内部噪声持续随机。
- batch4、800次更新、学习率2e-4；网络从零训练。
- 初始及每100次更新保存完整16步采样的误差与过程缩略图，使用独立固定采样随机流。
- 事前工程门槛：最终平均RGB L1/输入RGB L1 <=0.8，梯度L1比值<=0.95，MSE比值<=0.8，
  且4张各自RGB L1均优于输入。梯度误差仅使用有效区域内的像素对。
- 门槛判断依据完整采样结果，不能拿随机时间条件训练误差代替；不选择最低loss checkpoint。

通过只能说明网络可以学习这四对样本、完整训练/采样通路可工作，不能证明真实模糊泛化或正确补边。
失败先排查接口、日程、梯度或短周期学习情况，不自动开始60轮。

## 正式配置

[配置](../config/train/rgb_restoration_diffusion_d1_all60.yaml)：1000张全部训练，零留出，
60 epoch，batch4，每轮250次更新，完整预算15000次。512裁块来自1024等比letterbox图，
反射填充区不参与损失。沿用v6的20%原样/80%模糊和前6轮局部任务，之后保留局部任务概率。
正式训练从零初始化，不接着4图过拟合权重训练。

AdamW学习率2e-4以60轮余弦降到2e-6；预先采用最后一轮`last.pt`，不生成`best.pt`。
保存第1、10、20、40、60轮快照。训练日志和完整采样误差分开，不与v6训练loss直接横比。
60轮预算覆盖不意味着已经证明饱和。

过程monitor独立于验证：固定4张训练样本、裁块、退化与采样seed，初始、第1轮、每5轮及末轮
保存输入/修复/清晰参考、固定尺度局部放大和进度标注。所有图仅写入忽略的私有产物目录。
训练随机流与预览分离，续训保存随机状态。用户无需持续监控，程序自行保存过程图。

首个清晰图估计优于最终自由采样结果；后续步骤在这次诊断中逐渐积累误差。
正向状态由清晰图合法构造，低t天然保留较多目标信息；推理只能收到前一步生成的状态。
这说明当前短训模型对两种输入状态的处理存在明显差距，不能凭随机t训练loss下降认定完整修复有效。
