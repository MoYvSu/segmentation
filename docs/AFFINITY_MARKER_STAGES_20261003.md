## 固定合同与方法

固定`config/train/affinity_balance_mixed.yaml`对应mixed balance e20头、D5a e60首步、编码器／LoRA／两路语义、原生1024窗口与0.25重叠、连续融合、真实高阈值分水岭障碍及最终raw probability投票。总参数84,951,045。只改变起始区域生成方式：

| 读出 | 操作 | 用途 |
| --- | --- | --- |
| 原R1 | 原bridge、实际细化、dilate、seal及小区域过滤 | 验证旧完整输出精确复现 |
| reflect | bridge后镜像32px，再用原细化算法，裁回、接原dilate／seal／过滤 | 精确复现已评分参照 |
| nothin | 不做细化，bridge后直接接原dilate／seal／过滤 | 机制反事实；不是提交候选 |

marker是分水岭的起始区域。逐阶段检查的是屏障之外是否仍有通路：不同GT应被隔开，同一GT内部应能相通。顺序为high mask → 弱边界重建 → bridge → 原骨架／镜像骨架（nothin无此阶段）→ dilation → seal → 过滤后marker → 真实watershed → 最终uint16实例。高阈值0.65、低阈值0.45、重建8步及其余参数固定。

使用此前在输出前固定的六源（002、172、347、351、658、874）和已知定位源659。六源不是六类材质的分层验证；659另列为已知病例。全部使用处理后GT，包括filled；未知0仍忽略。这些源参加过训练，只能定位机制。

同时检查完整图、全部已知域、目标GT并集三个范围。两端只要有一个被屏障覆盖而成为0，就保持关系未知，不能称已经分开。目标GT并集的通路不会经过未知区或第三实例。完整已知对象检查保留所有贡献，包括微小片和0；两点达标不等于整粒恢复。接未知／图框的对象保留删失标记（无法确认其完整真实面积），不因局部变好删除失败记录。

原R1跨旧run的四张实际图和最终类别全部exact；七源reflect最终PNG与类别逐值匹配既存缓存。输入、GT、模型身份和受保护源码前后不变。细化使用原环境实际skimage回退。659的局部detail图未冒充全图marker。

## 队列与面积口径

旧R1有688个匹配F，reflect实际有689个。不能把继承旧688名单的汇总均值，直接与新689名单相减。此次独立汇总固定reflect实际689个GT，对nothin逐GT匹配，失配计0。平均实例IoU为0.90210451 → 0.90362738；属于已见GT诊断，不是比赛mIoU。

135个固定安全面积中，nothin仅131个仍可比较，其中130个面积改变，4个因接未知／图框失去可比较资格。共同131项相对面积MAE为3.2019% → 3.0702%；必须与4项失败并列，不能只报告共同子集改善，也不能外推比赛平均面积项。

nothin新增6个保守拆分：1F、5P。唯一安全F内部拆分（351的GT71）也是上述1F，两个诊断口径重叠，不能累加成7个独立错误。5个P拆分不直接计算铁素体平均面积，但仍影响mIoU。完整F数量／像素、相别翻转及全部错误名单保留在私有汇总，不用数量下降或面积上升拟合测试答案。

## 下一步与训练门禁

保留reflect固定读出，下一方向为**完整界面闭合与完整粒内通道纠正**：异粒弱界必须形成连续分隔，同粒内部要消除整条错误屏障，而不是只提高少量边的响应。

先用未删失659的69／70定位界面闭合，用可信未删失347的GT40定位完整内部通道。其余有可靠已知域的源做副作用与回归检查，GT48歧义不作确认的物理错误目标。只用已有允许训练GT，不制作测试GT。

冻结权重反事实必须同时修复完整目标、保住固定F匹配与深部、明确列出面积删失及新增误切／粘连，且在其余多源终态复查。只有实际连续融合和最终marker／实例均显示目标收益，才考虑复制affinity头短训；保留原完整GT监督和可靠旧关系约束，上游、语义与reflect合同固定。单源拟合、暂时骨架连通或训练loss下降均不通过门禁。本轮未启动短训或20轮训练。

已有旧链曾扫弱重建参数，见`AFFINITY_INFERENCE_AUDIT_20260826.md`；不能将旧代理结论当当前reflect链收益，也不把简单全局阈值／步数扫参称为新方向。
