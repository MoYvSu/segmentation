# 技术报告资料索引

本页将已有技术文档和实验记录整理为报告写作入口。研究记录是证据库，正式报告只保留
与最终提交方法有关的关键设计、必要对照和可核验结论，不按时间顺序罗列全部试验。
实验状态与最终部署可能继续变化，定稿时须再次核对实际提交版本，不能把候选写成主线。

## 建议阅读顺序

1. [当前管线与产物约定](PIPELINE.md)：核对实际模块顺序及当前推荐入口。
2. [半决赛规则与安排](SEMIFINAL_RULES_20261024.md)及[赛题规则备忘](../COMPETITION_RULES.md)：
   以本赛段口径确认数据、标注、模型、评分和提交限制。
3. 下表中的模块设计资料，再读取对应终态分析；实验计划不等于已完成证据。
4. 最后核对官方回分、提交包身份和最终代码/权重版本，再确定报告中的方法与成绩。

## 定稿前需要固定的证据

| 项目 | 使用原则 |
| --- | --- |
| 最终方法身份 | 绑定实际提交包、代码版本、配置和模型SHA；以该版本解释结果 |
| 官方结果表 | 只比较同赛段、同评分公式；列mIoU、面积项和可用的TP/FP/FN，不把precision改善自动等同总分改善 |
| 消融表 | 说明唯一变化、固定项和控制来源；复用同一控制，未测试项不补造数字 |
| 数据使用说明 | 区分人工GT、处理填补、自动几何候选、无标签训练和测试集目检；实际数量以最终数据清单为准 |
| 诊断与结论 | 已见GT重建、热图/实例数量、无标签目检仅作机制证据，不冒充独立验证或本地黑盒成绩 |
| 图片与附件 | 赛题原图及派生图、标注、权重、结果JSON和提交包保留于私有产物目录，不能收入GitHub文档或内嵌图像 |
