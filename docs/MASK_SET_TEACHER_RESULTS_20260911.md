## 归属约束减少了哪些问题，又留下了什么

在 873 的固定局部，归属组显著减少大晶粒内部的闭环碎片，形状更接近 GT 和主线。172 中，加入伪标签后原先破碎的中央三角形晶粒得到恢复，但相邻暗部仍出现大块空缺；归属组也仍有内部小环。两个局部都不能代表全体图像的平均表现，但与全图指标的收益、代价方向相符。

### 原始掩码确实重叠，但“环套环”不是最终 PNG 的双重 ID

最终 PNG 每像素只保留一个 ID，因而不存在同一像素保存两个实例的问题；环可以是不同候选争夺像素后留下的嵌套碎片。原始 sigmoid 掩码允许多个候选同时覆盖一个像素，本次直接测量了这一点。

| 512 网格有效图像内容，排除 padding | 原监督 e103 | 仅伪标签 e112 | 加归属 e120 |
|---|---:|---:|---:|
| 六张验证图，至少两个原始候选覆盖的像素占比 | 50.19% | 37.37% | 36.81% |
| 四张无标签留出图，同一占比 | 49.79% | 30.85% | 37.91% |
| 六图原尺寸，已覆盖像素平均候选数量 | 1.738 | 1.467 | 1.454 |

原尺寸最后一行是重数均值，**不是重叠像素百分比**；前两行来自单独的 512 网格诊断。伪标签训练方案明显减少重叠，归属项在六图上只再减少约 0.56 个百分点，在四张留出图上反而增加约 7.06 个百分点。现有证据不支持“归属项已普遍解决重叠”。

归属交叉熵比较的是候选之间的相对分数；它能选对相对赢家，却不保证赢家的绝对 sigmoid 概率足够高。当前空缺增加与这个已知限制相容，但本次并未证明“所有 logits 整体下降”就是原因。仍应保留 BCE/Dice 和 unknown-ignore，不把全图硬填满当作覆盖修复。

## 无标签一致性现在值得尝试吗

**值得做一个小规模、单变量对照；尚不能称为已经证明必需或一定有效。** 新方案已有更多可靠完整实例，可给一致性学习提供监督起点。固定主线伪标签本身已经让无标签图像参与任务训练，加入一致性的理由应是进一步改善稳定性与泛化。

本次对三个学生权重额外运行冻结前向：同六张验证图，加固定留出名单的前四张 `train_024/032/113/162`；后四张不在 249 张伪标签中。每图比较原图、轻微亮度/对比变化，以及水平翻转恢复后的结果。外观变化固定为 `clamp(1.08*x - .04, 0, 1)**.94`。

同类实例先一对一配对，在外观变化与翻转两个视图中均达到 IoU≥.8 才记为稳定；筛选只使用模型输出与图像内容，**GT 仅用于筛选后的可靠性审计**。使用 FP32 highest 和 512 网格统一重跑三个版本，未用部署扫参选阈值。此探针不是正式原尺寸评测，更不是已经完成 EMA 训练。

新版不是筛选准确率变得更高，而是在接近九成有效匹配的水平上，获得了约两倍的稳定区域。归属组的筛选可靠性与覆盖范围在本探针上略优，这为继续使用它作为学生起点提供了附加依据；四张留出图没有 GT，**58.10% 仅代表稳定覆盖，不能解释为正确率**。

## 建议的下一轮：保留监督基础，单独检验 EMA 实例一致性

推荐以**归属组损失最优 e120**作为下一次对照的共同起点：它在当前赛题相关面积项、碎片控制上更好，且能够提供更大范围的稳定实例。仅伪标签 e112 仍保留为覆盖率更好的回退。这个选择结合了完整几何、面积、空缺和稳定性证据，不代表按代理总分重新选择本轮 epoch，也不宣称 e120 全面优于 e112。

EMA 教师就是把学生历次权重做平滑平均，输出变化相对平缓的训练目标；教师不参与反向传播。方法依据见 [Mean Teacher 原论文](https://arxiv.org/abs/1703.01780)。弱扰动教师指导较强扰动学生，可参考 [UniMatch 原论文](https://arxiv.org/abs/2208.09910) 的一致性思路；这不构成其在本项目必然有效的证据。

1. **只增加一个短续训阶段。** 不重训 SSL，不重置任务头；从同一 e120 分出“不加一致性”与“加入一致性”两组，使用相同监督更新预算、人工/伪标签顺序、学习率日程和种子。这样不会把多训一段的收益误当成 EMA 收益。初次可预设 20～30 轮，不做大规模组合搜索；正式时长与吞吐应在实现后的真实 GPU 小验证中测量。
2. **继续保留人工 GT 与固定主线伪标签。** 它们提供比学生当前漏检更完整的目标，防止只强化学生已经会的区域。先固定归属权重 .5，不同时修改覆盖损失或推理阈值；本实验回答“一致性是否值得保留”。
3. **匹配实例，不直接对齐 query 编号。** 两次前向的第 k 个候选未必是同一晶粒；先恢复几何变换，再按类别与区域重合进行一对一配对。教师采用互斥分配后的稳定实例作为目标，保留可信区域，冲突、未分配和边界不确定区域忽略。新无标签样本没有被选中的区域不能自动视为背景，也不能给所有未配对 query 施加 no-object 惩罚。
4. **一致性权重从小逐步增加。** 只在质量筛选通过时贡献梯度；人工图的已知 GT 不被教师覆盖。优先采用已验证可恢复的轻外观变化与翻转，不同时加入会截断实例的复杂拼贴等增强。EMA 降低时序噪声，不能凭空恢复始终漏掉的晶粒。
5. **使用合规训练无标签池。** 扣除人工划分、固定无标签留出图及同内容重复图，不读取测试图训练。数据来源与筛选记录继续明确，不把在线模型目标记成人工标注。现有 249 张固定主线伪标签清单保持不变。
6. **按原人工监督验证损失选各阶段权重。** 最后才比较同一六图的原尺寸完整输出，以及固定无标签局部。重点要求计入漏检的 IoU、有效匹配和已知区域覆盖率不恶化，面积误差与形状有可重复收益；只看到一致性损失下降、稳定区域变大或环变少，不算晋级。部署时仍输出一个学生模型，不引入教师/学生连续融合。

如果短对照只让已有稳定实例更自信，却继续增大空缺或压掉小实例，应停止增加一致性权重，回到绝对掩码覆盖和遗漏的诊断；这时更复杂的教师系统没有充分依据。本轮不实现这些后续训练改动，也不因新方案进步撤下已验证主线。
