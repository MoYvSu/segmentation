# 保留原有分隔与全实例面积离群过滤

## 范围

落实[种子诊断](SEMANTIC_SPLIT_20260927.md)的第一步。D5a e60、simple语义头及独立语义LoRA e20、
V affinity与真实分水岭障碍保持固定，只改变种子生成及面积清理。
本轮遵循用户最终要求：**对所有实例统一过滤，阈值来自每张图的实际预测面积分布，不读取训练GT。**
不依据期望铁素体平均面积／实例数选择阈值，不使用类别特例，没有新训练。

## 实现

`utils/marker_restoration.py::restore_marker_partitions`在整图求粗边界反相连通域：
只做原弱边重建和bridge，不骨架化、不加新框。在每个旧正marker内部，若两个以上独立参考区域
各自提供不少于50像素的连通核心，则赋独立编号；不足时保持原marker。
每个参考区域只取该marker内最大的连通交集，不能把分散小碎片累计到门槛。
恢复阶段不跨旧marker合并，也不删除旧编号；**后续统一面积过滤可以删除任意旧／新小种子。**

`utils/post_process.py::_restored_marker_watershed`先执行真实分水岭，获得完整实例面积，
而不是用种子核心面积代替。令这一图全部正区域面积为A，计算：

```text
q1 = Q25(log(A))
q3 = Q75(log(A))
T  = floor(exp(q1 - 1.5 * (q3 - q1)))
```

对数使少数巨大的实例不直接拉动尺度；箱线图的下界只识别小侧离群，不是固定百分位删除。
同图所有实例使用同一个T，单位为原图像素，不依赖分辨率的外部固定阈值。
T只在首次分割计算一次并冻结；取消低于T的区域种子后，以同一分水岭重新分配像素，
不会直接从成品mask挖洞。若重分配后仍出现低于同一个T的区域，继续删seed并重分配；
每次严格减少seed，不能提高T。全相等／单实例不能因为exp/log的浮点尾差被误判成全部离群，
因此下界保守地向下取整。没有全局保留旧小实例或按父实例回退的额外规则。

原有最小种子／成品面积50、uint16上限65535、最终类别平均概率投票维持原口径。
关闭新配置时走原函数路径，旧checkpoint及原配置不变。
每张候选输出附`*_marker_restore.json`，记录恢复阶段父子来源、首次面积分布、固定阈值、
删除区域及重新分配次数；这些私有逐图记录不进入Git。

## 同权重黑盒配对结论

用户随后回报 `lora_control.zip` 为 **0.8445 / 0.8557**，等权折算85.010。
因此现在可以比较同一LoRA e20、D5a、输入和投票约定下的后处理变化：

| 方案 | mIoU | 铁素体面积项 | 等权折算 |
| --- | ---: | ---: | ---: |
| 原后处理LoRA控制 | 0.8445 | 0.8557 | 85.010 |
| 种子恢复＋统一面积过滤 | 0.8474 | 0.8354 | 84.140 |
| 候选减控制 | +0.0029 | −0.0203 | −0.870 |

这支持“本次后处理组合提高了官方mIoU，但面积项损失更大”。此前的铁素体平均面积系统性下降
与面积项变差同时出现，但无测试GT，不能证明所有新拆分均错误，也不能量化恢复和过滤各自贡献。
同样，mIoU提高不证明每条新增分隔正确，mIoU还受实例类别投票变化影响。
保持新后处理关闭，不按黑盒反调实例数或平均面积。LoRA控制是后续尺度训练的直接基准；
85.010仍未超过此前旧v4的85.715，不因此替换已验证最佳方案。
