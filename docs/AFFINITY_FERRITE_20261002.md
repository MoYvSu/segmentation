# 正式原生1024路径的铁素体专项定位

2026-10-02，承接[边界到实例定位](AFFINITY_PARTITION_20261002.md)。
用户要求将优化重点转向直接关系铁素体计数及面积的错误；珠光体案例只作机制旁证。
本轮仅分析冻结最高分输出，不训练、不生成黑盒包、不替换部署。

## 结论先行

正式1024路径全32张检查已完成。训练原图上存在铁素体弱界粘连和轮廓／面积收缩，
但目前不足以支持继续全局增权或扩大内部假边界惩罚。
固定展示的两处“内部多切”沿原图可见横线，而新GT没有分开，存在漏分歧义；
不能把它们自动当成模型幻觉边界。训练内类别表现较好也不能排除测试域语义错误。
下一项建议先拆未归属像素来源，再做固定语义的正式尺度局部模糊诊断；尚未部署或训练。

## 方法和复用边界

捕获入口`tools/probe_ferrite_native.py --mode capture`，只运行R1。
上轮正式两源train686／707有最终PNG、类别和连续边界SHA，但缺实际连续数组，
所以补一次相同seed的冻结前向，严格核对最终PNG、类别、两路语义、连续边界、真实种子／分水岭、blend摘要。
其余30源无满足合同的正式缓存，需要新增冻结推理；历史32rows实际是4源×8视图且支持域不同，不能冒称全32源缓存。
源图顺序保留旧两源前缀，再排序其余30源；seed为inference_seed加该固定序号，旧两源仍314159／314160。
先完整拼接连续边界，再一次全图划分与原图末端投票；每图捕获实际cv2.watershed种子。
只保存最终uint16PNG／类别、压缩float32连续边界／实际种子及回执，不复制整套RGB／语义张量。
旧148份源码及快照、运行精度／环境、模型冻结状态、父报告、旧结果、源图和新GT前后保护。

CPU入口同脚本`--mode analyze`；核心`tools/analyze_ferrite_native.py`。
按一次GT／pred交叉计数派生逐对象贡献、匹配与面积，不反复逐GT扫描整幅大图。
需严格分开：

- 铁素体之间粘连：同预测区覆盖多个真实F，是否有直接可信接触另记。
- 铁素体内部假切候选：多个预测片主要落在同GT，不能只因GT被多个ID覆盖就当真误切。
- 邻区侵入／边界偏位：GT贡献片的预测区还主要覆盖其他GT，贡献不是新晶粒数。
- 铁素体／珠光体混区及类别错误：几何混区与最终投票分开，类别0P／1F固定。
- 完整铁素体面积：GT与对应预测区都不触unknown／图框才作完整对象面积诊断；匹配及拆粘单列。

50像素／10%显著贡献门槛只是辅助描述，不能将门槛退出记为完整修复。
所有触unknown／图框的整个GT或预测区单列censor，不以裁图消除风险；不能计算不完整GT的全图平均面积得分。
图册规则事先固定：按源图名排序，每类机制最多两源、每源同类最多一例；缺可信案例就报告缺席，不放宽门槛凑例。

## 铁素体覆盖与错误分型

| 诊断对象／机制 | 全32结果 | 可完整比较的部分／解释 |
| --- | ---: | --- |
| F GT | 3192粒 | 不触unknown／图框560粒（17.54%；占F已知像素10.97%） |
| 几何一对一匹配F（IoU≥0.5） | 3055粒 | 这3055粒最终类别均为F；未匹配137粒不能据此排除类别或几何问题 |
| FF双向显著且真实接触的粘连候选 | 85个预测区 | 完整GT／预测区的整粒共占仅1例，train659 GT69／70 |
| 严格内部多切候选 | 1个GT | 触未知区，完整可信0例 |
| 同一主要GT的深内部多片候选 | 256个GT | 完整10例；仍需原图检查，不能直接等同假边界 |
| 显著邻区侵入 | 127个GT | 与粘连／多片不互斥，不相加作错误总数 |
| 主要发生在真实界4像素内的轮廓差异候选 | 2390个GT | 包含正常像素化错位，不能都称严重分割错误 |
| 完整、同类、一对一且无显著拆粘的F面积 | 467粒 | 仅全部F的14.63%，占F已知像素8.71% |

普通“一个GT内出现多个pred ID”几乎遍及全32源，大量只是邻区轮廓贡献；
不是数千次内部误切。上述机制使用不同计数单位、且互有重叠。
触unknown／图框的对象仍保留诊断，但不由其未知完整面积推断正式均面积。
来源并不均匀：train171–176六源只有446／3192个F，却承载129／256个同父多片候选和
60／137个未匹配F，其安全F仅27粒。后续配对必须逐源报告新增／消失的机制，
不能仅使用总量；这并未证明具体成因是光照或模糊。

## 面积与最终相区分配

467粒安全面积样本：382粒偏小、85粒偏大；逐对象平均有符号误差−2.534%，
平均绝对误差2.928%，中位有符号误差−1.464%。23粒绝对误差超过10%，全部收缩。
