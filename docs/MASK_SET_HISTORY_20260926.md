## 最后一次有效比较

来自历史`MASK_SET_CONSISTENCY_RESULTS_20260911.md`。相同五图、790个GT、原尺寸最终PNG；
未知区域不计入评价。不是官方黑盒，也不是本轮复赛测试；主线训练划分独立性未重新认证，
跨结构数字是同图输出参照，不能当成严格同训练集的泛化对照。

|指标|同预算续训e143|EMA一致性e144|当时E10a＋G4b|
|---|---:|---:|---:|
|有效匹配／790|609|615|715|
|匹配实例IoU|0.8299|0.8322|0.8475|
|漏检GT计零IoU|0.6398|0.6479|0.7670|
|已知GT像素未覆盖率|10.29%|8.91%|1.27%|

EMA让五图覆盖均有改善，但仍少匹配100个晶粒。取消类别限制后一致性组仍是615个几何匹配，
不能靠只改类别挽回这些漏配。该结论不代表所有未匹配实例的类别正确。

报告还排除了“只是删掉小区域”的解释：最低保留面积为1、不作重叠率淘汰，所有被拒绝候选
的已分配面积均为0；空缺在合格候选的掩码概率达到0.5后的覆盖集合中已经存在。
252–256个query通过类别门槛也不能单独证明候选数不足或no-object为唯一原因。
原始候选重叠、互斥竞争、概率不足和错误分区仍需区分；不能靠强制填满图像掩盖未检出。

当时决定保留e144候选，不替换主线，不直接延长训练。它没有证明所有Mask2Former变体无效，
但足以说明上一轮推荐的核心机制并非新方案。若重访，必须提出针对覆盖／实例归属缺陷的明确改变。
