## 是否精简、是否需要TTA

移除的是额外随机噪声生成及其实际注入。D5a恢复、两个任务头及三条输入处理路径仍保留：
整图恢复语义决定划分底图，局部恢复产生affinity边界，原图语义负责最终类别投票。
因此没有把整个模型合并为一次前向，也没有绕过恢复器。

当前全图前向还会计算未被patch1024最终边界使用的global affinity，旧入口也保留噪声资源的审计依赖；
这些可以另做保持最终输出一致的代码整理，但本包保持已验证执行顺序，不混入额外精简。
黑盒结果ZIP本身不包含任何噪声程序、代码或权重。

本包TTA关闭。已有方向平均只做过局部诊断，响应幅值发生变化，未取得完整读出或官方收益证据。
固定翻转/旋转后融合可以是可重复的TTA，但不能直接视为当前模型的稳定性或精度提升。
本包全零单视图的用户回分见首节；如以后引入TTA，应另做单变量对照。

12图独立同seed重复exact不证明任意硬件逐位一致；本包用户转报成绩独立归属，不继承旧含噪控制成绩。
