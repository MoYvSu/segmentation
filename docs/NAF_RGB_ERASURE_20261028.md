# 恢复RGB条件＋T8擦断实验

2026-10-28。用户在旧RGB复查后明确选择使用重建网络处理过的RGB。
本轮使用冻结D5a的N1局部零噪声首步输出作为RGB条件，训练新的四通道NAF边界修复器；
D5a、分割后端、原B1及raw语义投票固定。研究控制直接复用上一轮T8＋擦断的afc1bbaa，
不重复控制训练，不继承任何已训练NAF权重。

这一比较回答“增加恢复RGB条件是否有用”，不能拆分原RGB信息和D5a预处理各自的贡献。
旧raw RGB实验还同时缺少T8和人工擦断，不把跨配方变化全归给RGB。

在同一个N1>=.45公共带内，四图2×2棋盘交替幅度均下降；但raw概率出现更明显的规则竖向多轨。

| bridge后闭合孔 | 2385→3083 | 1857→3068 |
| reflect骨架后闭合孔 | 2068→1429 | 1520→1172 |
| dilate/seal belt孔<500px | 332→2153 | 337→2377 |

大量微腔被已有core50等过滤，不能把上千孔写成上千误检；50–499px也增加，且最终小F增多，
所以也不能声称微腔全部无害。棋盘项下降、骨架孔减少，都不能代替belt与最终实例检查。

补做两块固定干净256窗口的同步RGB/T位移探针：原输出SHA与monitor逐项一致；
只在中心160×160及valid区域比较，避免直接将输入边缘效应计入。
GT±8带内，移动1px再逆对齐的概率MAE为0.163–0.230，移动16px仅0.0014–0.0036。
该现象在单窗、未拼接或后处理时成立，支持明显的16像素相位敏感；
不因网络含PixelShuffle就断言全部由该算子造成。

固定七窗仅把恢复RGB改为同窗空间均值，平均valid输出MAE为0.03739，
自然缺口峰值变为25/161；转灰度仅0.00241，仍5/161。空间均值RGB仍有竖向多轨，
所以真实RGB纹理不是网格产生的必要条件。它证明RGB影响输出，不能把25点当作真实补边改善，
也不能用反事实输入的峰值选择正式部署。

### 决策与证据

本轮不原样续训、不替换旧模型、不自动出包。RGB有互补信息，但当前输入/目标/生成器组合
尚未将其转化为稳定完整分隔；不能将失败扩大为D5a或RGB方向普遍无效。
主要未解决项是局部max覆盖允许多轨/不连续高峰，以及输出对像素格点的强依赖。
优先保留单通道擦断控制，另做单变量的位移一致性或上采样设计实验，二者不同时叠加；
当前仅提出方向，没有启动下一轮。
