# 当前raw语义的完整GT对象裁窗检查

## 问题与隔离

承接[尺度与分支贡献检查](SEMANTIC_NATIVE_20261004.md)。当前高分辨修正有实际像素贡献，
应保留；直接原生裁块拼接主要改变小片，尚未改变大对象类别。
前次A64／B64已更新全部语义头，包括粗FPN与分类层，本次不能称首次训练粗分支。
新增问题是：当已标对象完整保留、周围上下文减少、原生纹理被放大时，当前头能否保持其类别判断？

“完整”仅指裁窗保留整个已处理GT父对象，不保证原标物理完整或内部局部物相已分别标注。
只使用既有32源处理后新GT，不补标、不从测试外观生成标签，不重新运行恢复器或几何。
上游编码器／LoRA及原部署语义、affinity、融合、实例PNG和分类阈值全部固定。
最终对照仅复制出末端语义头；现有最佳reflect保持。

## 预先固定的裁窗

- 对每源分别选F／P锚点：处理GT面积至少10000原生像素、原标覆盖至少80%、不触原图框。
- 不读取预测类别、错误榜单或测试图选择锚点；各类按面积、ID排序，取下中位数。
- 裁窗边长为`max(512, ceil(1.5 * max(bbox_height, bbox_width)))`，以对象框中心放置，
  超出原图时向内平移；原图某轴不足所需尺寸时保留该轴真实尺寸，不挤压。
- 从原图先裁RGB及同坐标GT／原标支持，再等比letterbox到1024；RGB reflect padding，
  GT常数0填充、padding与unknown无监督。必须验证锚点没有丢失任何原生像素。
- 每张裁窗重新通过冻结编码器，不能将原整图特征作为新裁窗特征。

先查既有固定四训练源001／173／558／889的八个裁窗合同。
八窗不代表32源的全部材质；必要时在训练前按同一规则捕获全部32源×两类的64裁窗。
两档均是零更新预检，不因四源未翻类就断言全训练域无信息。

## 是否值得短训的门槛

对锚点只在原标覆盖支持上汇聚概率、核心及像素分歧，filled／unknown／padding另列。
保留共同GT损失的真实梯度分布，检查粗FPN／分类层／高分辨修正分别有何学习信号。
输出梯度细分锚点原标／filled、其他完整对象、裁断邻居、unknown／padding；
另以锚点原标均值BCE作只读梯度诊断，不将它加入拟议训练目标。
所有数据、原概率SHA／逐ID类别、冻结状态、几何、输入位置与源码回执须通过。

只有预声明裁窗中至少一处出现如下信号，并满足有效梯度要求，才建议短训：

1. 真类平均概率较原整图下降至少0.05，或锚点原标像素错误率增加至少0.01。
2. 达到信号阈值的锚点，其原标均值诊断梯度能到达粗FPN与分类层；
   共同损失输出梯度在锚点原标域的绝对和大于锚点filled域，不能靠裁断邻居梯度代替。
3. unknown／padding的输出监督梯度严格为0，原部署状态无变化。

这是训练域机制门槛，不是泛化或官方收益门槛；不能通过增加裁窗倍率或降低阈值直到通过。
测试翻类、测试平均面积、目检亮度均不参与上述判断。
若信号只来自filled、裁断邻居或忽略域泄漏，停在预检，不自动训练。

## 若预检通过：候选64更新

| 项目 | 固定内容／唯一新配方 |
| --- | --- |
| 起点 | 原R1 mixed balance e20，同前次控制A64，保留现有全部语义头结构 |
| 控制 | 直接复用完成的整图共同GT控制A64，不重训 |
| 预算 | 同32源×两遍源序，64 AdamW更新，学习率2e-5、eps1e-4、weight decay1e-4、clip1 |
| 模式 | 整个复制语义头可训练但保持eval；原编码器／LoRA及全部上游冻结 |
| 目标 | `0.5 * whole共同GT损失 + 0.5 * 同源完整GT对象crop共同GT损失` |
| GT | 沿用原pixel／core／pool目标，processed-known含filled；unknown／padding忽略 |
| 锚点 | 每源首次曝光用预固定F，第二次用P；不附加182个预测小片的区域监督 |
| 观察 | s0／16／32／64固定缩略图、完整续训状态；末态固定32训练＋8既有测试实例对照 |

这是训练视野混合的整体方案对照，不能称纯尺度或粗分支单独消融。
候选每次更新有两个头部视图，控制为一个；裁窗改变上下文、纹理尺度、GT覆盖、
邻居截断和pool对象组成，这些均须记录。64更新只是机制短测，不能宣称收敛。
正式训练前必须核对旧控制初态、源序、配置、输入、权重与optimizer合同；
之后严格重载末态，并在固定实例PNG上比较大对象、核心、双向改类和小F组成。
当前计划不包含100图推理、黑盒或自动替换最佳。

四源八窗只用于合同检查；决定短测价值采用全部32源64窗，不从八窗推断整个训练分布。

原R1、复制语义头、输入、源码及配置前后保持，优化器更新为0，unknown／padding输出监督梯度为0。
未调用D5a、affinity或分水岭，也未使用测试图选锚点或训练。

这些对象都来自参加过训练的32源；“错”只指与记录GT不一致，不能直接裁决父多边形内的物理物相。
选位、倍率、门槛均没有根据输出修改，未添加预测小片的强制父类别监督。

**取舍：不把本路线升为整粒语义主线，但保留一次有限64更新机制对照。**
现成裁窗缓存和旧A64能降低该短测的成本；它回答混合视野能否压低P内部局部错误响应，
以及是否伤害原整图F判断，不预设能够解决测试图的整片F→P或提高官方mIoU。
正式入口为`tools/fit_semantic_grain_view.py`，配置`config/train/semantic_grain_fit.yaml`，默认只列计划。
`--smoke`在独立目录仅更新2次，整图读出限制为固定4训练＋4测试；正式`--go64`才运行64次更新。
smoke权重不作为正式起点，正式始终重新从原R1初始化。

末态除固定40源整图外，必须在全部64个封存裁窗上比较原R1、旧A64和候选，
按原标域报告像素错误、均值、核心与整对象类别；旧A64只新增缓存读出，不重训。
候选重载同时复核裁窗概率与指标；smoke裁窗范围仅固定4训练源×两类，共8窗。
保留固定裁窗过程缩略图，与整图monitor分开。训练不调用冻结编码器，复用的每份crop特征都必须
逐项绑定本次预检的RGB、坐标、GT、特征值及stride，不能用whole特征冒充新输入。

如果只改善已见P像素、大对象读出仍不变，就记录局部任务可学但未触达主瓶颈，不原样扩训。
若固定GT匹配或F整对象回退，或者只令小F数量显著增加，同样不扩训／100图推理／黑盒或晋级。
无标签测试的改判只作预测变化，不判断其正确方向；最佳reflect及原R1回退保持。
