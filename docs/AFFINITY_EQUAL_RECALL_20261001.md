# 2026-10-01：原生1024连接增权的等真分界召回诊断

## 目的与结论

比较旧p1024 e20与native balance e20，在保住相同比例真实分界时，晶粒内部误断是否减少。
这用于区分概率工作点变化与真假边界辨识改善。32源均参与过训练，原标也有缺陷；
本检查是机制诊断，不能代替独立验证或官方成绩，不能据此选择测试图阈值。

关系层与严格内部融合层的曲线接近重合，没有稳定的排序改善证据。固定部署阈值0.65下，
balance明显减少内部假响应，也保留更少真分界。这与误切／粘连取舍改变的解释相符；
不能证明balance只等价于调旧阈值，不能据训练诊断否定用户转报的官方收益。

用户已报告native balance e20／原生1024的官方结果0.8639／0.8730，综合86.845，
优于旧p1024的0.8580／0.8568及旧全图control的综合86.235。包身份由主任务核对；
本诊断未登录比赛平台、未提交新包、未进行新训练。

## 三种统计口径

1. **关系层**：512网格的8个既有offset，`1-sigmoid(affinity_logits)`为分界分数。
   两端原标`original_covered`且实例ID均大于零才可信；不同ID是真分界，同ID是内部连接。
   offset为四个单位轴向／对角关系，以及各两个距离2、距离4关系，分别报告并汇总。
   填充、窗外、零ID、未覆盖端点与covered-uncovered关系全部忽略。
2. **短距内部融合层**（`fused_boundary`）：复用部署gated-top2融合，正例要求四个短距关系
   全部可信且至少一条跨实例；负例要求四条全部同实例。这层也会将部分合法长距跨界响应
   算入内部响应，因此对边界宽度敏感，不能直接称为纯内部假边界精度。
3. **严格内部融合层**（`fused_deep_interior`）：正例仍为上述可信短距跨界；负例进一步要求
   全部8个关系均可信且同实例。长距可能合法跨界的近界面像素排除，避免口径混淆。
   每种输入有40911个正例像素及6728069个严格内部像素；短距内部口径负例为7292520。

融合层只比较512网格的连续概率，不进行多窗拼接、语义投票或最终实例划分。
它不是官方实例指标；原图上插值、窗口拼接及全局后处理可能进一步改变效果。
概率分8192格量化，阈值分辨率1/8192≈0.000122。预定比较90%、95%、97%、98%真分界召回，
报告实际达到值，分别累计并按源配对。没有从测试输出面积、实例数或黑盒分数拟合阈值。

## 等97%真分界保留：内部错误响应

下表为32源汇总；低值较好。严格层两模型实际保留率均97.0008066%，量化差异极小。

| 输入／口径 | 旧p1024 | native balance |
|---|---:|---:|
| clean／全部关系 | 6.373% | 6.370% |
| blur／全部关系 | 6.441% | 6.490% |
| clean／四个短距关系 | 9.804% | 9.910% |
| blur／四个短距关系 | 9.910% | 10.088% |
| clean／短距内部融合 | 11.709% | 11.855% |
| blur／短距内部融合 | 11.813% | 12.006% |
| clean／严格内部融合 | 6.549% | 6.585% |
| blur／严格内部融合 | 6.694% | 6.772% |

全部关系ROC AUC：clean 0.988539→0.988502，blur 0.988166→0.988138；
严格内部融合AUC：clean 0.989987→0.990025，blur 0.989545→0.989534。
严格融合的边界AP有小幅增加（0.588109→0.594232、0.576040→0.583071），但未转化为
各预定高召回点一致的内部误断下降。不能把这些低差异称为统计显著或泛化提升。

按源各自对齐97%召回时，严格内部层clean的32源有16改善／16变差，平均变化−0.0225个百分点；
blur有17改善／15变差，平均+0.0396个百分点。小变化方向随输入与聚合口径而变，
不支持“真假边界排序能力已显著增强”。

## 固定部署阈值0.65：工作点确实发生变化

只对融合层在现有0.65附近读取直方图，不修改部署配置；量化下界为0.650024414。

| 输入 | 真分界保留：旧→新 | 严格内部假响应：旧→新 | 短距内部响应：旧→新 |
|---|---:|---:|---:|
| clean | 89.770%→86.774% | 1.771%→1.317% | 4.963%→4.170% |
| blur | 90.250%→87.390% | 1.828%→1.371% | 4.987%→4.191% |

严格内部假响应相对下降约25%，伴随约2.9–3.0个百分点的真分界保留下降。
这解释了为什么训练连接率提高、预测碎片减少，同时部分弱界面会合并。
官方两项均提升说明这次取舍在当前完整部署链上更合适，而不是“所有真实分界都更准确”。
本检查不足以证明对旧权重做一个阈值变换就能逐像素复现balance；曲线仍有局部排序差异，
多offset融合、插值、窗口混合和全局后处理也不等价于单一分数变换。

补充版单独在其`strict/`子目录，未覆盖首版回执。两次的64份输入回执和原640份关系／融合
直方图逐值一致；新增严格内部层没有改变原层结果。完整数据、逐源结果和图像不进入Git。

运行命令（项目根目录，sam2_env，GPU）：

```bash
python tools/probe_affinity_equal_recall.py --sources all --output outputs/equal_recall/strict
```

若目录已存在应换独立输出目录，禁止覆盖既有回执。`deploy_point.json`来自相同保存直方图的
纯CPU读取，私有复现脚本保存在本地`output/equal_recall/setup/deploy_point.py`。
5个合成测试通过，覆盖未知／填充忽略、融合可信口径、严格内部排除合法长距跨界、
纯单调校准的等召回不变性，以及真实排序改善可降低等召回误断。

下一步先保留已证实的native balance e20与完整交付身份，利用已完成的mixed balance进行一次
独立官方检验，不重训控制。若进一步开展尺度训练，应以已获收益的native主监督为起点、
预定弱全图辅助并固定唯一变化；本诊断没有授权或启动该训练，也不建议马上增大连接权重。
