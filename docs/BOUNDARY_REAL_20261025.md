# 真实N0热图自损伤补边

2026-10-25。用户明确授权用N0开始下一轮五轮机制短训。
本轮保留N0推理噪声，以便和[GT合成配对五轮](BOUNDARY_RESTORE_20261025.md)比较；
长期取消噪声的方向另作实验，不与本轮同时改变。

## 问题与实验边界

[同图域差检查](BOUNDARY_DOMAIN_20261025.md)发现：相同32源、相同原生区域内，
GT合成热图与N0真实热图的响应带宽、弱尾部和非零底部明显不同。
本轮改用真实N0连续热图制作配对：局部制造断口或假线，恢复目标为损伤前的原热图。
不把GT重绘为目标，不将真实峰值统一拉到1，不把真实低响应压成0。

这是损伤重建训练，不是刷新伪GT。目标自身已有的漏边、假边不会自动获得正确答案，
因此即使配对重建改善，也必须继续检查完整部署下的粘连、双线和碎块。

### 配对表示的配套变化

这不是只替换一个数组、其它像素操作完全相同的消融：旧配方还会整体衰减输入幅值、
轻微改变合成线宽，本轮取消这些操作，避免再次奖励全局抬升。
断口长度继续8–40原生像素，横向半径8–14像素以覆盖真实较宽响应，
擦低到局部可靠深内部响应的中位数，而不是强制清零。
目标本身逐值保留，断口只下降、假线只上升；未知区保留原热图作为上下文，但不损坏、不计loss。

假线延续1–4条、12–64像素长度、1–2像素线厚、0.25–0.65强度，
限定距已知边界大于16像素、原响应不高于0.2的可靠内部；不额外加入旧配方的全图稀疏斑点。
有效安全带固定使用原配置的8像素下限，不再跟随合成sigma变化。
因此本轮检验的是“匹配真实响应的配对方案”整体，而非分别证明线宽、底部或幅值哪一项的因果作用。

### 假线周围的亮斑与损失结构

固定train176的假线中心被压低，但周围出现原目标没有的亮斑。
以原输入与目标逐值相同的像素限定环带，排除低于损伤mask门槛的人工尾巴，
新模型在假线周围1–8px的MAE为0.08674（14287像素）、8–16px为0.06252（21572像素），
高于整个未损伤域约0.012。远处背景平均值会稀释这一问题，不能代替邻域检查。

按320次实际更新的分母计算，197次存在noise支持，附加noise损失的单像素系数
相对普通valid背景的p25/中位/p75为783/1120/1850倍；gap对应中位387倍。
这是分别归一的损失设计造成的系数差异，**不是实际参数梯度倍率，也不是已证实的亮斑因果贡献**。
它提示损伤像素被强烈重视，而附近新增响应只承担较弱的全域保持代价；
后续如修该问题，应先单独检验损伤邻域保持，不能直接以删小块掩盖输出误改。

固定train176这一反例中，假线中心274像素MAE由输入0.19857降至新0.09363，
但原样1–8px环带的MAE为0.13775、平均有符号变化+0.12081，

### 结论与下一步

| 分析方案 | 可以得到的结论 |
| --- | --- |
| 同真实目标交叉配对＋反向合成配对 | 表示失配确实影响补全器；新模型更适合真实N0，不是普遍更强 |
| 全32源clean分支＋原强线截面 | 幅值/宽度误改和双线大幅减少，但并非恒等或所有局部稳定 |
| 固定原读出＋小块/父区对照 | 166碎化基本消除，101仍增小块；116原漏边未真正补完 |
| 假线原样环带＋实际loss分母 | 副作用可能从损伤中心转移到周边，不能只看损伤mask或训练loss |

**本轮保留研究结果，不替换N0，不自动出包，也不原样延长训练。**
它完成了“匹配真实响应能减少副作用”的部分验证，但没有完成“更可靠地补原模型漏界”的目标。

如果继续，真实N0输入应保留；补漏边的监督要转向处理后GT中可信的正边界，
让模型得到原N0没有给出的结构答案，其它可靠原响应继续保持，未知与不可信区域ignore。
不能直接回到整图GT细线重绘，也不把训练GT内部没有标出的线一律当假线。
损伤邻域保持/分母权重风险应另作单变量检查，而不是未经验证叠加多项损失。
新训练、GT目标设计或新推理候选均未在本轮启动。
