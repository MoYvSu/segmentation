# 旧NAF窗口／方向归因与合并后复票

2026-10-31。固定研究控制C：N1局部零噪声、旧20a59 NAF、S0、原分水岭/raw语义投票和final200。
本轮只有两项独立检查，无训练、前端重算、新分水岭、150图推理、提交包或部署修改。

## 决策

1. 合并后复票在现有13例无实际类别变化，不继续扩大此项或出包。
2. 窗口融合确实压低一些点，但登记断口的最高单窗也未补通；没有发现据此优先改融合的收益。
3. 方向变化主要是同一宽响应带内的亮点/平行轨换位。直接8向概率均值大幅改变幅值分布，
   不能直接接旧.65/.45阈值，也不能由更平滑宣称更准。
4. 下一组训练候选仍选择T8＋连续N1双输入，检验补充信息；本轮没有证明B在缺口处一定有正确线索，
   也没有证明双输入能解决相位问题。本轮不启动训练，不恢复先前13例GT全图统计。

## 合并后复票：范围与identity

单图流式读原C pre200/final实例、原float32 raw概率和合并audit，不读GT数组，不加载模型。
以原pre200实例重新投票，再套已有200映射继承，要求与C全部类别exact。
之后只在真正吸收小区的target_id上按最终区域复票，其他ID逐类保持，最终PNG完全不变。
真实helper维持float32取值顺序、严格大于.5归F，等于.5归P，没有换成float64/bincount平均。

| 当前测试 | 9 | 70 | 0 | 0 |
| 历史测试 | 2 | 36 | 0 | 0 |
| 已见训练源 | 2 | 7 | 0 | 0 |

所有候选类别表与C相同，因此本批F数量、像素和逐图均面积输入也全部相同。
当前9图概率变化绝对值中位.003976、最大.057873，虽非零，但都未跨过.5。
最大变化的当前目标.936421→.878548，仍为F；历史近阈值目标.566737→.514046，仍为F。
这只否定本批投票时机的实际作用，不能推断全150图都零变化或语义不存在错误。

## NAF窗口：怎样保证与旧C同源

固定旧checkpoint文件SHA `f2b8f2dbbf445461f8e1b54b869d4a36551cf45dc90a62b13f8d8bc7c019ee8f`，
状态SHA `20a59c3971b2112c48a3b744c31f8051f5687772456cd35b5d38f0ae41b158e8`。
三张当前测试169／226／302、一张历史116；每源两个预封128ROI。
区域由既有登记位置、固定中心或格点重叠区域确定，未按本次输出选最好区域。

直接读取既有整图T8，reflect32后沿原256/stride192格点取块；保留完整batch16分组，
包括同batch中不交ROI的窗口和原实际尾批。每窗权重由完整256生成后裁到ROI，
按原float32次序累加概率与权重；不预先归一化、不换logit融合、不改变窗口次序。
只对相关batch前向，所有8个ROI都与旧C相同位置概率逐值一致。

| 阈值 | 至少一窗过阈值 | 融合后过阈值 | 被平均压到阈值下 |
| --- | ---: | ---: | ---: |
| .45 | 6541 | 6243 | 298 |
| .65 | 6079 | 5832 | 247 |

分母为8个ROI中T8线带且至少两个窗口覆盖的17822次点访问；区域可能重叠，不能当互异像素。
另设1e-6阈值缓冲并单列附近点，不将末位浮动计入稳健跨阈值。
“某窗强而均值弱”不代表该点是真晶界；少数点也可能是关键割集，不能只按总比例轻视。

实际目检：历史116登记断口中，最高单窗也没有把中央暗缺口接起来，和原C融合形态近似；
这处不支持“单窗补好后被平均抹掉”的解释。不能由此排除其它位置的融合问题或外推整个150图。

## 方向：固定同一个256裁块，而非整图重分窗

每源固定一个原窗口，保留原batch形状，对输入做先水平翻转再旋转的8种变换；
输出先逆旋转再逆翻转。坐标微型例8／8通过，4源identity再次前向也都exact。
同输入在本机重复前向一致；这里测到的是输入变换后的方向/格点依赖，不将其当作新增随机噪声或跨机器复现验证。
输入T8只规范化一次；没有因8核偶数anchor重复处理引入坐标偏移。

方向统计在4个完整256裁块的T8带内，共43125次点检查；不是上述窗口ROI的同一分母，
不计算“方向比拼接大多少倍”。7个非identity方向对原输出的带内MAE范围约.3642–.6216。
8向同点极差均值.9527–.9842，说明带内格点强弱变化很大。

图样的粗走向、分叉与大小环大致保留，亮点/平行轨换位显著；
均值更平滑，但黄色强峰铺成低幅宽带。按旧.65检查升入436、降出13657，
它改变了当前读出依赖的幅值分布。该均值只为诊断，未接入原分水岭，不声称分数会升或降。
也不能把该现象全部归因GAN、上采样或训练测试域差异；单纯改上采样/平移一致性已有历史反例。

## 内存、进程与退出核验

CPU复票：单线程，8GiB RLIMIT_AS硬限，180秒CPU/300秒墙钟，峰值RSS162.4MiB；无torch/CUDA。
