# gray4：可复现语义失败的光度困难视图

## 动机与只读诊断

gray3对同一控制仅35／8668实例改判，关键测试区域未得到广泛纠正。
额外约束在训练接受域几乎满足，不能据此认为模型已经掌握真实工况的灰度判别。
用户授权先检查训练退化能否重现失败，再短周期尝试；不继续仅放大权重。

入口`tools/probe_semantic_hard.py`使用原simple e60、冻结D5a首步及匹配编码器。
从1000训练源中按内容映射排除32人工源，固定随机抽64张，每张2次独立退化。
没有读取测试图、推断测试标签或增加留出集。目标仍是清晰原图的独立灰度规则。
对照清晰输入、原增强、附加强全局变化、附加平滑局部变化，全部经过D5a。

先验内部连通区域至少32个256网格点；它们**不是晶粒实例或人工GT**。
区域均值判别及逐点分歧用于定位机制，不是准确率或竞赛代理。
128个视图累计3,953,692个接受格点、5058个区域；均含重复源及位置。

同时原图目标仍清楚、变化后明暗区别仍可见。支持当前增强未充分覆盖某些会触发模型失败的条件，

## 本轮改变：无标签困难视图及附加梯度预算

继承`config/train/semantic_gray3.yaml`，配置`config/train/semantic_gray4.yaml`。
仍从原simple e60重新接续，**不接续gray3**，以保留同一旧控制的可比性。
全32人工GT及其输入、增强、随机顺序、学习率与1280次更新预算不变。
全1000训练源循环取样，已有GT覆盖继续排除灰度监督，不减少源池或留出验证。
Stage1／joint-v3来源、SAM2／LoRA、D5a e60首步、V affinity和最终部署契约均固定。

新增强只发生在候选额外无标签流、D5a之前：

- 先沿用原模糊／噪声及采集外观变化，再生成`a*x+b`光度候选；
  `a∈[0.25,0.60]`、`b∈[0.12,0.30]`，全局或以大尺度椭圆高斯平滑混合到局部。
- 三通道共享同一变化，不移动坐标；各位置斜率为正。若有效内容截断超过1%，
  沿原图到候选的线段回退幅度。光照场不会成为标签，目标永远从清晰原图生成。
- 抽样序号交替分配全局／局部类型，避免较难的全局变化长期排挤局部变化。
  约20%独立随机抽样只保留原视图；其余比较原视图与当前类型的两个随机候选。
- 选择时关闭语义Dropout，以各类至多4个最困难的先验区域之置信缺口评分；
  选一个视图，再恢复训练模式进行原损失反传。并列时保留先出现的视图，
  所有候选都满足时保留原视图。网络只决定训练视图难度，不重写目标或排除其不同意的位置。
- **不新增区域训练loss。** 仍使用gray3单向像素约束、0.9置信门槛、最高名义0.15系数、
  5轮渐增和20倍归一上限；额外加入下面由短测触发的梯度预算，不改变结构和推理。

首次6步GPU短测中，名义系数仅0.03时，3次活动更新的附加／GT梯度比约1.38、3.07、3.95。
旧稀疏监督的放大叠加强困难视图后，附加信号已可能压过GT。故正式前新增逐步预算：
`实际系数=min(名义系数, GT梯度范数/未加权先验梯度范数)`，零先验梯度保留名义值。
每步记录GT／先验范数、名义／实际系数、是否触发及实际比例，附加梯度范数最多等于同一步GT。
这只限制大小，不保证梯度方向与GT相同或不会伤害泛化。
因此本轮同时改变视图机制和附加梯度预算；不能将结果严格归因为单个视图选择操作。
首次短测回执保留，更新后重新短测；没有追加完整控制训练。

`data/semantic_hard.py`保存新变换、选视图及固定训练难例缩略图；
`train_semantic_consistency.py`仅在明确开启`semantic_hard.enabled`的候选分支调用。
旧配置沿用原计算路径。额外前向置于独立随机流中，不推进共同GT增强和Dropout序列。

### 选样判据比像素监督更早满足

后5轮267次实际比较多个候选，其中240次所有区域困难评分均为零，按既定并列规则回到原增强。
这解释了第20轮64次中62次选择base，而非只由20%的主动保留比例造成。
区域评分看区域内平均概率，像素loss却会处罚局部未达门槛的位置，两者的停止条件不同。

其中115次，未选择的困难视图仍比base有更多逐点类别冲突；每次多出的冲突中位数仅7格、
合计1572格，所选代表候选的最大连续块为34格。全部未选候选均无≥64格大块冲突。
因此确有“区域平均掩盖局部残差”的选样局限，但现有证据将它定位为细小残差问题，
不能据此宣称找到真实测试大块错误的主因，或盲目扩大其权重。

## 完成结论与后续建议（未启动）

当前证据支持两件事同时存在：学习率变小使更新减弱；当前合成光度任务的大块错误已大体消除，
区域级选样判据也趋于满足。不能由单条训练曲线量化两者因果占比，更不能宣称整个模型容量已饱和。
相比直接原样延长至60轮，应保留e20候选，先明确下一次实验要验证哪个问题。

若用户希望严格检验学习率影响，建议短5轮配对续训：两组从同一e20及优化器状态出发，
共同GT／无标签新序列、视图选择、损失和梯度预算完全一致，只比较固定1e-6与5e-6学习率。
这不是重训旧控制，而是新的学习率变量对照；两组都必须经历相同数量的新增更新，
不能用e20静态结果代替低学习率续训臂。观察固定合成视图和相同完整测试输出，仍不以翻转数认定准确率。
本轮只完成分析与冻结模型复测，未启动续训、修改训练实现或制作新的黑盒提交包。
