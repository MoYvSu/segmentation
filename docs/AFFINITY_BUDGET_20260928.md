本轮检查连续界面附加目标是否因为力度偏弱而学不到，而不是直接再开20轮。
入口`tools/probe_affinity_budget.py`，配置`config/experiments/affinity_budget.yaml`。

本地汇总入口`tools/analyze_affinity_budget.py`。两组各64次更新与8视图完整分区检查已完成，
未达到继续正式20轮的条件，保留已验证control；无新官方分数。

  恢复图语义仍参与几何，原图语义只负责最后实例类别复投票。

- 64步固定学习率2e-5、AdamW eps1e-4；每4步启用一次附加项，前两个8步周期预热。
  新优化器从相同空历史开始。这是小批过拟合机制检查，不是原20轮轨迹的精确续训。

`logit`分支保留附加输出梯度不超过人工BCE的25%；`parameter`分支改为附加参数梯度
不超过人工BCE参数梯度的15%，两者同受名义系数0.1及预热限制，不叠加旧输出限幅。
梯度是损失推动参数变化的方向和力度，AdamW还会按历史调整实际步长，因此另记录
合计人工／SAM2梯度、夹角、裁剪和本步真实更新。

额外AdamW作用以同一步、同一优化器历史的“本步带附加项”与“本步去掉附加项”假想更新之差衡量；
它不是两条完整训练轨迹的差，也不是官方性能比例。每步核对带附加项的预测更新与真实更新一致。

原20轮control没有重跑。短测旧预算分支用于剥离这64步共同训练的影响，否则新分支相对e20的
任何变化都可能只是继续训练的结果。两个小分支的总更新数是128，不是两次20轮。

## 起点复现预检

第一轮在任何优化前被完整分区复现断言拦住，保存到`outputs/budget_preflight/`。
原因是新缓存入口的default_collate改变了单图内存布局：原输入stride
`(3,1,3072,3)`，stack后`(3145728,1048576,1024,1)`，像素值相同。
D5a两种布局的输出像素也逐值相同，但encoder特征、语义和affinity出现差异；
例如第一个源原图实例218→219。相同恢复图改回channels_last后，各级encoder特征逐值一致，
相同布局下显式encoder／两头与完整model.forward也逐值一致。尚未定位某个底层CUDA算子。

缓存入口现复用原`native_training_maps`的单图输入布局，保留原来的计数及全部旧固定点对
复现断言，不通过放宽阈值绕过检查。此修正只作用于新短测，不改既有训练或部署。
23项局部测试通过，覆盖参数预算、AdamW更新预测、旧梯度预算与连续界面监督。
后续patch的逐张／batch对照同样要固定噪声并检查布局与完整输出，见
[原生局部输入与D5a尺度计划](AFFINITY_PATCH_PLAN_20260928.md)。

## 64步结果与判断

两组输入顺序／增强与伪几何样本逐步配对，D5a和非affinity状态逐项不变；
两份末轮小头严格保存重载通过。全部8视图均接受过附加监督，每组16个附加步骤。
包含缓存、过程图及末轮全图诊断共492.65秒，峰值显存3875.94 MiB。

| 同一4源／8视图 | 旧输出梯度预算 | 15%参数梯度预算 |
|---|---:|---:|
| 附加／人工BCE参数梯度比中位 | 6.3038% | 15.0000% |
| 同历史本步额外AdamW更新比中位 | 1.6499% | 3.4069% |
| 附加梯度／人工及SAM2合计梯度比中位 | 5.4979% | 11.7856% |
| 修复初始粘连点对 | 26／73 | 27／73 |
| 修复初始误切点对 | 15／192 | 15／192 |
| 原误切代表点变成背景 | 9 | 9 |
| 相对初始新增显著误切点对 | 4 | 4 |
| 相对初始新增核心粘连点对 | 27 | 32 |
| 固定初始所选同实例关系BCE，各视图等权均值 | 0.92939 | 0.92546 |
| 固定初始所选异实例关系BCE，各视图等权均值 | 0.83442 | 0.82902 |

对应初始固定关系BCE为同实例1.19406、异实例1.15043；两组共同训练都学到了这些目标，
新预算的额外改善很小，不能把两组共同的loss下降归给预算修改。
新预算预热两步7.5%，其余14个启用步骤均达到15%，没有被名义0.1系数上限阻挡。
参数梯度与人工BCE夹角余弦中位0.2582／0.2552；真实AdamW更新与预测更新最大绝对差
分别6.192e-8／6.190e-8。可确认力度改变实际生效，不能把效果小归于分支未训练或未加载。

但增强力度只增加1个粘连修复计数，误切修复总数不增，同时新增粘连计数更高；
所选关系loss只有小幅额外改善。这没有显示足以放行正式20轮的针对性收益。
两条分支共同修复的内容不能全归功于新的参数预算；新增与修复点对也不能简单相减为净准确率。
此短测是4张已见训练源、固定选位分区及新优化器的过拟合检查，不能证明整个方向无用或模型饱和。

额外将两组真实末轮PNG直接配对：26个粘连修复和15个误切修复是双方共同的，参数预算
独有1个粘连修复；没有只被旧预算修好的旧固定点对。以旧预算末轮完整分区作参照，参数预算
新增5个核心粘连点对、0个显著误切点对，并修复1个粘连点对。它们可能共享连接或实例，
不按独立错误数或净准确率解释。5个新增点对全部来自同一源的原图／模糊两种视图，
不能当作5个独立样本；独有修复来自另一源。完整定位保留私有`paired.json`。

**决策：不继续增权或自动启动20轮，不产出本短测的黑盒包，不替换最高分control。**
下一项优先检查原图原生patch是否减少尺度压缩造成的边界信息损失；D5a对局部放大后的
修复另设同输入对照，不能预设有效。计划已写入上述专题，尚未执行patch检查。
