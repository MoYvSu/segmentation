# 语义适配前的一次性训练／测试外观检查（2026-09-26）

## 结论与用途

检查已完成，覆盖赛方全部 1000 张训练原图、32 张人工标注图对应的源图及全部 100 张复赛测试图。
现有“合成模糊／噪声 → D5a”能改善细节覆盖，但没有覆盖真实测试图的亮度、局部对比及颜色差异。
扩大语义训练源池有价值，却不足以自动消除这些差异。下一轮应让 A/B 共同使用保持结构的外观变化，
仅让 B 额外学习无标签图的一致性；不继续增加 D5a 锐化强度，也不改变 affinity。

这里完成的是无标签外观诊断，**不是准确率评估、训练集划分或 checkpoint 选择**。
后续计划为每组 **20 轮、1280 次监督更新**，不是 60 轮；本记录不表示新训练已经启动或完成。
具体训练实现、无标签损失和运行状态由独立实验记录说明。

## 来源身份核验：人工目录发生过重编号

首次检查发现人工目录与 1000 张源图池中有同名但不同图的情况，因此停止了同名匹配。
随后对文件 SHA 进行核验：32 张人工源图均在 1000 张池中找到唯一、文件内容完全一致的来源。
这说明人工目录使用了不同编号，**不等于图像与其人工 GT 错配**；本检查没有审计 GT 内容，
不能由这一发现推导标签质量结论。

正式检查按 SHA 确认的真实池源名划分 32／968 组，拒绝缺失来源、多个匹配或多个人工名映射到同一源图。
完整“人工名 → 池源名 → SHA”记录仅保存在私有 manifest 中，本文不复制逐图信息。

## 指标与覆盖计算

所有输入保持原纵横比，统一到 1024 letterbox。有效区域随增强的翻转／旋转变化，
统计明确排除反射填充。每张图统计整图和有效内容的规则 4×4 网格，不按结果挑选区域。

- 亮度：灰度均值及 10／90 分位数。
- 整体对比：灰度标准差；局部对比：减去 sigma=8 平滑图后的均方根。
- 细纹理：原灰度与 sigma=1 平滑灰度的平均绝对差。
- 梯度：sigma=1 平滑后梯度均方根，并给出除以灰度标准差的归一版本。
- 模糊尺度代理：sigma=4 与 sigma=1 平滑后的梯度均方根之比。
  数值较大通常意味着更平滑，但仍受晶粒和纹理尺度影响，不是光学模糊真值。
- 颜色差异：每个像素 RGB 最大与最小通道之差的平均值；另记录接近黑／白截断的比例。

每项输出 5／25／50／75／95 分位数。单项包络覆盖表示测试行落在参考组 5–95% 范围内的比例。
多变量最近邻使用亮度均值、整体对比、局部对比、细纹理、归一梯度、模糊尺度比、颜色差异七项；
先用中位数和四分位距缩放，再计算均方根距离。

**人工 32 与全部 1000 的比较共用同一“全部 1000、相同变体、相同统计尺度”的中心、四分位距和距离阈值。**
阈值取全训练池内部跨源图最近邻距离的 95 分位数；计算阈值时，同一源图的全部网格均排除，
避免把相邻块当成独立来源。这里只排除距离计算中的同源候选，没有划走训练数据。
各变体仍有各自的尺度，不能把不同变体的距离直接视为同一绝对量尺。

## 完成结果

本次抽样得到 795 张 blur、205 张 identity，其中 392 张采用空间模糊。
配置中的 profile 概率为 `[0.2, 0.8, 0, 0]`：虽然配置保留 gamma、exposure、channel_gain 字段，
当前选中的 identity／blur 分支不执行这些光照和颜色操作。噪声使用原有概率 0.5、sigma `[0, 0.006]`。

以下数值为“逐图统计量”的中位数，括号内为跨图 5–95% 范围；亮度和整体对比换算为 0–255 单位。

| 输入域 | 亮度均值 | 整体对比 |
| --- | ---: | ---: |
| 32 人工源原图 | 196.71（155.83–218.89） | 60.04（30.25–80.67） |
| 全 1000 训练原图 | 189.67（140.81–214.51） | 63.06（32.02–89.95） |
| 全 100 测试原图 | 139.05（113.57–145.71） | 32.73（25.86–47.75） |
| 全训练合成退化 → D5a | 189.82（140.82–214.65） | 62.82（31.79–89.92） |
| 真实测试 → D5a | 138.90（114.27–145.43） | 35.63（29.09–50.87） |

修复后的亮度错位基本保留。测试对比略升，仍明显低于训练合成修复图。

下表使用原始 0–1 数值或无量纲比值，同样为中位数与 5–95% 范围。

| 指标 | 测试原图 | 全训练合成退化 → D5a | 真实测试 → D5a |
| --- | ---: | ---: | ---: |
| 局部对比 | 0.03962（0.02277–0.04852） | 0.10396（0.06262–0.14823） | 0.05858（0.04444–0.07865） |
| 细纹理 | 0.00275（0.00230–0.00446） | 0.00983（0.00476–0.02096） | 0.00788（0.00538–0.01084） |
| 归一梯度 | 0.08851（0.06517–0.13848） | 0.15909（0.11858–0.18163） | 0.14588（0.11573–0.18138） |
| 模糊尺度比 | 0.66575（0.55570–0.75756） | 0.53088（0.48702–0.57479） | 0.47896（0.43889–0.50150） |
| 颜色差异 | 0.05667（0.04958–0.06659） | 0.02959（0.01936–0.05355） | 0.06019（0.05261–0.06837） |

D5a 后，全部测试图的细纹理落入训练合成修复图的单项 5–95% 包络。
但 62% 测试图的局部对比低于训练 5 分位，92% 的颜色差异高于训练 95 分位。
此外，75% 测试图的模糊尺度比低于训练 5 分位，说明修复后的细节形态未必与训练输入同域；
不能仅凭这一代理称其“过锐”或“生成了虚假边界”。

以训练合成退化 → D5a 为参考，对真实测试 → D5a 的 1600 个有效网格作比较：

| 参考源池 | 亮度单项包络覆盖 | 七项包络同时覆盖 | 最近邻距离中位数 | 落入共同距离阈值 |
| --- | ---: | ---: | ---: | ---: |
| 人工 32 | 26.06% | 0.125% | 0.67237 | 0／1600 |
| 全部 1000 | 63.31% | 2.25% | 0.52842 | 1／1600 |

共同距离阈值为 0.17469。扩池确实缩短最近邻距离并扩大亮度覆盖，但测试局部的多项外观组合
仍与训练内部距离尺度相差很大。整图层面，全部 1000 参考下也没有测试图落入对应共同距离阈值。
各组的单项 5–95% 包络随分布形状变化，不保证样本增加时每一项包络覆盖均单调上升。

## 对下一轮语义实验的约束

1. 保留 D5a、SAM2／LoRA、既有 affinity 及 Stage1／joint-v3 来源；本轮只处理语义。
2. A/B 从同一当前 simple 权重继续训练，两组监督样本、顺序、退化、外观变化和监督更新预算保持相同。
   在 D5a 前共同加入保持结构的亮度、对比及轻微 RGB 变化，覆盖完整“外观变化 → 修复 → 分类”路径。
   不按测试逐图结果配置增强，不强行拉齐整图直方图。
3. B 额外使用全训练池中其余允许图像的无标签一致性；弱视图提供较可信预测，较强视图学习保持分类。
   不可靠区域不强迫学习。A 不加该无标签损失，才能区分扩大语义样本覆盖的收益。
4. 本轮计划 20 轮，每轮 32 张人工源 × 2 次抽取，即每组 1280 次监督更新。
   无标签部分的抽取与损失合并方式另行记录；这里不宣称训练已启动。
5. 保留过程缩略图和类别／置信度诊断，避免只看下降的损失；后续仍需相同最终推理链比较，
   不能根据此处外观覆盖直接晋级模型。
