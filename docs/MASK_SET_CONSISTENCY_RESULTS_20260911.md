# 30轮续训与EMA一致性：最终输出与清理结果

2026-09-11。**EMA一致性相对同预算续训有小幅收益，覆盖改善较一致，实例几何仍明显落后主线；保留e144为掩码候选，不替换E10a+G4b，也不据此直接加长训练。**

已先完成服务器清理，再核验训练和执行最终推理。数据盘从90.8%降到40.6%，释放约25.1GiB，清理后可用约29.7GiB。两组正式最优与末轮权重、原始数据、GT、当前伪标签和SSL均保留。

## 比较口径

- 两组从同一归属模型e120启动，每轮64次人工、192次固定伪标签更新，均训练30轮；配置唯一差别为一致性权重0/.2。前者是续训对照，后者使用EMA，即缓慢跟随学生参数的教师。
- 固定伪标签已共同去除9个人工图别名，保留240张；一致性使用912张在线池。只评价`train_172/351/686/872/873`，共790个GT实例。
- `train_889`曾以`train_589`进入亲本伪标签，继续排除；亲本原先按六图损失选优的历史仍保留。本轮按五图原监督验证损失选优，不用代理分数回挑epoch。
- 正式推理使用各组最优**学生**checkpoint，FP32 highest、相同1024输入/512掩码网格、等比letterbox、相同原尺寸恢复与像素竞争。类别阈值.5、掩码阈值.5、最小面积1、无重叠率淘汰。最终PNG保持原尺寸单通道uint16；unknown只在评分时屏蔽。
- 主线复用已经保存的E10a+G4b最终实例输出，按同五图重新汇总。主线与新模型使用各自encoder/LoRA和输入归一化。主线训练划分的独立性没有重新认证，因此跨架构比较是同图性能参照；一致性效果以本次两组差值判断。
- 下表为仓库完整输出代理，**不是官方黑盒83.94的口径**；本轮没有新的官方成绩。

“匹配IoU”只对匹配成功的晶粒统计重合度；“漏检计零IoU”将未匹配GT也放入分母，更能揭示漏粒。面积误差越小越好，未覆盖率只统计有GT的区域。

## 短板与局部观察

**主要差距仍在覆盖、分区完整性和实例检出。** 一致性输出中，不看类别时也只有615个几何匹配，与带类别匹配数相同；在已经能几何匹配的实例里，类别不是主要损失来源。这个结果不代表未匹配实例的类别全部正确。

珠光体匹配226/331，主线287/331；铁素体匹配389/459，主线428/459。与对照相比，一致性多出的6个匹配中5个来自铁素体，珠光体只增加1个；珠光体匹配IoU还从.8027略降到.7999。这轮没有解决珠光体检出的明显差距。

少于50个原生像素的小实例由35减到25；没有任何预测区域覆盖其10%的GT由37减到33；被多个GT共同作为最大覆盖区域的预测数量由89减到84。但按既有10%占比规则统计，拆分GT由132增到134、混合预测由258增到264，不能宣称拓扑全面改善。这些几何诊断与正式指标里的同类别split/merge定义不同。

原始候选掩码仍存在重叠。已覆盖区域平均同时被多少个候选掩码覆盖，从1.441升到1.469；这不是“46.9%像素重叠”。最终PNG仍每像素只有一个ID，原始重叠和最终互斥是两个不同层面，EMA没有直接消除重复候选。

当前读出还确认了两个具体事实：

- 五张图的一致性模型有252～256个query通过类别门槛，256个候选槽位几乎全部被判为某种相类，最后实际留下201～220个实例。单凭这个现象不能断定no-object分支是首因，但“多余候选如何退出”值得与覆盖一起检查；贸然增强空对象惩罚可能同时损失召回。
- 所有被拒绝候选的已分配面积均为0。因为最小面积为1且不做重叠率淘汰，厚空隙并非面积后筛选删除的像素；它们在**符合类别条件的候选掩码达到.5阈值后的覆盖集合**中已经缺失。现有诊断还不能把每处空缺进一步归因于类别门槛还是掩码概率。

固定局部沿用先前预选的172与873坐标，没有裁块重新推理，也没有重挑有利位置。172仍可见厚空隙、细带和局部错误分区；873的部分空缺缩小，但细小内部轮廓仍在。172这个局部主线也有合并错误，新结构有分出其中部分区域的能力；全图统计仍明显有利于主线。

## 训练与一致性是否实际生效

两组均完整训练30轮、7680次监督更新。每个checkpoint中的148个解码器参数、96个LoRA参数均相对亲本改变，优化器步数与epoch一致；EMA参数有限且区别于学生。10个相关运行文件与正式启动源码快照一致，严格加载学生模型后完成10张原尺寸输出，未发现此前“部分模块未训练”一类问题。

| 项目 | 续训对照 | EMA一致性 |
|---|---:|---:|
| 任务开始→结束 | 09:32→10:07 | 10:07→10:57 |
| 平均每轮耗时 | 70.3秒 | 98.1秒 |
| 损失最优epoch | 143（续训第23轮） | 144（续训第24轮） |
| 最低五图监督验证损失 | 3.286323 | 3.250779 |
| e150末轮验证损失 | 3.331089 | 3.288815 |

两组初始五图损失均为3.348179。首五轮到末五轮，一致性组平均验证损失从3.3406降到3.2974，对照从3.3396到3.3337。收益不只表现为某一次最低点，不过后期有波动，不能把曲线当作继续延长必然获益的证据。

在线一致性实际读取1920次、覆盖全部912张图，EMA更新7680次。筛选后平均每图73.4个实例，约50.6%的非padding内容像素接受有效一致性监督；其余不稳定区域保持ignore。前五轮到末五轮的一致性损失均值从.3074降到.2472。新增耗时约14分钟，学生部署不增加EMA模型或额外前向。

因此这轮确实把无标签数据用于了实例任务头与LoRA的训练，已经超出“仅SSL预训练使用无标签图”的范围；固定主线伪标签仍如实记录为模型生成标签。

![训练曲线](../output/20260911_consistency_results/training_curves.png)

较可信的解释是：当前一致性主要稳固教师已能稳定预测的区域；三视图筛选保护了伪目标质量，也让约一半像素缺少在线监督。教师本身缓慢跟随学生，难以凭空补出两者始终遗漏的实例。这与“小幅扩大覆盖、仍保留大部分结构错误”的结果相符，尚未通过单独消融证明是收益有限的首因。

## 后续判断

1. **保持E10a+G4b部署主线，保留e144作为当前掩码候选。** e144几何和覆盖较对照有正向证据，仍没有主线级最终输出。
2. **EMA可保留为第四阶段，但目前不扩大轮数或一致性权重。** 无标签接入已经工作，继续接入更多同类机制不是当前最有证据的投入方向。
3. **下一次改动优先对准已知区域的完整覆盖与多余实例退出。** 先用固定权重区分掩码概率不足、类别门槛和重复候选；再决定是否调整现有BCE/Dice、归属目标或no-object监督，使训练奖励和最终互斥输出更一致。unknown继续ignore，不能用全图强制覆盖掩盖漏检或捏造标签，也不能凭本次观察保证某个新损失有效。

本轮说明当前这一版一致性方案的提升有限，没有证明Mask2Former式结构的上限。没有启动新的训练、阈值扫描、全测试集推理或官方提交。
