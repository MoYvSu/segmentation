## 原生1024：对齐参照后看训练方向

| 相同参照 | 接续训练上一组 | 随机重训本组 |

| 相对同路径旧头U0的像素翻转 | 0.757242% | 0.720546% |
| C→候选稳定对应中的F→P / P→F | 69 / 13（1166对） | 47 / 51（1162对） |
| U0→候选稳定对应中的F→P / P→F | 59 / 13（1169对） | 41 / 46（1164对） |

这些稳定集合要求旧/新相互覆盖至少90%，每组集合不同，不能只比较翻类个数当准确率。
本轮C→原生：F→P 142,639像素，P→F 62,511像素，合205,150；
背景进出65,491/66,041另计。名单外旧59/新57、旧31个主要被较大对象接管另列。
同路径U0→本轮则为98,027个F→P像素、120,028个P→F像素，更能体现训练增量的双向变化。

同时，同路径旧头的小F预测（面积<500像素）从27增至53；原C为22。
这可以来自小区类别变化或划分变化，不能仅因总F数接近原C就认定更准确，也不等同于新增真实小晶粒。
