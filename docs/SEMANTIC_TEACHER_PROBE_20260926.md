# 原图语义教师可用性检查

用户本轮仅授权方案第一步：检验原图域S-align能否为D5a后的simple提供可靠的新语义信息。
不启动蒸馏训练，不检查或改造affinity，不创建留出集，不读取测试图。

## 数据及对照口径

全部32张人工源使用与simple训练完全相同的补缝GT，仍保留所有图参与后续训练。
通过文件内容SHA核验其在1000图训练池中的身份，再排除这32源，从余下968源中
用seed=20260928均匀无放回抽取64张。选择不读取模型预测，不按测试图或诊断结果选样。

每源检查三个弱视图：原图、`0.98*RGB+0.01`的小幅对比变化、水平镜像后将输出复原。
该光度变换无截断；避免旧随机偏移在截断预算下回退为恒等却被误认为通过稳定性检查。
自身教师对照接受同样三视图原则：D5a清晰输入、弱输入经同种子D5a、镜像D5a清晰输入。
这是预先固定的诊断口径，不是上轮随机偏移可靠掩码的精确重放。

原S-align与simple原生输出分辨率不同。可靠域在256学生网格上比较：
先对各自logits做sigmoid，教师较大网格的概率再面积平均；不平均logits。
所有弱视图均置信度≥0.9、同类、概率跨度≤0.05，且按类别向内收缩一个格点后才接受。
有效内容以面积下采样全为有效才保留，reflect padding排除。

学生另读取两次独立的在线模糊／噪声／D5a前外观增强，再经D5a。
沿用当前退化参数和50%外观施加概率，不为增加分歧故意加大退化。
增强的翻转／旋转严格逆变换回原朝向，保证教师、学生与GT同坐标。

分别报告：

1. 各教师可靠覆盖、两类覆盖、弱视图稳定程度。
2. 可靠域内教师／学生的概率差、类别分歧、概率差>0.1的比例。
3. 两教师各自可靠域和共同可靠域两套统计，避免掩码不同导致不公平比较。
4. 人工图中“教师正确而学生错误”“教师错误而学生正确”，未知或混类网格不作GT。
5. 固定原尺寸GT实例，使用部署相同的float32概率均值、严格>0.5投票；
   这只是训练内分类诊断，不运行分水岭、实例匹配或竞赛面积代理。

64图没有GT，只能判断稳定性和差异，不能称其为纠错。
32图本身已参与训练，已知GT上的高准确率不能证明测试泛化。
高置信和多视图自洽也不是标签正确的保证。

| 输入／模型 | 错误实例数 |

| simple，清晰输入经D5a | 1 |

该结果说明权重可用、常见训练实例的分类接近满分；这些图已参与过训练，
不能据此判断真实工况或测试图上的教师更准确。整实例均值正确也不保证其全部像素正确。

在两教师**共同接受**的人工图网格上，已知GT格点为1,089,070个，两教师有同样的3个错点。
第1／第2次退化中，两者均提供1／978次“教师对、学生错”的类别信号，
均为0次“教师错、学生对”；改变教师没有新增的类别纠错。

原图教师独自接受的已知GT网格只有8,822个：

| 原图教师独有区域 | 教师对、学生错 | 教师错、学生对 |
| --- | ---: | ---: |
| 第1次退化 | 5 | 84 |
| 第2次退化 | 27 | 98 |

这是格点／退化视图次数，不是独立实例数，也不是实际训练后的纠错或伤害。
至少在这些已知区域，额外目标中错误方向多于正确方向，不支持因覆盖增加就放宽接收。

## 64张其他训练图：新增信息量

两教师分别按相同标准筛选可靠区域，再取交集；交集**没有要求两教师类别相同**。
因此下面的零分歧来自实际预测，不是筛选条件预先强制的。

| 统计项 | 原图S-align教师 | simple自身教师 |
| --- | ---: | ---: |
| 可靠区域覆盖有效内容 | 69.16% | 74.53% |
| 相对另一教师独有覆盖 | 0.65% | 6.02% |
| 各自可靠区，两次退化平均概率差 | 0.001334 | 0.001362 |
| 各自可靠区，两次退化平均类别分歧 | 0.0934% | 0.1015% |

各自可靠区范围不同，后两行不能当作同像素准确率比较。公平的共同区域统计如下：

- 共同接受2,144,130个256网格点，两教师**类别分歧为0**；平均概率差仅0.000143。
- 与第1／第2次退化学生相比，两教师各有相同的2,517／1,381个类别分歧。
- 原图教师独有区域为20,232格点；两次退化分别增加47／97个类别分歧，
  没有GT，不能称为纠错。
- 原图教师与强视图学生的4,042次分歧中，96.14%集中在5张源图；
  26／64图出现至少一次分歧。困难样本信号存在，但不是更换教师带来的新类别知识。

32张人工图的共同可靠区域同样零类别分歧，平均教师概率差0.000126。
可靠筛选会排除边缘和含糊区域，因此结论限于当前保守监督方案；
不能推出被排除区域没有信息，也不能未经检查直接降低置信门槛。
