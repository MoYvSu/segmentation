# 有标签源图的光照鲁棒性诊断

## 结论与下一步

完整32图、5126个固定GT实例（珠光体1934、铁素体3192）已完成，耗时1046秒。
本轮未发现足以支撑立即追加光照增强训练的实例分类脆弱性。保留诊断工具；
训练代码与配方保持原样，未启动新训练，也未更换部署模型。
这不排除测试分布上的光照作用：所有源图都参与过训练，而且本轮使用正确GT区域投票，
不包含实际预测实例合并、切碎或边界偏移的影响。

原语义头仅局部+0.10在两个输入条件各新增1错，其它条件无新增实例错误。
A/B全部条件的核心投票均为100%正确；核心保留5126实例、排除0个。
说明这次观测到的少数整实例投票错误对边缘区域的纳入敏感，不能解释为普遍的内部分类失败。
实例BCE没有一致恶化；图等权准确率变化的bootstrap区间均包含0。

像素预测仍有轻微反应：A/B局部调光使原尺寸GT像素mIoU下降约0.035–0.069个百分点，
全局偏移的下降约0.0004–0.039个百分点；部分按图像素准确率变化区间不跨0。
因此结论不是“光照完全无影响”，而是“本轮影响很小，没有触发大量实例分类错误”。
这些像素指标和上面的实例准确率均不是官方mIoU或面积得分。

必须保留截断限制：训练图较亮，原图条件下+0.10造成的像素截断比例逐图中位数为30.76%，
局部负/正场为18.27%／6.11%；不能将它们描述为纯亮度平移。
相对干净的−0.10有12张整图零截断、2071实例，A/B零新增错误；模糊条件为13张、2204实例，
A零新增零纠正，B零新增纠正2个。无截断子集仍未给出支持追加光照训练的证据。

下一步优先在有标签源上固定**实际预测实例**、对照GT检查混类与边缘投票；
随后分别检验局部对比度压缩与模糊的叠加。前者检验GT理想区域掩盖的部署问题，
后者检验简单亮度平移没有覆盖的外观差异。上述是后续建议，本轮未执行。

## 对照范围

沿用 `config/train/semantic_d5a.yaml` 的全部32张人工训练源与现有补缝GT，不留出验证集，
不制作测试GT。对原S-align语义头、A完整头e60、B随机初始化简化头e60分别诊断。
三组SAM2/LoRA/affinity状态逐项摘要相同后，仅共享encoder前向；不运行affinity或分水岭。

每张源图有两个输入条件：原图→D5a首步，以及固定种子的既有模糊/噪声配方→D5a首步。
后一条件将退化profile条件化为100% blur，其空间/端点/重采样/噪声参数不变；
不能把它当作原训练配方的无条件平均。逆转退化包装器的翻转旋转后，逐点断言GT朝向一致。
每个图/条件只运行一次D5a，各光照变体和语义头共享该输入；两输入条件使用相同D5a种子。

光照全部施加在D5a之后、encoder及语义头之前，共7个条件：零扰动、RGB统一偏移±0.10、
平滑横向局部偏移±0.10、亮度gamma=0.8/1.25。0.10相当于8位像素的25.5级；
局部场为有效区域内从+1到−1的余弦，并延续reflect padding。全局偏移在未截断时保留
RGB通道差与局部对比；gamma也改变对比，作为辅助诊断。零扰动必须与原tensor完全一致。

logits按部署规则恢复至GT原尺寸，在CPU作sigmoid；固定GT实例内float32概率均值严格大于
0.5判铁素体，否则珠光体。未知像素不计，所有实例均纳入主统计。附加统计将实例腐蚀
3个模型像素的原尺寸等效距离，核心不足12原尺寸像素的实例单列排除，主统计不删除。
另检查无截断核心与整图零截断子集；全局注意力可受其它区域截断影响，不能仅凭核心
未截断就宣称排除全部截断混杂。

主报告使用实例等权准确率、两类平均召回、原本正确→错误、原本错误→正确及净错误数。
像素混淆矩阵与BCE为辅助。置信区间按32张源图重采样1000次，描述**图等权准确率差**，
不是实例汇总准确率差的置信区间，也不是对新数据泛化的保证。
