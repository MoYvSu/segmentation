# 旧/双输入NAF的高阈值缓存2×2检查

2026-10-31。对应[双输入终态](NAF_DUAL_ANALYSIS_20261031.md)提出的有限读出适配检查。
本轮完成旧20a59／双输入776f各自高阈值.65/.75的四格对照，不训练、不加载模型、
不运行NAF或上游前向、不跑150图。旧/新.65结果直接复用，仅增加两套.75的缓存读出。

## 决策

保留旧20a59＋S0＋原.65读出＋final200。
不优先为旧.75或双输入.75出包，也不继续盲升这个阈值。
双输入的部分微环受阈值影响，但升至.75同时合并了较大的F区域，
尚未把其输出变成兼顾保线与去环的候选。保留权重和记录，不因这次结果宣称所有阈值均无效。

## 分隔保留与目检

以各模型.65实际高阈值骨架作为参照，检查.75骨架在其r2方形邻域是否仍有点：
当前4图旧模型保留95.87%，双输入89.84%。这是无标签骨架保留代理，
被删点包含微环和侧轨，不能将其全部叫作真界漏检。
原N1弱组的骨架参考点在部分图仅几十个，报告保留原计数，不能单独用比例放大结论。

按每侧>=32像素且>=各自区域5%的空间交集判断实质拆/并，
旧模型相对.65为拆14／并22，双输入为拆85／并126。
此为分区重排诊断，既可能包括纠错也可能退化；没有把重编号当成几何变化。

六源沿用上一轮已保存的ROI，不按本轮阈值结果重挑；后验最大变化ROI明确标记为上一轮选择。

- 169预封细通路：主要分隔在四格中仍保留，小环没有系统消失。
- 116预封断口：四格都未形成有效实例分隔。
- 226上一轮后验ROI：双输入.75中央一段竖分隔消失，两侧区域并成更大连片；旧模型变化小。

## 本次试验回答了什么

新模型的阈值反应明显强于旧模型：marker孔的高阈值效应旧+5、新−117，
差异为−122；F数量效应旧−2、新−39，差异为−37。
因此新输出存在额外阈值敏感性，部分微环确由较弱响应参与形成。
但.75只压掉部分微环，同时带来明显分隔合并，不支持本次简单抬高阈值即可解决输出形态问题。
这不是“所有读出都无效”或“连续信息没有价值”的证明。

比赛主线维持旧.65。当前不再为这一高阈值密扫，也不以这两组结果消耗黑盒机会。
双输入权重保留用于后续研究；剩余赛程优先返回已规划的原生768视野独立对照，
固定旧最高分权重/读出，避免同时叠加新模型和新尺度。该尺度试验本轮未启动。
