# 真实热图上的GT正边界纠错研究

2026-10-25。承接[真实N0自损伤补边分析](BOUNDARY_REAL_20261025.md)。
当前目标是寻找能纠正原N0遗漏、又不把偏移GT画成平行线的监督；
用户授权继续研究至否决、正式开始训练或达到预期中的一项。

## 保持项与候选定义

仍固定N0、原语义与完整部署读出，只研究单通道补边器；只读取已授权的32张处理后训练GT。
GT内部没标出的线不作为负类，不改GT文件，不制作测试GT，不用测试图选择目标或阈值。
仅正向增补目标，不直接删除旧响应；新GT支持并不等于无条件正确。

在GT非分叉路径上，用半径4原生像素内的N0最大响应进行位置容忍匹配：

- 连续8–64像素的低响应段（局部最大<0.45），前后各16像素内均需有≥0.65的匹配强锚点。
- 沿整条短段逐点检查法向外侧5–12像素；若已有≥0.45响应，拒绝可能的偏移/重复补线。
- 只在通过的短段附近增加sigma3、峰值0.90、截断3sigma的软带。
- 既有N0≥0.65像素和允许域以外逐值保持，未知不改；目标不是全图GT理想细线。

逐点守卫来自明确反例修复：只看段中点会漏掉仅在端部出现的偏移旧线，产生两个亮峰。
真实训练源003也出现GT中心约0.093、半径4法向最高约0.298，
法向+10像素却已有0.939响应的情况；不能为了产生训练样本关闭偏移拒绝。

## 第一版：原始覆盖严格支持域

全部32源，先按原始标注覆盖联合域侵蚀8像素，只允许其中的正边界。
源图/N0/处理后GT/类别按已核manifest和内容SHA匹配，没有按文件同名跨目录拼接。
预先固定弱像素排名源与均匀索引源的展示规则，未按测试结果挑图。

| 筛选步骤 | 数量 | 结论 |
| --- | ---: | --- |
| processed-known可靠骨架 | 1280006像素 | 79.66%的边界中心来自filled |
| 原始覆盖侵蚀8像素后的骨架 | 80180像素，保留6.26% | 原图像素覆盖高，不代表边界监督保留高 |
| 半径4匹配仍低响应 | 4185像素，5.22% | 不等于物理漏界 |
| 连续弱段 | 236段 | 长度不符122段，双端锚不符96段 |
| 长度与锚点通过 | 18段 | 全部被整段偏移守卫拒绝，其中4段仅看中点会漏报 |
| 最终候选 | 0段、0源 | 无新增监督，不能启动有意义的本配方训练 |

所有第一版目标都逐值等于N0，连通分隔探针有效分母为0，不能称补边已有效。
该结果否决的是这版支持域设计，不能用人为排空监督否定GT纠错路线。
001/623等固定区域中，可见晶界被原始覆盖侵蚀整条排除，支持域与标签形成方式不匹配。

## 第二版：按来源约束窄填补区

不降低响应阈值、双端锚、长度或偏移守卫；只重审处理后GT的支持来源。
显式策略为`processed_thin_fill`：

- 监督有效域是processed-known联合域侵蚀8像素，不逐实例侵蚀。
- 原始覆盖自动支持；filled只在距最近原始覆盖≤4像素，且最近原始位置的实例ID与自身一致时支持。
- 已知—已知交界的两端都要受支持；远填补或来源ID不一致不加入。
- 写目标仅在上述支持域；检查已有偏移线则观察整个known-safe中的N0，不能因未支持filled而看漏旧线。

4像素对应原有GT/模型位置容忍范围，不从测试集拟合。这仍是处理后GT的推导信号，
不能改称新的人工标注或完全正确真值。第二版结果另存，不覆盖第一版冻结证据。

## 构造器与可重复性

入口`data/boundary_correct.py`，测试`tests/test_boundary_correct_data.py`。
构造器只生成候选，不调用模型或执行训练，绑定数组形状/类型/SHA和完整配方。
发现OpenCV precise距离计算在重复调用时有微小舍入漂移，导致目标SHA不同，
已改用SciPy float64距离，不修改调用者线程设置，不放宽哈希检查。
直线/斜线在OpenCV线程1/2/4各重复三次，目标与记录逐值一致；含薄填补反例的21项CPU测试通过。
旧冻结候选仍保留来源身份，最终产物必须记录实际执行源码版本。

## 开训前必须核实

候选应有实际新增正监督和合理空间分布，目检不得明显重画现有偏移线。
报告实际训练裁窗对自然修复的曝光率、有效分母，不能让新监督被稀疏随机采样淹没。
同一源所有增强必须使用同一个固定纠正目标T*，不能在gap补线、clean/noise又监督回N0。
无人工损伤输入不等于identity；identity仅在有效区input与target逐值相同且无损伤时成立。
自然repair与人工gap分别记账，pristine采用精确`input==target`，不拿阈值mask的补集替代。

若进入训练，继续随机初始化、相同小网络、五轮/320更新、有效batch4、20轮LR日程，
复用已有真实N0自损伤e5控制，保存e0/e1/e3/e5固定缩略图和完整续训状态。
新目标/采样若发生变化必须明示；以下检查最终不支持开训，没有启动新的正式训练。

私有根目录为`output/boundary_correct/`及服务器同名run；所有图像、GT、目标与checkpoint均不进Git。

`243e23d0363762c994daea6e41313f68bca6da9f8afd42eb01bd152052b2b547`、
`7330e412644eb47f84afa4f78c93732b712143b89bbd14c422e3ab5ccaf66461`。

| 检查方案 | 实际结果 | 能得出的结论 |
| --- | --- | --- |
| 原始覆盖严格支持 | 18段通过长度/双端锚，全部被偏移检查拒绝；最终0段 | 严格支持域本身过窄，不能单凭0候选否决GT路线 |
| 薄填补支持 | 骨架521137像素；595弱段→61段通过长度/锚→57段偏移拒绝→4段，来自4源 | 扩大支持确实恢复候选，但新增短正监督仍极少 |
| 固定纠正目标的分隔检查 | 3个有效两侧探针均仍连通；另一探针两点属同GT实例，不计分母 | 未展示完整分隔收益；不等于这3段局部增补必然错误 |

薄填补4段来自171、558、875、889，共120个中心像素、1780个实际修改像素；
相对147457310个known-safe有效像素，仅0.001207%。类别探针有效的3段为P/P一段、F/F两段。
这只是新增目标的密度，不是新监督的准确率，也不说明原有监督只有这个覆盖率。

4段192像素细节图已全部目检：部分新增核心看起来像悬空短线或局部弯折，
但缩略图观感不能替代阈值连通。修正检查把120个缺段中心点逐一映射到T*≥0.45分量，
4段中心全部属于两实际锚点所在网络；实际锚非同一像素，间距28.60/41.05/33.29/38.47像素。
不过558/875/889两端原本就已在局部连通，单端附接旧网络也可满足“同分量”，
不能称4次新增双端补通。只有171原两锚局部断开→相连，该段又是P/P，且全图两侧仍可绕行。
这既不证明双端独立接合，也不证明候选分割收益；558两侧探针属同GT实例，不计全局分隔分母。

局部锚点检查发现的统计陷阱：若用所有`target>input`像素的连通分量，
原有高响应边缘被Gaussian轻微抬升的外围也可能计入，不能据其触锚宣称补线核心已经接好。
原`local_links.json`保留，方法结论已由`local_core_corrected.json`明确废止和更正；
即使更正后的核心同分量成立，也须与“原本已连通”和最终两侧分开区分。
这些是候选目标的机制检查，不是模型训练收益。

processed-known全部1280006个GT骨架像素中，半径4匹配有1265954个（98.902%）N0响应≥0.65，
8925个（0.697%）<0.45。这32源已经参加过后端训练；高匹配率不能当测试准确率，
但说明在这些源上，很难通过再找短低响应段为冻结N0提供大量新的正答案。
目检同时可见GT遗漏的弱界，不能把未标出的内部响应一律当假线。

processed-known对照只用于解释来源限制：不把大块filled自动认作可信原标，不纳入训练。
它也不是候选数量的数学上限：支持域变化会改变路径分段及长度，不保证计数单调。
薄填补summary累计字段`thin_fill_max_native_distance=128`是将32源参数4错误相加；
实际配置及每源记录均为4像素。该累计项无半径语义，不能解释为放宽到128像素，
保留原回执并用补充说明纠正，不静默覆盖已执行证据。

**决策：否决当前“真实N0＋GT短正缺段纠错”的五轮配方，不开新训练。**
依据是可信新增监督少、监督源已被后端见过、候选又尚未展示完整分隔作用，
而非认为GT或所有补边方法无效。重复裁这几段不能增加独立信息；放开偏移检查凑样本
会重新引入已观察到的平行线风险。

结合两轮已完成训练，当前单通道热图补边器也不晋级部署：合成版能补缺口但有明显双线/碎化，
真实自损伤版大幅减少副作用却未补完116原漏界。继续原样加epoch或第三次近似同目标训练，
没有足够依据。N0、语义、上游和正式读出不改，保留两版checkpoint与全部诊断供回退复用。

如果未来重启该方向，应先获得不同的信息：例如只在允许训练图上，比较
`N0(退化RGB)`与`N0(原RGB)`的真实响应配对，或研究有图像上下文的后端改进。
RGB退化配对仍只能恢复清晰输入下教师看见的边界，不能自动纠正教师原有漏界；
这是候选后续方向，本轮没有启动、没有预先认定有效。
