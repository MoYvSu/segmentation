## DINO方案：只训练新的末端语义

配置`config/train/semantic_dino.yaml`沿现有`_base`继承语义损失。
官方DINOv3 ViT-B/16永久eval/frozen，取第3/6/9/12层的归一化特征，
每层独立1×1投影，再由两层轻量卷积和分类层输出F概率。
语义头随机初始化，不加载任务预训练分割头，不增加直接RGB残差修正分支。
输入原图RGB按DINO官方ImageNet均值/标准差处理；原SAM2输入规范不改。

| 固定项 | 实施方式 |
| --- | --- |
| 处理后新GT | 32人工源，原图/NPZ/类别JSON逐文件与既有处理链SHA一致；不使用原LabelMe即时重建或教师伪类别 |
| 监督区域 | 处理后已知域含合法补缝；剩余unknown及letterbox padding为-1，不参与语义损失 |
| 几何与控制 | 复用原N0三图PNG/类别，不重训控制；monitor最终类图仅重新做实例内概率均值投票，PNG/ID不变 |
| 其他部署 | 原encoder/LoRA、affinity、D5a、全图几何语义、融合/后处理均不更新；DINO训练无需加载它们 |
| 参数量 | DINO骨干85,669,632＋新头381,505＝86,051,137；与原N0合计171,002,182，低于500M |

这是新实际方案的对照，结构、初始化和采样也有差异，不称单一骨干消融。
DINO的64×64原生特征格不是高分辨率晶界，类别更好也不会自动拆开固定实例中的粘连。

## 五轮预算与过程图

- 每轮32源各8视图，共256视图：整图128、原生1024裁块128，在线翻转/90°旋转；不新增光度配方。
- microbatch2、累积2次，有效batch4；每轮64次优化更新，五轮320次，共1280训练视图。
- 只优化随机头，AdamW LR`1e-3`、weight decay`1e-4`、梯度裁剪1；余弦日程预设20轮，程序先停5轮。
- 保留原有pixel BCE＋Dice＋instance/core/pool语义损失和权重；不把短训五轮当作收敛证明。
- checkpoint保留头、optimizer、RNG、骨干身份、数据/源码/控制摘要和采样日程，严格重载/恢复。
- e0/e1/e3/e5固定缩略图：六训练源展示RGB/处理后GT/概率/类别；三旧测试图展示RGB/N0/DINO概率/同PNG新类别。
- 训练图monitor参与过训练，不能当留出验证；测试只无标签观察，不进入loss、采样、选epoch或伪GT。
- monitor在eval/no_grad下运行并保存恢复随机流；中断残留目录先保留，再重绘，避免阻断续训。

不划出新的验证集，不自动做100/150图推理或提交包；阶段比较固定使用e5。
