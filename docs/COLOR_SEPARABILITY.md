# 铁素体 / 珠光体颜色可分性分析

更新时间：2026-08-21

这是一项基于赛方允许的有标签训练数据进行的 GT 引导统计分析，目的是判断颜色先验能否作为语义分支的辅助信息。它不是测试集标注，也没有使用测试集真实标签。

## 数据与方法

- 数据：`data/raw/` 中 32 张带 LabelMe 标注的训练图。
- 标签约定：`1 = ferrite / 铁素体`，`0 = pearlite / 珠光体`。
- 每类从 GT 区域随机采样最多 12000 像素，固定 seed=`20260821`。
- 主统计先对 GT 区域腐蚀 2 像素，减少多边形边界混色；另有 `erode-radius=0` 的原始覆盖统计。
- 颜色空间：RGB、HSV、Lab。Lab 使用近似 CIE Lab 单位，其中 `L*` 表示明度。
- 判别指标：单通道最佳阈值平衡准确率、直方图重叠率、线性分类器准确率与 ROC-AUC。
- 为检验跨图泛化，额外进行了 leave-one-image-out：每次用其他 31 张图估计 `L*` 阈值，再测试被留出的图。

## 主要结果

### GT 内部区域

| 特征 / 分类器 | 结果 |
|---|---:|
| Ferrite 与 pearlite 的 Lab 均值距离 | `DeltaE ≈ 56.8` |
| Lab `L*` 均值差（ferrite - pearlite） | `+56.6` |
| Lab `L*` 直方图重叠率 | `0.017` |
| Lab `L*` 单阈值平衡准确率 | `0.9917` |
| RGB 线性分类平衡准确率 | `0.9947` |
| Lab 线性分类平衡准确率 | `0.9950` |
| Lab 线性分类 ROC-AUC | `0.9998` |

### 包含边界混色的原始 GT 区域

腐蚀半径设为 0 后，颜色可分性下降但仍然很强：

- Lab `L*` 单阈值平衡准确率：`0.9846`
- Lab 线性分类平衡准确率：`0.9889`
- Lab 线性分类 ROC-AUC：`0.9982`

### 跨图固定阈值能力

在腐蚀后的 GT 内部区域上，leave-one-image-out 的 Lab `L*` 阈值结果为：

- 平均平衡准确率：`0.9912`
- 最低：`0.9742`
- 最高：`0.9978`

包含边界混色时：

- 平均：`0.9845`
- 最低：`0.9680`
- 最高：`0.9932`

困难图主要包括 `train_557`、`train_172`、`train_175`、`train_176`、`train_872` 等。逐图最优 `L*` 阈值大约位于 `63.7~81.0`，说明存在曝光/照明差异，不能未经校准地固定一个绝对阈值。

## 颜色特征解释

颜色差异主要来自明度：

1. Lab `L*`、RGB 的 B/R/G 通道和 HSV 的 V 通道最有效；
2. HSV 饱和度有辅助作用，但稳定性明显较低；
3. Lab `a*`、`b*` 和 HSV 色相的单通道判别能力较弱。

因此当前数据中可以概括为：铁素体整体更亮、珠光体整体更暗，而不是依靠稳定的色相差异。

## 对项目的含义

这项分析证明颜色先验值得利用，但不能把它解释成“固定亮度阈值就能完成最终分割”，原因有四点：

- 统计使用了 GT 区域，属于有监督的乐观估计；
- 腐蚀后的内部像素不代表真实晶界、薄片和边界混色区域；
- `L*` 阈值在不同图像间仍会变化，受曝光和照明影响；
- 颜色阈值只回答相区分类，无法解决实例完整性、分水岭种子、嵌套环和 255 ID 上限。

当前推荐把颜色先验作为语义头的辅助信息：

- 用每张图的 Lab `L*` 双峰/自适应阈值生成软颜色先验；
- 只在图像具有足够双峰分离度时启用；
- 与语义头概率融合，不直接覆盖语义输出；
- 将颜色先验重点用于低亮度/低对比图的语义纠偏和边界 refine 输入；
- 对分水岭只提供相区置信度，不直接强制实例数或平均面积。

下一步应在无标签 holdout 和测试图上只做无 GT 的颜色先验可视化与网络输出冲突分析，再决定是否落地融合。不能使用测试集真实标签拟合阈值或训练模型。

## 给后续对话进程的接续提示

开始处理颜色、语义或数据增强问题前，请先阅读本文和 [`docs/PIPELINE.md`](PIPELINE.md)。当前可复用结论是：

- 32 张训练标注图上存在极强的 ferrite/pearlite 明度分离；
- Lab `L*` 是最简单、最稳定的颜色先验候选；
- 它应当作为软辅助或自适应后处理，不应替代语义头；
- 当前参考模型仍是 E1/V6 主线，颜色统计不能改变实例后处理的 255 上限约束；
- 后续实验必须额外使用固定无标签 monitor，不能只看 `data/raw` 上的 monitor 图判断泛化。
