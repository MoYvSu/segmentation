# 原生局部输入与D5a尺度检查计划

状态：参数梯度短测后，用户授权的冻结检查已完成；结果见[原生patch检查](AFFINITY_PATCH_20260928.md)。
下文保留运行前方案；8源48次完整分区、32对恢复及结构复测已完成，新裁块训练仍未启动。
当前参照仍为最高分control e20（0.8486／0.8761），不叠加纯分隔恢复、面积过滤或语义候选。

## 为什么值得检查

当前模型输入等比letterbox至1024，affinity为512网格。对2448像素宽的原图，横向每格约
对应4.78个原生像素；从原图裁1024方窗再输入时，每格约对应2个原生像素。细密交汇处的
窄间隙可能由此保留下来。这是取样尺度与上下文的变化，不保证已有模型能正确利用新增细节。
512方窗放至1024还能改变模型感受尺度，但插值本身不会增加观测信息。

此前`SEMANTIC_SCALE_20260927.md`在D5a处理后的1024整图中裁512，再放至1024，
只训练语义头及其独立LoRA、固定affinity；因此不能用该实验的结果否定原生局部affinity检查。

把相同patch逐张处理或合成batch，主要改变速度与显存。固定噪声、输入布局、eval状态后，
应先检查连续输出的数值差异和最终分区一致性；不能把batch组织导致的差异记为尺度收益。
本次参数短测的预检发现：同像素输入由原单图布局改为stack布局，D5a输出像素逐值相同，
encoder特征却不相同，最终实例218→219；恢复原布局后特征逐值一致。
这是当前GPU环境下的复现注意事项，未定位到某一个底层CUDA算子，不能外推所有设备。

## 最小对照顺序

1. **固定模型及最终部署。** control e20的affinity、SAM2／LoRA、D5a e60、融合配置、
   阈值与后处理均固定。原图语义概率用于最终复投票，恢复图语义用于几何处理；两套语义图
   都由原全图入口计算并复用，避免只固定最后分类却暗中改变几何阶段的语义输入。
2. **先做同patch的逐张／batch复现。** 每个patch使用可重放的独立初始噪声，不能简单地
   给整个batch重置同一个seed而改变后续patch噪声。记录dtype、完整stride、eval状态和
   连续输出最大／平均差。D5a的`q_sample`已有显式noise入口，可据此隔离随机性。
3. **比较全图与原生1024重叠局部。** 从原始分辨率裁图，保留上下文重叠，先不使用512→1024。
   在各局部内按原规则将方向affinity融合为边界概率，再映射回原图并对重叠部分加权。
   最后只进行一次全图分区。不能分别生成实例后直接拼ID，否则裁窗边缘会成为人为裂缝。
   距离1／2／4通道在不同尺度对应的物理距离不同，不直接跨尺度平均这些通道。
4. **再拆分D5a贡献。** 对相同原生局部比较插值输入与D5a首步输出；额外保留全图raw入口
   作为无D5a参照。这样区分“局部保留更多细节”“修复器对新尺度的响应”和二者交互。
   只有1024局部有迹象，再考虑512→1024。裁已缩小的D5a整图只能检查视野变化，不能冒充
   恢复原生高频信息的对照。

首轮只使用少量固定训练源及若干无标签测试图，保存全部样本和失败图，不挑选最佳patch。
训练图检查覆盖全图的最终粘连／误切，防止局部裁窗遮掉通向远处的连接；缺失标注保持ignore。
测试图只目检边界、交汇、拼接缝和实例稳定性，不编造GT、不据实例数或平均面积决定正确答案。
没有证据前不启动多尺度训练、全100图新提交或替换主线。

## D5a是否能完成放大后的修复

现有D5a是同尺寸RGB恢复器，不能直接称为超分辨率模型。其训练退化允许0.65–1.0倍
降采样后恢复，但没有因此证明2倍放大后的边界恢复可靠；局部原生纹理的频率也会改变。

单独使用允许的清晰训练原图构造已知目标：取原生清晰patch，在线施加模糊／平滑局部模糊，
再分别做训练范围内的降采样及更强的0.5倍降采样，最后插值回共同目标尺寸。
同一输入比较“插值本身”和“插值＋固定D5a首步”，保留不退化的清晰输入检查凭空造边。
每档分别报告RGB误差、梯度误差、真实边界附近响应宽度、连续性与新增假边，
不能只凭更锐利的外观判定成功。清晰源虽被D5a见过，新的退化可检查机制是否工作，
但该结果不作为独立泛化精度；仍需无标签真实工况目检及之后授权的官方比较。

D5a检查不通过，也不自动否定原生patch方案；可能需要仅调整恢复顺序／尺度适配，
或先在不加修复器的局部对照中验证affinity是否受益。相关变化必须单独比较。
