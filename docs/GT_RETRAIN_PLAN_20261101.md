## 2. “优化GT”先具体修什么

建议先在**原32训练源**建立修订清单，区分相别、实例拓扑、边界位置和未知支持域，分别解决：

1. **原标中的明确矛盾与遗漏。** 优先核同一实例混入两相、同相邻区误合/误拆、明显漏界、
   不合理的同ID多连通片及细小夹杂。原图证据不充分的地方保留不确定，不能仅因教师更整齐就改答案。
   珠光体按赛题的连续团簇口径核对，不用“全部相邻P都合并”代替逐处判断。
2. **r8补区和窄缝接口。** 原标大多在晶粒内部，filled占总像素约6.27%，却可贡献大量界面监督；
   要优先看连接两个原标对象的接口、窄零缝、补区跨界归属及原标两侧支持。
   不先整体扩大补缝半径，不把补全边当作人工精描线，也不因原标面积占比高就忽略补区。
3. **有效监督是否真的到达损失。** 逐图、逐实际尺度记录known/unknown、边界正点、内部负点及
   affinity各通道的连接/断开关系，按原标—原标、涉及filled、教师分歧分别列账。
   修正图像/GT坐标、最近邻ID变换、裁窗外端点、反射padding ignore等确定性错误，优先于盲目扩训。

修订使用新版本目录和manifest，不覆盖r8、原LabelMe、教师资产或旧回执。
每条修订保留源SHA、原/新GT SHA、改动类型、相别来源和实际复核依据；新确认记录不能伪装成原始人工标注。
几何实例ID、0P/1F类别和unknown要联动一致，语义、边界、亲和关系从同一版本派生。
unknown保持`ID=0/semantic=-1`；不能把未覆盖或teacher0直接当负边/背景，不能为采样方便补满所有区域。

本节原建议保留人工锚点，理由是已有**实际反例及边界**，而非教师未获授权。
2026-11-01用户进一步提出“当前C完整实例及类别覆盖32源＋GT依赖模块冷重训”，作为不同的新候选评估，见第6节；
不把本节原建议当成禁止该新实验的规则：

- R1同源教师属于自蒸馏。确认允许使用不等于每处物理边界已被独立证实；其相别仍是诊断输出。
- 既有A/B在共同known域保持相同ignore，教师仍使原断开关系被改连接；在原标双方的FF关系中也存在冲突。
  同64个SAM2答案的训练日志呈连接recall升、断开specificity降，不能只解释为teacher0少了一些像素。
- 窄零缝恢复已获授权并完成320步，但未带来稳定的完整分隔收益；不能把“恢复了合法关系”当“恢复了正确答案”。
- 原GT不完整，模型与其冲突不自动等于模型错；反过来，也不能用模型自洽证明GT应改成模型答案。

详见[教师来源完成分析](AFFINITY_GT_SOURCE_20261004.md)、
[零缝修补结果](AFFINITY_TEACHER_SEAMS_20261004.md)及
[NAF监督来源审计](BOUNDARY_NAF_GT_20261026.md)。旧320步affinity接续配方不原样重启，新提案另行定义。
语义标注修订与最终预测生成均不交给LLM/VLM逐图判相，不制作测试GT。

## 3. 新GT影响哪些模块，哪些旧资产可复用

| 改动 | 直接影响 | 对旧依赖的处理 |
|---|---|---|
| 仅修0/1相别，实例ID与有效域exact不变 | 语义头及语义派生目标 | affinity/NAF几何目标可经数组exact核验后复用；不能声称它们已经学习新相别 |
| 修改实例拆并、边界或known域 | affinity正负关系、NAF目标/有效域；相别汇聚也可能变 | 重建该版本的派生目标与来源账本；旧目标缓存不能只换manifest名字继续用 |
| 只更新语义头，encoder/LoRA固定 | 语义预测、WS底图和最终类别 | N1/NAF输入可保持；最终几何仍会被WS语义改变，必须比较完整部署输出 |
| 更新affinity头 | 新N1的幅值、线宽、缺口及S0参考 | 为训练源重算真实新N1缓存；旧NAF可作冻结控制，但不能默认已适配新输入分布 |
| 更新encoder/LoRA | 语义、affinity两头共同特征 | 两头都需重新适配/重训，不能直接接回依赖旧特征的冻结decoder并声称兼容 |
| 更新NAF目标或输入 | NAF、种子/防线及S0最终行为 | 重建同新GT、新N1绑定的训练缓存并完整验收；不复用旧heatmap身份冒充新链 |
| GT变化而RGB数据/恢复目标不变 | 不直接改变D5a的RGB恢复监督 | 不因“全量”二字机械重训D5a；若要从头复现整个历史模型，则另列其60轮训练与成本 |

当前NAF明确绑定旧13b3/9315产生的真实N1，配置为
`boundary_naf.real_input_manifest/real_input_models`；T8是整图阈值、细化、ellipse8后再裁256窗。
新链必须绑定实际新输入，GT不能乘到NAF输入上制造“干净预测”。
旧NAF若继续作为候选组件，要通过新输入下的完整终态对照；不是每次改语义就必需重训NAF，
也不是affinity换了权重后仍可无条件沿用它。

代码依据：`data/backend_adaptation.py:22`、`data/semantic_targets.py:27`、
`data/boundary_naf_real.py:93`、`config/train/boundary_naf_real.yaml`。
新特征或新GT均采用新checkpoint/manifest身份，严格核missing/unexpected keys，不通过宽松加载掩盖不兼容。

## 4. “全量重训”至少要区分三件事

- **全量数据训练**：所有已约定训练源参与各自任务；1000图没有相别GT，不能写成1000张语义监督。
- **分割任务重训**：重新训练语义和affinity，并处理NAF输入/目标依赖；可以明确冻结官方encoder、LoRA或D5a。
- **全链冷启动复现**：从允许的官方预训练encoder和赛方数据开始，重新构建SSL、监督上游、教师缓存、任务分支及必要恢复模块。
  这仍不等于SAM2所有参数必须解冻，也不是从零随机初始化整个基础模型。

任务FPN/decoder的冷启动仍遵守随机初始化约定，不载入SAM2原生Mask Decoder权重；
接续阶段若继承已有任务权重，需按真实来源单列，不能包装成从头训练。

已完成的`random_full_v1`只是从13b3的冻结共享特征上重置、训练6,302,010参数语义头，
20轮/2560更新；affinity、D5a、encoder/LoRA、NAF均未重训，不能当作上述全链工作的完成。
与warm-start还同时改变了学习率，不能把其表现当作“从头全量训练已无效”的证据。

当前模型的历史依赖大致为：

```text
1000训练图 + 官方SAM2 encoder
  -> LoRA重建SSL -> Stage1人工监督 -> 固定边界缓存 -> joint-v3
  -> 配套语义初始化载体/S-align语义，以及跳过V6边界阶段的V affinity
1000训练图 -> 独立D5a RGB恢复
配套共享特征 + S-align/V + D5a -> R1 mixed-balance affinity适配
实际R1/N1训练源热图 + 处理后GT -> 旧NAF训练 -> S0/WS/raw票/final200
```

这是历史依赖图，不是宣布新配方要无条件重跑每个消融组。
V已跳过独立V6几何阶段，不恢复G0/G0-long/G1/G4b等已淘汰几何串链；
S-align仍有历史语义初始化载体依赖，不能因为V跳过V6就宣称整个模型从未依赖V6。
若采用更短的新上游，须明确作为新架构/训练方案，并让共享特征及两头一起适配。

正式排程前冻结下列合同字段；本文件不擅自补学习率、轮数或启动命令：
新GT方案默认使用全32任务源且不新增留出；若目标是复现既有最高包，则保留各历史阶段真实的
split与选优规则，不能把新的全32计划写成旧模型当年的训练事实。

| 必须落定 | 最低记录 |
|---|---|

| GT版本 | 32源允许清单、原标/filled/unknown、类别、修订与确认回执SHA；64几何源及32教师分别使用与否 |

## 6. 当前C完全教师化32源＋监督链冷重训：可行性评估

2026-11-01用户新提案；**本节只评估，没有生成新GT、启动推理或训练，也未修改统一入口配方**。
按32源的实例ID和P/F类别一并替换理解；原64源SAM2无类别几何保持原清单、互斥处理与ignore规则。
训练目标可完整采用教师版本，但原人工/r8资产另存并保留作回退及分歧检查，不物理覆盖源文件。

工程上可行，应称为“C教师整套自蒸馏候选”：学生重新学习已评分老师的最终答案。
动机是获得更完整、一致的实例轮廓与类别监督；这不等于已证明教师标签比原标更正确。
随机重置移除旧任务参数及优化器历史，不能消除教师标签中的错误；同32已见源也不会成为独立验证集。

旧10月4日实验只从旧R1继续更新affinity 320步、类别不训练、共同known域ignore不变，
且教师读出不含当前NAF/S0/final200。新提案同时改变教师、类别监督、支持域和初始化，
旧结果只提供风险线索，不能直接否决本方案；若新组变化，也不能只归因为“GT更好”。
旧R1/D5a与当前13b3/9315是同源训练权重及其导出，不能因文件SHA不同就说核心网络变强；
新教师的实质区别主要是全零/N1/NAF/S0/final200完整读出。
若完全采用C答案，`teacher ID>0`可包含原GT unknown区域，应标作teacher-only监督；
不再强制与旧known取交集，反之便不是本次完整替换。teacher ID0仍保持ignore。

| 组件/资产 | 与“监督依赖从零”一致的处理 |
|---|---|
| 官方SAM2、原SSL LoRA、D5a | 可复用不依赖人工GT的初态；不可拿已监督训练的joint/R1 LoRA冒充SSL |
| Stage1/joint语义及边界FPN | 从本轮随机任务头开始，全部监督改从新32源答案派生；后续阶段接续本轮训练结果，不在每阶段重新清空 |
| V6/S-align/V affinity | 重建本轮教师/缓存/几何初始化来源，语义及几何均不复用旧监督成品 |
| R1 | 组装本轮新共享特征与双头，重新适配；SAM64仍仅训练几何 |
| NAF G/D | 从随机初态重新训练；输入来自新backend的真实零噪N1，目标来自固定C教师GT，不能拿新学生自己的预测同时充当答案 |

**当前统一入口不能只换`completed_gt_dir`就实现本方案。** Stage1/joint正常双头分支仍读取purified目标，
V训练/验证仍有原LabelMe入口；必须将新ID/class统一派生为语义、边界、affinity及NAF目标并切换全部对应读取。
原监督产出的Stage1/语义边界缓存、V6固定教师和旧NAF输入也要重建。
教师版本若没有`original_covered/filled`，应新增明确的teacher来源字段，不能伪装成原人工补缝版本。
统一入口当前绑定完整context与GT资产，不支持跨GT版本直接搬用旧完成回执；
策略上复用SSL/D5a需显式导入其权重、原配方和来源证明，不能复制或修改旧receipt假装本轮已训练。

两项需要特别处理：

1. 教师最终输出含watershed分界零像素。ID0继续ignore，不能默认为负边或按类别填满；
   必须检查nearest缩放到训练网格后剩余的same/different监督，避免无意删除大量断开关系。
2. C最终结果包含NAF/S0/200像素合并的影响。整套硬实例蒸馏会同时复制误切、漏界、整粒错类及小区合并；
   新NAF可能学习旧NAF与读出规则的痕迹。边界检查和固定训练小图只作诊断，不以自一致或低loss证明正确。

有限时间下建议只冻结一版C教师与一套预定预算，保留旧C回退，不同时加入深层SSL、改视野、
改网络或删WS语义。先做32源输出/旧标分歧与监督有效域检查，再决定是否正式启动这一组。
最终通过同一150图完整输出及官方两项评分判断是否晋级，不能以对C标签的拟合率替代效果。

方法参考：[Born Again Neural Networks](https://proceedings.mlr.press/v80/furlanello18a.html)表明同架构蒸馏可能有效，
但该结果不是本项目硬实例/类别全替换的增益证据；
[Pseudo-Labeling and Confirmation Bias](https://arxiv.org/abs/1908.02983)讨论了错误伪标签被强化的风险。
