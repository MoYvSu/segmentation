# D5a零噪声首步适配

## 问题与范围

核对到的旧实验没有证明D5a的随机推理噪声必不可少。冻结旧模型的零噪声首步仍能恢复图像，
固定四个已见训练源的均匀／空间模糊MSE分别比单次带噪低约1.10%／0.48%，
但空间条件新增强图像边缘略多，最终划分也改变，没有准确率排序证据。
详见[冻结诊断](RESTORATION_NOISE_20261007.md)。

本轮从带噪训练过的D5a e60开始，只检验短适配后能否安全取消部署首步噪声；
不能据此证明从随机初始化训练时噪声无用。暂缓affinity训练，继续优先研究恢复器。
现有双噪声一致性B保留作参照，不能因五轮阶段结果直接认定该路线无效。

| 起点 | 同部署D5a e60；新AdamW | 相同 |

| 更新目标 | 两次forward的原清晰RGB＋0.2梯度监督平均，无附加一致性 | 相同 |
| 预算与精度 | 5轮1250更新，有效batch4、micro1；BF16训练／FP32首步 | 相同 |
| 学习率 | 2e-5起，沿60轮cosine日程，5轮停止 | 相同 |

C仍抽取两份同形状随机张量并消耗相同随机流，只将实际传入q_sample的噪声置零。
每次仍执行两次forward，保持有效更新和运算顺序；模型没有Dropout或BatchNorm，
两份零噪声输出本来应相同，因此C的额外一致性权重为0，与A的实际权重相同。
已有A配置继承的0.1仅用于候选B，A实际为0；C配置显式写0，不代表删去A已有监督。

复用原A的e5、日志和过程图，不重跑控制。逐更新必须核对源图顺序、清晰／退化配对哈希、
有效域、原始随机抽样与随机状态、增强profile／mask、学习率、样本数和T16。
另记实际注入噪声哈希及最大幅值，避免把“抽了噪声”误读成“向网络输入了噪声”。
旧A文件在运行前后核对SHA；数据、模型、loss和随机实现保持原版本，
新增入口／监控依赖通过独立源码清单记录。没有测试训练、留出或分割标签输入。

## 固定恢复配对的交叉比较

精确复用四个已参与训练的源图073／125／210／970、24组清晰／退化配对和八份固定噪声。
训练视野512与原生1024分别报告，不将同四源的两套裁块视为八个独立源。
旧模型／A／B的576次带噪结果直接复用，新执行384次FP32首步，包括C的八噪声、
四模型零噪声、旧s0图册复核及六张测试无标签目检。没有新留出验证或测试GT。

核心比较固定双方都用零噪声推理，因此下面差别来自五轮训练模式，而不是推理噪声切换。
四源等权；百分比为C相对A的相对变化，百分点为保留比例的绝对变化。

还应单独区分“带噪训练权重能否直接零噪推理”和“零噪专门适配能否再提高”两个问题。
冻结A e5、只取消首步附加噪声时，原生1024均匀／空间MSE相对A八噪声平均低1.045%／0.451%，
四源逐项方向均改善；下面C零噪对A零噪才衡量专门适配的额外收益。
这里相对变化均按四源等权平均误差之比计算，不与四个逐源百分比的算术平均混用。
因此训练时使用噪声不能单独推出推理时必须注入噪声，也不能反过来推出训练噪声无价值。

但幅度小、只有四个已见训练源，不能外推官方分数。图像梯度包括内部纹理，不是晶界GT召回。
新增强图像边缘的变化方向混合：原生均匀+0.00276个百分点、空间−0.00258个百分点，

相对A带噪部署，C零噪四条件MSE分别低2.331%／1.467%／4.953%／2.498%，
这组数值包含训练与推理同时改变，不能替代上表单变量比较。
反向给C加噪时，模糊MSE比A带噪高0.60%–7.78%，像素噪声std变为A的2.25–2.87倍。
因此C的正确候选用法是明确绑定零噪声首步；仅更换旧部署的权重而仍注入随机噪声会偏离其适配状态。
零噪声的确定性和恢复准确性分别验收，不把seed波动为零当作恢复更准。

固定monitor的C零噪e3→e5均匀／端点MSE仍低1.19%／0.73%，端点RGB却高0.096%，
不能断言饱和，也没有证据预设继续训练必有大收益。第5轮实际LR为1.9803e-5，
末态保存的下一轮LR为1.9693e-5。

## 阶段结论与下一步

1. **当前首步部署尚无证据必须保留随机噪声。** 相同零噪推理下，C比A的固定配对恢复略好，
   支持取消随机输入作为候选方向；旧D5a本身仍来自带噪预训练，不能推广成所有扩散训练无需噪声。
2. **恢复有小幅一致收益，最终竞赛收益未确认。** 四源均参加过训练，六测试源没有标签，
   弱图像梯度不能代表晶界召回，最终平均面积既有上升也有下降。保留最高reflect和云盘包。
3. **若继续，先保持C零噪配方检查e5→e10。** e3→e5尚有小幅恢复变化，没有饱和证据，
   也不预设后续收益。若要比较e10的训练噪声作用，A从已有e5完整状态同样接续到e10；
   不重跑已有前五轮，不用A e5对C e10宣称同预算优势。若仅检查C轨迹，可不续A但需明确范围。
4. **暂缓新增zero/noisy一致性和affinity适配。** 对两个相同零噪声输出加一致性本来为零；
   要得到有效约束需再加入扰动，会同时改变输入分布和监督目标，先避免混淆本轮恢复收益。
   后续需要噪声鲁棒性时再独立测试小扰动，不默认恢复随机推理。

五轮分析时未启动续训、全100图、黑盒或部署修改。若部署局部C，必须保留全图旧恢复器：
旧整链84,951,045参数，加局部3,283,651参数后共88,234,696，仍小于500M；
云盘的单份`restorer.pt`不能直接覆盖成C，否则同时改变了本轮固定的全图路径。

当前首步代码在eta_T=1时构造`x_T=y+0.03*epsilon`，并由网络直接预测清晰RGB。
将epsilon置零只取消人为随机扰动，网络仍完整执行该步恢复；它不是取消原图模糊或绕过网络。
零输入输出不等于带噪输出的期望，且本轮结论不自动适用于完整多步链。
扩散研究中的[DDIM原论文](https://arxiv.org/html/2010.02502v4#S4.SS1)也说明同一训练权重可对应
不同随机性的采样过程；但其确定性采样通常仍从随机初态开始，不能把它当成直接置零初始噪声的证明。
本项目的零首步可用性由上述实际冻结推理与配对质量检查支持。
