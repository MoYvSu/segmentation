# 复用全图恢复语义作末端实例投票

2026-10-31。用户授权：取消原图全图语义那次前向，复用已有全图恢复语义，同时供分水岭和逐实例投票。固定12图GPU推理、四源缓存CPU重放及本地验真已完成；无训练、无新150包、无本候选官方分。

## 唯一预测变化

控制C为已回分`.7462/.9070`的[全零150图包](GLOBAL_ZERO_PACKAGE_20261031.md)，SHA `d484e9e1…aee30a5`。本轮直接复用其中此前封存的12张全零控制输出。

```text
原C：全图零噪D5a → 全图恢复语义 → WS底图
     原图全图 → 再一次encoder/语义头 → 末端实例概率均值投票

候选：全图零噪D5a → 一次encoder/语义头 → 全图恢复语义
                                            ├→ 原WS底图
                                            └→ CPU sigmoid后末端实例投票
```

恢复图语义在原C本来就只算一次；本轮省掉的是另外一次原图语义前向。局部原生1024滑窗、零噪D5a、affinity与拼接、T8/旧20a59 NAF、S0、reflect32、强弱阈值、seed50及final200全部固定。

独立入口`tools/infer_restored_vote.py`保留原`prediction_maps`全图恢复和局部`boundary_grid`，仅删除raw图prepare/encoder/semantic调用。全图原本未消费的affinity仍照算，避免叠加另一个整理变量。原入口不改。

同一份原尺寸全图恢复logit，先在CPU按生产4线程做FP32 sigmoid，供最终均值投票；不使用二值语义mask，不先sigmoid再插值。分水岭内部临时类别依旧被外层投票覆盖，之后仅执行一次final200、继承接管者类别。
