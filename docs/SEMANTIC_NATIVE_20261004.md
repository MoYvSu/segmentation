# 当前raw末端语义的原生尺度与上下文检查

## 问题与范围

本次承接[区域语义64更新检查](SEMANTIC_OBJECT_FIT_20261004.md)。
新增区域目标确实可学，却主要改变小片类别，没有证明大对象或比赛指标改善；不继续原样扩训。
本次先用已有R1权重检查局部细节／上下文是否影响末端语义，不训练新模型。

铁素体预测平均面积为预测铁素体总像素数除以其实例数。语义改类与几何拆并都能改变该比值，
共同偏差可以抵消，不能仅凭图数或大数定律排除。官方高分是有效评分证据，但不单独证明每个对象正确。
本次不按测试图的面积、实例数或外观拟合答案，不制作测试GT。

### 抵消机制的只读复核

复用全部32源当前reflect预测与新GT，不修改文件、监督或类别，只核算记录GT下的反事实。
182个严格原覆盖、类别一致、非图框区域逐像素复核，64个与记录GT分歧。
其中44个F目标判P；31个单父小片在同一父GT中另有独立、正确判F且原覆盖IoU≥0.5的大匹配。
这31片共21,055px、位于30个GT父，支持“按记录GT粒度，小片判P可遮蔽额外F计数”的具体机制。
另1片跨两个同为F的父GT，不把它计作单晶粒内碎片。
父GT的物理完整性及局部相别仍受前次原标粒度限制，不能直接认定这些边界物理错误。

不能把这个逐像素界直接视为实例类别变更的严格界。
保留完整连续图可复核的test101／train173，分别84.9709%／90.2824%像素满足这个不可翻符号条件。

“预测很极端”不等于监督或训练已饱和。

**取舍：保留当前高分辨率修正，不直接采用coarse-only或局部语义，不追加这些候选黑盒。**
语义研究的下一目标应是粗特征／完整晶粒判断；必须保护已有大对象，并避免继续用父GT类别强推每个小片。
当前观察不足证明测试语义无提升空间，也不足启动一轮同配方扩训。
后续有限定位应检查粗FPN／分类器在保留相别的工况变化下，是否产生完整晶粒的方向性偏移，
并将同相误切／异相粘连单独报告；只有出现可复核机制，才安排粗分支短周期适配。
不直接提高修正上限、不再硬推所有GT父对象内部小片同类，不用测试外观补真值。
若核查语义与几何的四格反事实，应仅限既有完整可比F对象／固定支持域、失配计0并单列删失，
不得拿不完整GT全图均面积与全预测均面积比较，或把已见GT的near-perfect类别当测试域归因。
