## 启动前发现并修复的验证污染

人工 `data/raw` 与完整 `data/unlabeled` 存在不同命名：32 张人工图在无标签目录中有不同名称的同内容图。旧伪标签生成器虽然核对了无标签目录中的排除名称和内容，却没有读取人工目录的实际图像内容，因此漏掉了跨目录别名。

原 249 张固定主线伪标签中有 9 张与人工图重复；其中 `train_589` 与人工验证图 **`train_889`** 的文件内容完全相同，其余 8 张对应人工训练图。此前六图结果里的 889 已通过硬伪标签参与任务监督，不能作为未参与训练的验证图。仅在新阶段删除它也不能消除亲本已经见过它的历史。

因此本次两组共同采用以下修正：

- 原始 249 张数据与旧训练归档保留。新建只引用原 PNG 的 **240 张子集**，不生成新标签、不修改保留标签内容。
- 人工训练仍为原 26 张；选优只使用 `train_172/351/686/872/873` **五图的原人工监督验证损失**。889 只可用于明确标记的已见图诊断。
- checkpoint 保留原始划分，并显式保存 `evaluation_excluded_names` 与 `selection_validation_names`。正式 evaluator 默认遵守排除记录；显式请求 889 时记为分析覆盖。
- 在线无标签池从 1000 张赛方训练图中排除 56 个已声明名称及 32 个额外内容别名，剩 **912 张**；不使用测试图。
- 生成器、伪标签读取入口均增加跨目录内容排除。旧版未记录该检查的生成清单不能被新生成器静默继续；历史训练配置指向原 249 张时，新的来源检查会明确报告别名冲突，应使用本次子集或经过修复的新生成数据。

证据：[内容别名审计](../output/20260911_091212_consistency_launch/content_alias_audit.json)、[五图重新汇总](../output/20260911_091212_consistency_launch/validation_scope_correction.json)。剔除 889 后，旧监督、仅伪标签、归属组的匹配数为 **510 / 611 / 600**，主线为715；进步仍存在，但原六图全部独立的说法已撤回。亲本 epoch 仍保留原六图损失选优的历史，本次不以新指标重新挑选旧权重。

两组增加的监督预算、去重数据、低学习率与优化器重置完全相同，所以应以两组之间的差别判断一致性收益；不能将新阶段与旧 e120 的所有变化都归因于一致性。运行器会检查两组配置仅有一致性权重和输出路径不同。

复现链仍可理解为四阶段：已有 SSL LoRA → 掩码头预热 → LoRA 联训 → 本次短续训。不重新训练 SSL，不更换架构或最终推理方法。

## 如何生成可靠实例目标

EMA 教师从 e120 完整复制，参数不接收反向传播；只跟随学生实际训练的解码器和 LoRA。学生安装用于节约显存的梯度检查点前，先独立复制教师，避免 Python 闭包错误引用学生 trunk。

每张在线图像做等比 letterbox 和 reflect padding。教师用 FP32 highest 分别预测原图、固定轻外观扰动 `clamp(1.08*x-.04,0,1)**.94` 和水平翻转图；翻转掩码恢复到原坐标。学生仍使用 BF16。

1. 在512掩码网格上采用与部署一致的候选竞争：类别/掩码阈值 .5，按类别概率×掩码概率选像素赢家，并列选较小 query 编号。
2. 同类实例按区域重合做一对一匹配，两个变化视图都与基准达到 IoU≥.8 才保留实例。query 编号不代表同一晶粒，不能直接逐槽位比较。
3. 有效监督像素还必须由三视图分给同一匹配实例，且三者赢家的绝对掩码概率都≥.7。冲突、空缺、低置信边界和 padding 忽略。
4. 学生使用在线轻亮度/对比度/gamma变化及随机水平翻转；图像、目标掩码和有效区域一起变换。
5. 只对最后一层计算类别+BCE+Dice一致性，`eos_coef=0`，不将未匹配 query 设为背景；不额外施加归属损失。负掩码监督只存在于其他已筛选实例的可靠区域，未选中的区域不产生负监督。

原人工和固定主线伪标签监督继续保留，帮助纠正学生始终遗漏的区域。目标不足时跳过该无标签损失，但监督更新与 EMA 更新继续。在线池按完整随机排列循环，循环内不放回；计划共读取1920次，可覆盖两遍912张池并开始第三遍。912张中包含现有240张伪标签源图，不应把它们全部称为首次接触的新图像。

先反传监督损失并释放其激活，再反传一致性损失，最后合并裁剪梯度并执行一次优化器更新。额外视图、匹配点与增强采用独立随机序列，不推进原监督采样的随机状态。无标签系数直接乘损失，不用系数和归一化将其抵消。

- 筛选后确有有效实例与像素产生一致性损失。该小验证只证明实现工作，不判断分割增益；初始权重仍可因验证损失更低保留为best。
