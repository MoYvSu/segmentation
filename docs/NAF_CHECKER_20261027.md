# NAF点阵机制诊断（2026-10-27）

本轮黑盒包配方保持固定。现有证据支持：**多级子像素上采样提供的像素相位偏好被训练放大，当前截面峰值监督又允许不连续的低损失解**。不能据此断言PixelShuffle或GAN是唯一原因，也没有官方增益证据。

- state SHA256：`20a59c3971b2112c48a3b744c31f8051f5687772456cd35b5d38f0ae41b158e8`。

- CPU探针SHA256：`probe_cpu.py`为`9ceae0d2abdef5938285ede6d3ccc030a56fad3ca43f27b2883f03a7f6b15cda`；损失反例/制图脚本`probe_loss.py`为`c4a01e81594c2ec1ccb95842abe910dced724600884973cdd0821b1871b35029`。

- 线程2、CPU前向约5.39秒，`cuda_initialized=false`。严格加载checkpoint，与同架构同seed的随机初态比较；无训练、无人工/测试GT。
- 输入均为128×128的严格0/1常数、8像素直线或方环，单次前向，无裁块拼接、无细化/膨胀。测量直接取float输出概率，不取JPEG颜色。

“局部交替幅度”是每个2×2单元的`abs((左上+右下-右上-左下)/2)`均值。它衡量一像素级的起伏，不是准确率；也不等同于全图四相位均值极差。

## 结果

| 分析方案 | 数值结果 | 结论及边界 |
|---|---|---|
| 同seed随机初态→step1000，8px竖线单窗 | 局部交替幅度0.01865→0.36871；横线0.02106→0.34125 | 训练显著放大相位差。没有拼接或输入骨架化仍发生，故二者不是必要起因。 |
| 常数1单窗 | 0.02519→0.17619 | 无输入晶界/纹理也会产生周期结构；此输入仅作机制探针，不代表真实数据。 |
| 最后一级四子像素通道临时平均 | 竖线0.36871→0.11609，减少68.5% | 最后一级重要，但不是唯一贡献者。 |
| 仅倒数第二级临时平均 | 0.36871→0.09054，减少75.4% | 多级上采样共同参与。 |
| 四级均临时平均 | 0.36871→0.01032，减少97.2% | 相位自由度是可干预机制，但输出内容/幅值也改变，不能直接当修复部署。 |

临时平均使用forward hook：在内存中把PixelShuffle前每组4个子像素激活取均值并复制回四相位；不改权重，退出即移除。它会丢失子像素细节，不是正式修复。竖线共同区域平均概率也从原0.40971变为最后一级0.47185、倒数第二级0.68188、全部0.42143，说明交替减少不能单独当作质量提升。

平移实验把同一二值方环移动，再将预测移回原坐标，以中心固定区域比较。下表为输入线带及附近区域的概率MAE：

| 右移1px | 0.02639 | 0.54563 |
| 下移2px | 0.01223 | 0.49436 |

## 监督的可辨识性反例

使用当前原样容差重建损失，合成一条48点竖直GT，分别预测连续线和法向两侧交替的48个孤立点。两者概率用logit±20表示，容差2；不含GAN。

| 输出 | 8邻接组件数 | GT点覆盖 | 重建loss |
|---|---:|---:|---:|
| 连续线 | 1 | 48/48 | 4.12230694e-9 |
| 互不连接的交替点 | 48 | 48/48 | 4.12230694e-9 |

`utils/boundary_rgb_training.py:109`沿每个GT法向截面取最大logit，各截面可选不同位置；`:87`把GT容差带排除出负例。因此覆盖满不保证沿线连续或带内单线。该反例证明目标容许退化解，不证明实际点阵全部由此造成。

## 对其它归因的边界

- `models/boundary_naf.py:138/143`的四级stride2卷积及PixelShuffle，让2×2位置有独立响应；`models/boundary_rgb.py:75/78`的encoder skip和T全局跳连没有强制相邻响应连续。
- 既有原始float缓存已发现四相位差，合成单窗也出现，故不是JPEG压缩或拼接才产生。`tools/boundary_rgb_monitor.py:109-114`为概率加权平均；常规tile256、stride192、pad32均为16倍数，相邻窗相位可保持一致，未必相互抵消。另用150图清单和实际`tiles()`作CPU坐标核验：11047窗中10105窗（91.47%）起点的两个坐标均为16倍数；47张2048×2448图全部窗同相位。其余图末端窗确有4/8/12像素相位偏移，不能声称全部窗口同相位。此计数不是像素覆盖比例，也没有直接测出拼接对伪影的增减量；私有回执为`output/naf_checker/tiling_phase.json`。
- 合成探针没有使用骨架化/ellipse8，因此输入标准化不是必要起因。真实数据上的线宽/分布差异仍可能改变程度。
- GAN本轮没有单独关闭训练对照，不判定其贡献。CPU内的组间比较也不等于GPU精度消融或跨卡逐位复现。
- 无新官方分数、无测试GT、未修改部署或包配方。

## 最小后续方向

优先只消融上采样方式，例如resize+conv，固定初始化条件、训练预算和其它监督；同时检查原有完整边界、断口、双线、内部碎块与最终实例。若仅去点阵而未补通，再单独研究容差带内宽度/连续性约束。当前hook只用于定位，不能直接替换正式模型。
