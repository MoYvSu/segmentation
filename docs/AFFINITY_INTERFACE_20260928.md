## 连续界面的具体定义

1. 预测零缝临时赋予最近预测区域编号，只用于寻找候选接触。它不写回GT或最终预测。
2. 同一原标可信GT内部出现不同预测区域，取其distance1接触；按该GT独立扩展4格邻域，
   覆盖假分隔的响应带。只监督同GT且整条关系均可信的位置，目标为相连。
3. 不同GT的可信短程接触若在预测中有粘连，选中该无序GT对的完整可信接触，目标为分开。
   没有可信接触的GT对仍不补造监督。
4. margin判断组是否还有困难关系，入选后整段合法界面参加BCE，不截成16条孤立边。
   正组按GT、负组按GT对归一，两方向等权，最多8组且有双向候选时均分。
5. 最终选择只涉及四个distance1通道；普通BCE仍训练八通道。未知、自动补缝和padding
   不进入新附加项。监督带也不作为推理阶段额外规则。

它仍是困难关系BCE选位改进，不是MALIS或拓扑保证。最近区域归属和带宽可能有副作用，
必须经过完整部署检查，而不能只看loss下降。

## 结论与下一步

当前证据是“附加监督产生了少量变化，但未呈现显著纠错收益”，不是证明affinity饱和，
也不是已证明该损失方向一定无用。无新官方得分，保留0.8486／0.8761的control，不默认替换。
本轮不原样续训，不建议优先消耗黑盒机会验证这一版微小变化；100图完整输出已保留。

优先候选是一次短周期的**参数梯度力度检验**：从同一可回退状态、同一小批可信训练输入出发，
单独将原25%输出端限制改为人工BCE参数梯度的受控目标（例如15%，仍保留名义系数上限与预热），
而不是只调大weight。同步观察参数梯度方向、合计梯度及真实参数更新、目标界面的预测变化和
完整分区中新误切／粘连；不以loss下降或“输出变化更大”当通过。
只有短测显示针对性纠错且无明显副作用，再从原共同初始化做同预算20轮，继续复用已有control。
本轮仅提出此方案，未修改训练配方或启动下一轮。弱力度有直接证据，但尚无力度因果消融，
不能预言增力必然提高黑盒分数。

后续已按用户授权完成[同起点64步参数预算短测](AFFINITY_BUDGET_20260928.md)，
力度改变生效，但未显示足够纠错收益并增加新粘连；未进入正式20轮。
