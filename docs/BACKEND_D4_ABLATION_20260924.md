- 人工类别、有效域、辅助边界和affinity全部由同一补缝实例图及类别映射派生；
  不再把新语义目标与旧LabelMe几何目标混合。Unknown与反射填充不作为负类。
- 64张SAM2源清单SHA256为
  `4ed3e2e1fcfd2fa369dd647fc5ce7c869c5bcb7f472e29398ee889b368e40749`，
  与既有用户授权清单相同，见`G1_ABLATION_TRAINING_20260912.md`。
  历史approval.json未恢复，不虚构审核人、时间或新审批。所有SAM2类别仍为空。
- 1024等比letterbox；在有效内容上在线退化，再反射补边，并对图像和全部目标同步翻转／90度旋转。
  不随机挤压、不裁块、不离线改写原图。
- D4原配方：20%原样，80%模糊；Gaussian sigma 0.4–5.2，模糊样本内50%平滑空间模糊，
  保留原重采样概率与尺度。叠加温和三通道共用噪声：模糊样本50%概率，sigma均匀0–0.006。
  不加局部遮盖SSL任务，不使用测试标签。
- 两组增强按seed/epoch/源图/抽次生成独立可重放流；D4用单独generator，每步后端随机流相同。
  A/B开始与结束检查初始权重、数据配置、样本顺序和逐步seed。

相对旧部署，本次还共同使用全32张标注和统一几何目标。因此A/B可隔离该适配方案下D4的增量作用，
但任何组比旧部署改善，都不能全部归因为已证明“特征不适配”。不凭训练loss或无标签目检晋级。

## 优化、监视与自动收尾

配置为`config/train/backend_d4.yaml`，AdamW eps=1e-4、weight_decay=1e-4；
语义/affinity/LoRA初始学习率分别1e-5／2e-5／1e-6，60轮余弦降到各自10%。
语义和人工affinity损失权重各1，SAM2 affinity权重0.5，两组不分别校准权重。
后端使用BF16、loss用FP32、梯度裁剪1；D4始终FP32。出现非有限损失或梯度即终止，不静默跳步。

固定4张真实图在e0、e1、每5轮和末轮保存原图／类别／边界概率缩略图；
这是过程观察，不是验证或选择checkpoint。保存last训练状态快照和e20/e40/e60完整fused权重；
没有实现精确断点续训入口。最终LoRA和两个头与共享encoder一起严格载入，禁止挂回旧头。

```bash
python tools/run_backend_ablation.py --config config/train/backend_d4.yaml
```

入口顺序：d4训练→raw训练→配对完整性核对→两组各100张同协议推理→两份提交ZIP→四组对比渲染。
启动时将解析后配置冻结到运行目录，全部读写位于fast盘，输出短目录`outputs/d4_adapt/`。
脚本不向竞赛平台上传，不需要代理持续监督训练。

最终图为原图＋baseline＋D4原后端＋D4微调后端＋无D4微调后端。
固定铁素体金色、珠光体蓝色、实例边界洋红色；test101另存左右256像素同坐标原尺寸裁块。
不依赖随机实例颜色判断变化，不调整实例数量或面积来拟合成绩。
