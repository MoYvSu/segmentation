# 弱界短测新增粘连：marker读出定位与镜像边框诊断

2026-10-03。接续[弱界保留32步](AFFINITY_WEAK_RETAIN_20261003.md)，检查两臂新增的已知铁素体粘连。本轮不重训，不换权重；在原服务器`sam2_env`精确重放已封存的整图连续边界、两路固定语义与最终划分。

## 核心结论

**这一例的连续边界已经能分隔两侧，新增粘连发生在marker生成时。** marker是分水岭的起始区域；两个晶粒共用同一marker后，后续分水岭无法凭强边界自动生成第二个独立实例。

不是此前弱晶界案例的“原响应太低”机制。当前同一实际已知域通路穿界处概率约0.746／0.837，已超过0.65；高阈值、弱边重建和桥接都能在全图、已知域、两粒域隔开，骨架化后才连通。骨架化把粗响应变成细线，但不保证保留细线与图框的接触。

| 分析方案 | 结果 | 结论 |
| --- | --- | --- |
| 原R1、U／R第16／32步的完整CPU重放 | 5套实际marker、WS、uint16实例及原rawprob复投票类别均精确复现 | 定位的是实际部署链；不是本地近似骨架算法 |
| 逐层全图8邻连通与已知粒对路径 | 32步时高阈值／重建／桥接分开，细化后相通，膨胀／后封框未接回 | 先处理边框端点读出，不能只加大训练负边惩罚 |
| 预封框、跳过细化；仅替换实际WS种子 | 两者解除新增粘连；跳过细化使R固定面积MAE2.7924%→3.1806%，新增铁素体内拆分 | 原响应分隔可恢复；简单取消细化有副作用 |
| marker桥接后镜像扩展，再细化／裁回 | R原131名单恢复完整；固定21面积逐项不变；32／64宽度完整输出一致 | 可继续扩大几何检查，尚不是正式增益或训练晋级依据 |

## 实际失效位置

在含真实左图框的原生像素局部中，桥接后的粗屏障始终触框。旧R1细线端点距图框1px，16步为2px，32步为4px；原膨胀1px后，32步端点仍距图框3px，而既有seal仅占0、1两列，留下第2列的自由绕行通路。

既有238像素最短通路完全位于processed GT两粒已知域内，不依赖未知区；它只是一个实际见证，不是唯一通路或最小割。路径经原粗屏障阻挡、却被最终种子放行的像素均贴近图框。原生局部图与实际二值数组支持端点内缩这一定位，不单凭预封框成功作归因。

两粒都接触图框／未知区；264条原生直接接触中260条至少一端来自filled。仍完整使用新GT，包括filled，但不将其当完整真实粒面积、独立验证或比赛答案。GT0保持忽略，删失不能抹去已知内部的归属变化。

原训练两窗的合法界面关系各1079条，保留883／844条；没有关系因修正带被排除，其余主要因教师置信不足。第三个重叠窗也参与此界面，但未参加原两窗训练，且此前未保存新logits。本轮已明确后处理失效，无需先补该窗GPU推理；**没有声称完整归因三窗输出变化**。

## 镜像边框变体

独立入口`tools/probe_affinity_marker_replay.py`，不改`utils/post_process.py`或默认推理配置。

```python
candidate = build_marker_variant(stages, 'reflect', reflection_padding=32)
decoded = decode_marker_replay(semantic, native_boundary, config,
                               candidate['marker_labels'])
```

流程：原生bridge → 二值marker屏障以`cv2.BORDER_REFLECT`扩展 → 原实际算法细化 → 裁回原尺寸 → 原dilate／seal／min_area。镜像延续让触框线在细化时继续到图外；不加入完整白框，不使用GT决定补线或实例数。原高阈值WS障碍与实际WS输入图保持逐像素相同。

实际服务器本次走`skimage`回退，而非`cv2.ximgproc`；Python3.12.3、Torch2.8.0+cu128、NumPy2.3.2、OpenCV5.0.0。原marker注入仍精确复现完整最终输出；反射宽度32／64只作稳定性检查，不按GT或目检选宽度。三套模型状态的裁回骨架、marker带、marker、WS、实例PNG及类别全部一致。

## 决策与后续门禁

1. 保持当前最佳部署；本轮不取消U／R原训练安全门禁，不开20轮或直接生成黑盒候选。
2. 优先扩大镜像marker的固定多源几何检查：原R1、训练候选采用同一读出；检查所有F、原匹配名单、已知弱小粒、F-P投票变化及实际全图F平均面积。此阶段仍非独立验证。
3. 同时检查旧种子到新种子的双向拆分／合并，以及斜向触框、拐角、近框未触框和贴框闭环的合成例。若32／64输出不一致，应报告边界条件敏感，不能挑较好的一组掩盖。
4. 多源检查通过后再做100图无标签分布对照；重点核贴框碎块和F面积变化，遵守不推断测试GT、不反调实例数／面积的边界。
5. 再决定是否扩大完整GT＋局部学习。原R1的旧弱界本身并未被镜像读出修好；这说明训练仍有必要，但其收益应在读出机制受控后判断。

已有粗放预封框在全100图产生大量贴框小腔；已有marker_restore＋面积过滤亦有严格配对黑盒退步，见[旧恢复实验](MARKER_RESTORE_20260927.md)。本次镜像改变骨架的图框条件，与在原种子内部依据粗边界拆分不同，但历史教训仍要求完整输出检查。
