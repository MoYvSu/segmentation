用户在参数预算短测后授权按既定顺序执行冻结检查，并强调平均面积项只涉及铁素体。
本轮不训练、不更改默认模型／后处理、不制作测试GT或自动提交。
入口`tools/probe_affinity_patch.py`，配置`config/experiments/affinity_patch.yaml`，
汇总`tools/analyze_affinity_patch.py`，服务器快盘私有`outputs/affinity_patch/`。
2026-09-28已完成8源×6方案的48次完整分区、32对清晰参照恢复与追加结构复测。
冻结状态不变，4张测试图的全图基线逐像素／类别复现已有control；未训练或修改部署默认值。

## 六种边界输入

| 名称 | affinity输入 | 几何语义／最终语义 |
|---|---|---|
| global_d5a | 原全图缩放1024＋D5a | 固定全图D5a／raw |
| global_raw | 原全图缩放1024 | 同上 |
| patch1024_d5a | 原图裁1024＋D5a | 同上 |
| patch1024_raw | 原图裁1024 | 同上 |
| patch512_d5a | 原图裁512→1024＋D5a | 同上 |
| patch512_raw | 原图裁512→1024 | 同上 |

`global_raw`也复用D5a全图几何语义，不是把整个系统改为raw的历史包；这是隔离affinity输入的必要控制。
原生裁窗目标步长为窗口的75%（最少重叠25%，末端贴边时重叠可能更大），
每块内按原规则先将多方向／多距离affinity融合为连续边界概率，
再回原图坐标加权拼接。权重中心高、边沿低且处处为正；不混合不同物理距离的原始affinity通道。
不在局部生成实例后拼ID；合成连续边界后仅作一次全图分水岭，因此局部外部连接仍然参与分区。
裁窗从原始RGB进行，不从缩小后的整图或恢复图二次裁窗来冒充原生细节。

在首个训练源前4块上比较逐张与batch=4：每块使用同一显式噪声，并验证与原`restore_first`
的同种子输出逐值一致。记录RGB与边界最大／平均差、阈值翻转率及首块固定语义下的完整局部分区。
这不是全图精度；所有正式尺度比较统一逐张执行，不把batch数值误差引入尺度对照。

## 分类别诊断口径

铁素体单列实例数、总像素、平均面积、小于200像素实例数，按图比较变化：
平均面积比=总像素比／实例数比。不能只看面积是否变大，也不能用预测均值拟合未知测试答案。
珠光体不计算面积得分，但独立统计实例匹配与过分割，防止内部纹理被切成不合理小块。

训练匹配仅在`original_covered & instance_map>0`原标可信域计算，两边都移除未知像素。
分别报告同类有效IoU≥0.5匹配、GT数、匹配数、平均匹配IoU和未匹配GT计零的诊断量，
同时检查显著误切／粘连。它们是被裁掉未知区域的已见训练图指标，不能写成官方或独立泛化精度。
未知域、补全域和遗漏实例不当背景负例；不输出伪官方面积／总分。
新增几何错误按原GT分成铁素体误切、珠光体误切、FF／PP／混合粘连，点对可能相关，不简单相减。
测试图只有最终预测统计及固定全图／局部目检，没有准确率。

## D5a已知清晰参照检查

每个训练源取2个固定原生1024裁块，共8块，每块四种输入：清晰恒等、0.75倍降采样、
0.5倍降采样、平滑局部模糊后0.5倍降采样；降采样用area，回1024用linear。
局部模糊名义sigma从0.6平滑过渡至4.5，沿用既有sigma平方插值实现。
对照插值输入与D5a首步，共32对，同一清晰图为RGB／梯度参照；不优化权重。

固定清晰参照的边缘阈值，测量纹理边缘支持率、远离参照边缘3像素以外的新响应比例、
参照邻域响应带面积比。这些是纹理恢复诊断，不等于人工GT实例边界准确率；带面积比也不是
严格的光学黑线扩散宽度。恒等档检查D5a对本已清晰图的改动，误差为零的输入不计算比值。
保留全部32组固定中心256像素对比图，不能以更锐利单独判成功。训练图曾被D5a见过，
所以即使改善也不能据此声称真实测试放大分布的泛化能力。

## 实现验证

16项本地最小测试通过：非方形／小于窗口／精确窗口的完整拼接覆盖与无缝坐标回放、
缺块拒绝、珠光体分片不改变铁素体面积、未知预测保持ignore、已知图像误差／假边检测，
以及既有完整部署解码与monitor契约。追加2项结构检查通过，验证可信铁素体内部排除
未知域／实例边缘／珠光体／裁窗外沿，恒等构造不改写原始参照。GPU完整结果见下节。

额外的只读面积分档使用每图control本类实例的中位面积作为固定参照，
统计小于5%／5–10%／10–25%／25–50%／50–100%／100–200%／大于200%的数量和像素。
它不删除或合并实例，不根据GT或测试得分选择阈值。跨档净变化不是新增真实实例的逐个溯源。
另按1024预测相对全图的珠光体实例增量定位512像素窗口，绘制逐实例着色图，
防止大量同类小片被同一蓝色掩盖；该选窗是风险定位，完整固定8图仍全部保留。

### 逐张与batch

同一4个原生1024裁块、相同逐块显式噪声；显式调用与既有单张`restore_first(seed)`完全一致。
batch=4相对逐张，D5a RGB平均绝对差约3.56–3.86e-6；边界图平均差3.44–5.45e-5，
0.65阈值翻转约0.0019%–0.0038%。首块局部分区均为70实例，但像素不完全相等。
这支持存在微小数值变化，不能解释成batch之间交流信息，也不能把同计数称为相同分割。
完整48组正式对照全部逐张执行；未根据这些数值改变精度或后处理阈值。

### D5a恢复与结构风险

8个清晰训练裁块上，0.5倍降采样再插值时，D5a的RGB误差比值中位0.9914、梯度误差比值0.8960；
平滑局部模糊叠加0.5倍降采样时，分别0.5078、0.8800。平均像素与梯度误差都改善，
但固定对比图中出现了原本平坦铁素体内部的细网纹，故追加全部32对的affinity结构检查。

追加入口`tools/probe_patch_structure.py`，配置`config/experiments/patch_structure.yaml`。
原图与既有D5a输出误差逐项重放在1e-9内一致；模型状态完全不变，耗时16.09秒。
只取原标覆盖、同一铁素体实例内部，距实例边缘／未知域／裁窗外沿至少8个输出格的位置。
每档合计833680个格点。统计清晰图边界概率低于0.45、当前输出超过0.65的新增强响应：

| 退化档 | 插值输入 | D5a输出 |
|---|---:|---:|
| 恒等清晰 | 0 | 0 |
| 0.75倍降采样 | 289 | 115 |
| 0.5倍降采样 | 613 | 221 |
| 平滑局部模糊＋0.5倍降采样 | 3777 | 7422 |

单纯降采样时D5a减少不受清晰参照支持的强边界；局部模糊叠加降采样则4／8块增加、4／8块减少，
合计增加96.51%，主要由两块贡献。train_558第0块的新增网纹被affinity响应为分支晶界，
清晰参照／退化／恢复RGB与固定色阶的边界图已并列保存。
这是特定合成退化下的结构失败，不代表D5a普遍有害，也不能证明测试512分片全部由D5a导致；
raw512本身也明显分片。它说明RGB／梯度改善不足以验证恢复器对分割有益。
这些格点不是新增实例数，不是无标签测试准确率；清晰图affinity本身也并非完美教师。

## 冻结检查后的原生裁块适配建议

以下为冻结检查结束时的建议。用户随后授权1024和512两组顺序、独立训练，
已完成双组GPU短测并启动正式队列，见[原生裁块适配](AFFINITY_NATIVE_20260928.md)。

用户进一步提出训练时直接看小块。当前最高分control最近这轮20epoch的数据流，
由`CanonicalBackendDataset`先将整图letterbox至1024，`PairedDegradationDataset`再退化与翻转旋转，
没有原生裁块；本次`SAM2GeometryDataset`调用也没有启用`native_crop_size`。
历史G3等阶段曾有原生裁块，不能说整个谱系从未见过小块；这里针对的是当前D5a适配阶段。

建议第一轮只改训练视野为原生1024，不同时使用512放大、类别合并规则或新的结构损失：

1. 新组从已完成control当时的同一V／S-align／joint-v3初始化开始，保留Stage1谱系，
   用相同20轮／1280更新与原普通affinity损失。直接复用已完成的全图control，不重跑控制。
   实施前核对其初始化哈希与训练回执；不能把control e20再接20轮称为同预算的裁块消融。
2. 全部32人工源与已授权64个SAM2几何源保留，不建留出或扩展伪实例来源。
   在原始RGB及其同一实例／有效域坐标上先裁1024，再作既有退化、D5a和模型前向。
   D5a、encoder／LoRA、语义冻结，仅affinity decoder更新。真实图尺寸不足时仍等比padding。
3. 裁窗位置覆盖晶界密集区和完整内部，不只挑边界。GT未知域与窗外offset端点继续ignore；
   裁窗边框不能被造为真实晶界。保持目标来自原实例图，使恢复后纹理不会自动成为监督边界。
4. 用已有control与新权重，分别做全图和1024局部推理的交叉对照，拆开推理视野与训练适配的作用。
   语义仍走固定全图，局部连续边界拼回原图后仅一次全局分区。首轮不加新的跨尺度融合。
5. 固定e0/e1/e5/e10/e15/e20缩略monitor，兼看完整输出和局部细节。铁素体单列误切／粘连、
   小块和平均面积；珠光体看主体轮廓／匹配。训练短测只检查可学性与契约，最终收益仍需官方比较。

原生1024方向有继续适配的依据；512放大在现有冻结链上的风险明显，暂不直接扩大使用。
D5a产生纹理可先由GT指导affinity抑制；若此后仍成为主要错误，再独立研究恢复器结构约束，
不能预先保证只训affinity就能消除它。本轮未启动新训练、全100图推理或生成新黑盒包。
