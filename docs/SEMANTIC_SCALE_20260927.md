# 全图与局部尺度语义适配

## 问题与唯一变量

冻结模型诊断显示，同一D5a结果仅改变语义视野与尺度即可改变局部类别概率，但相邻位置也可能反向变化。
本轮用训练适配这种敏感性；不直接用局部推理替换全图，也不把单张无标签图的改判当作准确率提高。

沿用私有语义LoRA实验的原simple e60初始化、原有LoRA复制初始化、全部32张人工图／1000训练源、
光照／模糊配方、先验接受规则、损失、学习率与20轮1280更新预算。
只训练simple语义头与私有语义LoRA；D5a、共享SAM2底座、原LoRA及V affinity冻结。
保留Stage1/joint-v3谱系；无留出集，不重训原控制，不使用测试标签。

唯一变化是D5a完成后的语义输入视图：每条训练流独立以0.5概率保留全图，0.5概率选有效内容内
512×512方窗再放大到1024。对应约2倍视野尺度，不启用4倍，也不引入新的原生细节。
裁窗4像素对齐、不混入reflect padding；位置由独立随机流决定，不能推进旧增强／Dropout随机流。
有效内容不足512时回退全图，不改变长宽比。

人工GT、实例ID、已有边界和ignore同步最近邻变换；不新增裁窗框作为GT边界。
局部损失只看裁窗内可见部分，类别不变；这属于尺度视图变化，未另改损失定义。
无标签灰度先验仍在清晰整图上计算，排除已知GT，随后同步裁目标和接受mask，绝不在裁图上重算阈值。
困难光照增强仍回放gray4原先选中的类型、幅度与D5a噪声；最后只改变语义分支视野。
步骤日志同时保留裁前目标计数和裁后实际监督计数，避免把缩放后格点数理解为新增标签覆盖。

## 第二项：暂不改变核心池化

当前实例概率损失实际取核心，而最终部署取整个实例均值，两者确实不同。
但像素BCE/Dice已在全部有效像素监督边缘，代表性局部又存在图外连接；尚未证实必须同时修正。
本轮保持`utils/semantic_training.py`及原pool_weight=0.5不变，避免将损失目标和尺度效果混为一谈。
未来若做完整实例池化，应作为单独候选，与这轮权重和部署严格对照。

## 后续判断

保留预定e20作为尺度消融候选，不原样加轮数或替换已验证方案；全100输出已齐，可复用产物做黑盒，
正式参照是本次用户回报的LoRA控制0.8445／0.8557，不能混用恢复后处理组合。
当前没有明显全局改善证据，也不能由少量改判预言官方增益必小。

如果继续尺度方向，下一项更值得验证的是同一位置的全图与局部配对训练：保留每步全图主监督，
局部作辅助监督，并对齐两种预测以约束尺度变化。这与当前随机各半不同；当前仅651步直接看全图，
没有显式要求两种视野互相一致。该修改会增加计算量，需要单列预算与对照，
且不能默认局部一定正确或把无标签一致性当新增正确知识。此处是候选方案，未实施。
完整实例池化仍应单独消融，不与新尺度策略或后处理一起改变。
