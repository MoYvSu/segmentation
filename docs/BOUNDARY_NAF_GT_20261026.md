# NAF新增边界与有效样本量审计

2026-10-26。按用户授权，只检查现有模型和处理后新GT，不启动训练、不替换部署、不提交黑盒。
结论：当前细化接入的NAF存在大量与记录GT冲突的内部新增分隔；训练裁窗访问和空间覆盖并不明显短缺，
更直接的缺口是输入任务分布没有覆盖真实N0的错误支路。GT有遗漏风险，本审计不是物理真值裁决。

## 判据：支持、内部响应与实际分隔分开

1. 对NAF输出的0.65正响应求骨架；距输入骨架超过2原生像素才计新增，排除普通加粗。
2. 未知区及其8像素邻域、图框8像素安全带忽略。原标/填补只用于分组，不分别切域算连通。
3. 新增骨架距记录GT界面≤4像素记位置支持，>8像素记记录GT深部内部，其间保留为缓冲。
   另报告0.45阈值及2/8像素容差敏感性，不据此选提交参数。
4. 新增落点属于原标还是填补，与附近GT界面是否由原标—原标两侧支持分开统计。
   容差内可由两种来源同时支持时单列，避免最近点并列造成任意来源分配。
5. 对整个同GT安全已知域比较旧开放分量是否被新屏障切成子块；显著子块预设≥50像素且
   ≥旧分量5%，所有小子块仍保留在结果中，不从预测中删除。
6. 诊断性移除新增深部屏障，只有显著子块全部恢复同一连通分量，才记严格深部新增导致的分隔。
   两个子块还需各有≥50个原标覆盖像素，才记为双原标支持的强案例。
   该反事实只用于归因，不是推理回退或新后处理。

用于连通诊断的屏障基于原始浮点输出的精确`p>0.45/p>0.65`掩码，经原8步弱响应重建、bridge1、
reflect32细化、dilate1、seal2、min50流程生成。训练源001的两个权重与项目原marker实现逐值校核。
这里未重放真实浮点概率logit→sigmoid临界舍入，也不包含语义/WS，不能称完整最终输出。
8bit热图只用于展示；统计不使用量化图代替原阈值掩码。

## 内部线是否真的切开了记录GT

| 诊断 | 5000 | 6000 |
| --- | ---: | ---: |
| 显著切分与深部新线共现的旧开放分量 | 289 | 402 |
| 严格反事实、双子块均有原标支持的旧开放分量 | 282 | 395 |
| 上项涉及的不同记录GT实例 | 274 | 375 |
| 严格案例按记录类别F/P（旧开放分量） | 110/172 | 155/240 |

actual与只保留新增作用的`before|after`对照在这些强指标上相同。
395是旧开放分量/案例数，不是395个不同晶粒；同一GT可有多个旧分量。
这已超出“内部出现一些零散响应”：新增深部屏障对记录GT内的额外分隔有反事实支持。
但GT可能漏标或合并物理晶粒，仍不能把375个记录GT冲突一律认定为物理误切。

## 同时检查记录晶界的恢复机会

不能只看新增线里支持比例低：已见训练源的输入本来可能已覆盖绝大部分GT晶界。
因此固定同一GT边界分母，补算到输入/输出骨架距离，按来源检查恢复及掉出容差。
安全域原标边界522,199、填补边界2,075,411，总计2,597,610像素。

| --- | ---: | ---: | ---: | ---: | ---: |
| 原标，4px | 90.2625% | 89.4510% | 50,849 | 1,800 | 6,038 |
| 填补，4px | 92.7844% | 91.4214% | 149,754 | 5,571 | 33,859 |
| 原标，8px | 96.9988% | 97.0553% | 15,672 | 741 | 446 |
| 填补，8px | 99.4119% | 99.4092% | 12,205 | 733 | 789 |

8px宽容差下，全安全域覆盖98.9268%→98.9360%，净增239像素（约0.0092个百分点）。
机会确实不多；但相对原漏分母，恢复也仅约3.5%–6%，不能把低支持比例全部解释为没有机会。

0.134%只是位置分母，不能据此推断参数梯度比例或直接认定加权有效。

## 结论与下一步

1. 当前版本有真实补边能力，但新增分隔与已有监督冲突广泛，现阶段不直接出包或晋级。
2. 没有证据把失败首先归为训练访问数量不足。补边任务没有覆盖真实N0错误支路，比继续增加相同理想擦断样本更直接。
3. 下一轮优先考虑保持同一处理后GT、结构与随机初态，改用同图真实N0细化输入，
   使输入中的错误线也能与GT负目标配对；先小批验证真实输入的保持/纠错，再决定训练。
   这是下一轮建议，本轮没有生成训练队列或开始优化；不要同时叠加来源降权、损失扫参和网络扩容。
4. 原标/填补继续分层监控，填补带不默认真也不默认假；GT记录缺陷与模型不可靠连线不能混作单一原因。

画廊按预设规则选择3个双原标支持内部案例、3个恢复邻接案例、2个固定种子随机源；
极端案例用于定位机制，不代表随机发生率，完整统计覆盖全部32源。
绿色新增线为≤4px GT支持，红色为>8px记录内部，黄色为缓冲；灰色未知忽略，青色GT界、橙色填补。

后续用户目检确认：本轮展示的`train_557`新增内部线所在位置没有晶界，应属误切。
这是该训练图案例的人工确认，不推广为395处案例均已确认。未编辑GT或新增像素标注；
下一轮仅将该已有训练源区域加入固定过程图，目标仍读取同一处理后GT。
