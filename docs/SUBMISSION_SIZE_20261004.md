1. 先构建真实`results/`＋`code_model/`完整包，清除优化器、训练缓存与无关权重；保留
   推理必需权重及代码，不能通过遗漏模型来伪装完成工程演习。
2. 完整检查100对结果、PNG位深与尺寸、实例ID／JSON一致性、ZIP路径以及独立推理复现。
3. 记录最终ZIP准确字节数、MiB与SHA256，并与200 MiB默认参考线比较；该比较不等于
   已核实平台接受。若压缩后的真实必需模型仍使包超过参考线，先报告实际体积。
4. 用户在真实赛题入口尝试选择／上传该完整包，记录具体报错或接受状态。平台可能在选择
   文件后直接开始传输，不能承诺“只选文件”一定不上传。本次代理未执行该步骤。
5. 若实际入口拒绝，按界面提示向组委确认正确限额与模型材料交付方式；保留完整可复现包，
   不擅自将仅结果包当成满足最新双目录要求的正式交付。
