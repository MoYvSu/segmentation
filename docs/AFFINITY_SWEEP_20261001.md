## 当前实际生效的训练参数

核对`config/train/affinity_balance_mixed.yaml`的完整继承结果及
`train_affinity_balance.py`→`train_affinity_native.py`实际路径。
affinity输出两个像素属于**同一实例**的概率：正关系是应该连接，负关系是应该断开，
与日常说的“边界正样本”方向相反。

| 参数／机制 | 当前实际值 | 实际作用 | 本次安排／正式证据 |
|---|---|---|---|
| `direct_semantic_affinity.affinity_loss.negative_weight`，r | 1.0；旧控制1.5 | 两来源共同使用，调整断开相对连接的贡献 | 第一优先0.75、1.25；1.5→1.0已有两条正式配对收益 |
| 同节`hard_negative_weight`，h | 1.0 | 在应断开关系中，更关注模型高置信连起来的位置，主要针对粘连 | 先0，再条件2；当前1.0尚未单独消融 |
| 同节`hard_negative_gamma` | 2.0 | 控制困难加权的集中程度；h=0时不起作用 | 首轮固定；h有效后再考虑1或3 |
| `backend_adaptation.pseudo_weight`，β | 0.5 | 整路SAM2相对人工监督贡献，两路每步各一张 | 条件0.25、1.0；采用后文名义总系数归一化，尚未实现 |
| `backend_adaptation.learning_rates.affinity` | 2e-5 | affinity头峰值学习率 | 首轮固定；优化不足时单独考虑1e-5、4e-5 |
| `backend_adaptation.minimum_lr_ratio` | 0.1 | 20轮余弦日程最低学习率比例 | 首轮固定；末段仍有未满足信号时备选0.3；e20结束后的下一学习率为2e-6，并非e20全部步骤所用值 |
| `backend_adaptation.weight_decay` | 1e-4 | AdamW权重衰减，约束参数增长 | 生效，暂不扫，尚无本谱系独立消融 |
| `backend_adaptation.grad_clip` | 1.0 | 总梯度范数超过1才缩放 | 条件生效，先统计触发比例，不能默认一直限制更新 |
| AdamW `eps` | 1e-4，代码固定 | 优化器分母稳定项，也影响小梯度更新 | 实际使用，尚非配置项，本轮固定 |
| `epochs`／`manual_repeats` | 20／2 | 32人工源每轮64抽样，与64确认SAM2源配对 | 固定64更新／轮、共1280更新；增加轮数不是仅改监督权重 |
| mixed视野 | 每轮32全图、32原生1024 | 两来源同步，全图等比缩放；局部先从原图裁块 | 固定；这里不是1024／512各半 |
| `backend_adaptation.noise` | 开启，概率0.5，sigma=0～0.006 | 在线噪声，配合既有D5a退化及首步恢复 | 首轮固定退化与随机序列 |
| offset与训练通道平均 | 8通道等权，4短程、2距离2、2距离4 | 各距离实例关系分别监督后平均 | 固定；目前没有可配置的训练距离权重 |

仅第一行的**本次具体改动**有上述正式配对涨分证据。实际参与计算不代表当前值最优。
当某通道两种关系均存在时：

`L通道 = (L应该连接 + r × L应该断开) / (1 + r)`。

两类先分别求平均，再组合，不因内部像素更多就必然淹没边界。r=1.5→1使名义系数
从0.4／0.6变成0.5／0.5。h用当前连接概率确定困难度，困难度本身停止反传；
当前归一化使h改变负关系内部的相对关注位置，并非统一增加所有负关系的总系数。
