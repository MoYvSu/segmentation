## 干预和计数口径

对同一输入固定全部语义概率，只改变指定affinity输出，再走实际完整解码：

| 方案 | 变化 |
|---|---|
| base | 原control e20输出 |
| ideal_short | 原标可信域内4个distance1通道，按GT端点关系替换为±16 logits |
| ideal_all | 原标可信域内全部8个distance1/2/4通道，按GT关系替换 |
| selected_only | 只替换现有附加损失在此固定视图实际选中的输出关系 |

`selected_only`通过现有损失对独立logits求梯度恢复所选位置；不对模型反传或更新。
逐项核对所选数量、可信域及未选位置不变。强制正确输出是一种反事实检查，
不是可实现的训练结果或性能上界；尤其不能将其等同于训练的共享参数变化。

固定代表点在原尺寸GT可信内部选取，所有连通域及通路均在整张图计算，裁剪仅用于展示：

- 粘连关系：不同已知GT实例的主要预测重叠区域共享一个预测ID，枚举这些GT核心之间的点对。
  同一大粘连可产生多个点对，点对并非独立错误实例，也不要求两GT直接邻接。
- 过分割关系：一个GT可信区域内最大的两个预测碎片，各至少占该GT已知面积10%，且至少50像素。
- 零种子／背景点单列为blocked，不当作已成功分开。
- 统计“修复”仅问原先这批错误关系是否达到预期同／异ID；没有计入干预新引入的全部错误，
  因此不能将修复比例解释为净精度提升。

追踪顺序为高阈值、弱边重建、bridge膨胀、骨架细化、细线膨胀、封边、marker、分水岭和最终实例。
前六级同时计算仅允许通过原标可信像素的通路，以区分必须经过未知区的连通。
直接截获真实`cv2.watershed`输入，与独立重建的marker逐像素核对。

## 汇总结果

全32源／64视图完成，三份任务的后端及恢复器状态摘要前后完全一致。
64张整图缩略图、三张路径细图及全部记录已回传。聚合见私有`report.json`。

| 固定错误关系诊断 | 原图32视图 | 在线模糊32视图 |
|---|---:|---:|
| 基线粘连点对 | 358 | 554 |
| 涉及的合并预测ID数 | 207 | 283 |
| bridge后分开、细化后重连 | 238／358（66.5%） | 304／554（54.9%） |
| 上行中，最终通路可完全留在原标可信域 | 34 | 35 |
| 基线显著过分割点对 | 919 | 881 |
| ideal_short修复粘连／过分割 | 257／609 | 334／603 |
| ideal_all修复粘连／过分割 | 269／713 | 353／683 |
| selected_only修复粘连／过分割 | 2／0 | 1／0 |

每张源图的原图和模糊视图都发现细化后的分隔丢失，但点对不独立，不能把这些比例当作
全测试漏分率。严格原标通路子集中仍有69例；其余细化后重连关系不能在原标可信域内
单独确认最终自由通路，保留其未知区影响，不据此给漏口补GT。

理想全关系替换对既有粘连点对分别修复75.1%／63.7%，对显著过分割分别77.6%／77.5%。
这说明改好关系预测仍有实际影响，且改善同时包括拆开粘连与合回误切。
只修短程已解决不少问题，全offset还可多合回一部分碎分；没有证据支持直接移除长程通道，
也没有将“512网格／融合一定是主要瓶颈”确认为结论。

附加损失在原图只选中20／358个粘连关系、25／919个显著过分割关系；模糊视图为
35／554及22／881。粘连点对中236／358和387／554没有两GT之间直接可用的完整可信接触边。
这些关系可能并不邻接、可能隔着原标空隙，不能为了增加覆盖而把空隙升级为真值。

64视图实际选中7826条输出关系；强制其正确后，融合图累计4992格变化超过0.01，
13／64视图的最终实例数改变，但本次主要错误点对只修复3个粘连、0个显著过分割。
因此“确有loss／边界数值改变”不能替代对最终划分的作用检查。
这只是固定视图上的直接输出干预；真实训练会通过共享参数改变其它输出，跨epoch的选边也会变化，
不能据此证明该损失训练必然无效，只能否定“只要把这批边训得更准就足够”的推断。

## 对下一步排序的影响

先修复具体被定位的分隔丢失，再考虑训练力度。需要区分两件事：

1. 原粗边界已分开的区域在细化后又绕通，属于种子形成链的问题。下一项适合固定全部权重，
   单独检查保留这些已有分隔的机制，以及它是否引入新的拆分或周围轮廓变化。
2. affinity本身仍有改进空间，但现有附加项应先检查所选关系与最终划分的关联。
   不因参数梯度较小就直接把15%预算当成已证实的下一训练配方。

历史`marker_restore + 面积过滤`组合曾在旧语义LoRA链上损失0.870分，见
[MARKER_RESTORE_20260927.md](MARKER_RESTORE_20260927.md)。旧方案不只恢复分隔，
还释放部分原种子像素重新生长并过滤面积；不能凭本次定位直接重新启用该组合，
也不能把旧回退全部归因于过滤。后续应先单变量、完整输出比较，官方回分后才考虑晋级。

本次完成的是定位；没有启动新训练或生成新的提交包。
