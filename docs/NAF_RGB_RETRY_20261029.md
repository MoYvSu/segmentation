## 是否值得重试

值得一次受控短训。此前恢复RGB实验同时处于PixelShuffle、GAN0.01、无填谷的背景，
后继已分别定位相位敏感、输入宽带两侧被学成额外轨和目标缺少连续带偏好。
旧负结果不足以排除RGB在新配方中的价值，但也不能将旧退化全部归为周期性。

旧恢复RGB组确实参与学习：每步RGB入口有梯度；内部负loss下降，却使四人工实际分隔4/4→1/4、
四测试小F30→163，test116仍未补开。空间均值RGB下也存在竖向多轨；
这些是实质负面证据，须在重试时重新验收，不因发现周期因素就抹去。

## 主要看什么

1. 原T断口在RGB中仍有可见弱线时，能否真正分开两块内核；同时检查亮F之间的弱同相晶界/细通路。
2. 原T有可疑内部线时，RGB是否减少误切；特别检查P纹理是否反而生成更多内部假线。
3. 四人工分隔、116预登记点对、GT69/115、GT143，以及原标/填补/unknown分层，保持原坐标与规则。
4. 原始多轨/相位、S0最终小F/大F/粘连一起比较，不只报loss或单个断口峰值。

RGB入口有梯度、预测对RGB敏感，仅说明通道被使用，不证明信息有益；
需看实际分隔/删错线与弱界保护是否同时支持。先看统一1000步，不按测试monitor择优epoch。

RGB在这里仅增强NAF的补/删边依据，SAM2、LoRA、affinity及语义头均冻结。
它不会直接修正语义头的整块错类，最多通过更合理的实例边界改变原raw投票；
语义误判需要独立研究，不能将其改善预先归给RGB条件。
是否晋级仍看正式两项得分，当前已验证最高分仍为旧20a59＋S0。
