## 唯一变化

原方式对每个GT点独立在法向±2像素取最大响应，邻接点可分别选不同位置，形成不相连的亮点。
候选在方向可靠的三个相邻GT点上，要求**同一个法向偏移**使这三个位置共同成立：

`L(q) = min_d mean_s softplus(-z(q + s*t + d*n))`，`s=-1,0,1`，`d=-2,...,2`。

其中`t`是沿边界方向，`n`是垂直边界方向。直观上仍允许一小段线整体移动两像素，
却不允许三个点各自左右跳动来交差。先各自计算负log概率再平均，最后选共同偏移；
不先平均logit，避免一个极强点抵消空缺位置。

- 只对GT中三个真实相邻点、方向一致且非方向fallback的短段生效。
- 未知区、图外、可靠方向不足的弯角/交点沿用原逐点方式，不凭空补训练GT。
- 不删除任何原positive，沿用原共同正分母；远离GT的可信内部负例完全不改。
- 仍允许带内厚线/双线等退化解，不声称一个修改解决全部拓扑问题。

### 不是简单的“整体响应过宽”

四图P>0.65前景总像素823054→854816，只增加3.86%；各图前景占比例如116为5.778%→6.016%，
169为5.497%→5.751%。P>0.45总像素936644→1033462，增加10.34%。
这些支持中低响应肩部也有变化，但不支持把最终实例多53%简单归为全体响应统一加粗。

两组高阈值掩码的2EDT中位都为2px；多孔、点阵和多轨会强烈干扰该代理值，
不能由此断言物理晶界或响应包络同宽。新组完全位于原B>=0.45带内的8邻接暗腔像素占共同带
4.88%–5.68%，旧组为0；新响应组织方式已改变。全图暗腔还包含正常大晶粒内部，不能统统叫噪声。
局部骨架转角统计受数字方向与邻接影响，也不能代替真实曲折度或GT误差。

### 残留周期来自哪里

单独对终态运行严格0/1常数、直带、方环的128px单窗CPU探针，没有输入细化、裁块拼接或后处理。
常数1输入仍出现4/8/16像素相位起伏；16相位均值极差0.2691。方环平移1px再对齐，线带MAE约
0.235–0.238；平移16px降至0.00533。新模型内部仍有与四级stride2/上采样相符的格点偏好。
这排除“必须经过最终形态处理才出现周期”的解释，但未隔离每个结构/损失的因果贡献，
合成常数也不是实际准确率验证。无须把一切周期都当错误；优先处理影响可存活种子的小环。

### 当前损失仍允许什么

CPU合成反例在同一176点GT、相同负集合/分母下，对正确单线、5px实心带、平行双峰及带内11环，
旧/新重建loss均约4.1223e-9（不含GAN）。无重叠的长波单线新loss升至1.3636，
但只在换偏移处重叠两行，就又可取得近零损失。三个点共用d没有保证相邻短段共用同一条主脊。
这证明目标容许退化解，不能单独证明优化器或GAN偏好它。

实心直带、实心平滑弯带经过两种细化都从0孔保持0孔；双线横档的环在细化前就存在。
因此不能声称“宽带细化必然凭空造环”。合成微环经原belt后仅12–13px，会被core50过滤，
也不能把该反例直接当成最终FP证据。真实输入的多峰、孔槽、局部接触及其读出需要分开检查。
