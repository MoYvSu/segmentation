# RGB退化诱发的真实N0响应配对研究

2026-10-25。承接两轮独立补边器及GT正短段筛选，重新检查更贴近自然模糊失效的监督。
本轮调研和小规模缓存诊断已完成；不训练、不替换N0、不生成提交包，不制作测试GT。

## 方法判断

此前的“损坏热图→原热图”属于重建/去噪监督，而非严格意义上的对比学习。
对比学习通常约束两种特征应该接近或远离；配对输入输出不自动成为对比损失。

| 方向 | 如何针对当前问题 | 当前取舍 |
| --- | --- | --- |
| RGB退化后经N0，再恢复原RGB的N0响应 | 让固定模型自己产生弱化、错位和漏响应，避免仅手工擦热图 | 先做8源缓存，检验是否确有连续线变缺段 |
| RGB＋热图作为补边输入 | 提供热图中未保留的灰度、纹理和线条走向 | 后续单变量输入消融；尚未证明缺少RGB是失败主因 |
| MALIS式连通监督 | 把训练关注放到决定区域误连/误分的关键关系 | 保留；先解决与实际marker/分水岭部署不匹配及不完整GT风险 |
| clDice式中心线约束 | 训练时关心线条中心覆盖，而非只有逐像素误差 | 保留；不能把中心线覆盖改善当闭环/最终实例改善 |
| Mixup/CutMix | 混合图像或粘贴图块，提高样本多样性 | 后置；不是新漏界答案，也尚无证据是当前主要短板 |

Mixup把两图和标签加权混合，金相图可能出现不真实的叠线；CutMix交换局部图块，
需要同步处理实例ID及跨粘贴缝关系，不能将人工粘贴边当晶界。这里只判断其与当前机制的关联，
不声称这些增强在本任务已被实验证明无效。

MALIS原论文针对阈值affinity图的连通分量；当前部署先方向归约/门控，再插值拼接成边界，
再经reflect marker和分水岭。不能直接套一个图损失，就认定已优化当前最终分隔。
GT也有遗漏，过强全局拓扑监督可能强化缺陷；不据训练GT或单个关键像素晋级。

## 本轮唯一输入变化

记冻结局部N0及其原窗口拼接为F：

- 旧真实配方：人工损坏`F(原RGB)`，目标`F(原RGB)`。
- 新候选配对：输入`F(模糊RGB)`，目标`F(原RGB)`。

新配对可能提供“原图上教师看见、模糊后教师漏掉”的真实失效监督，
并非没有价值的恒等复制；但原图上教师也画错/漏掉的线，依然没有独立正确答案。
它是教师响应的退化鲁棒性研究，不能称突破教师结构上限或严格纯无监督。

冻结D5a、N0后端、Philox噪声、原1024窗口索引、0.25重叠、融合、插值及拼接顺序。
不调用全图语义或最终实例读出；候选响应拓扑只是中间层机制诊断。
不读人工GT标签，不用测试图，不改变旧缓存或封存源码。

## 预先固定的数据和退化

复用已有boundary-domain manifest的顺序和身份：

- train_gt组索引0/10/21/31，四源只作旧缓存桥接；本次不打开其GT标签。
- train_extra组索引0/6/12/18，四源检查是否仅有已标注源现象；不称完全未见样本。
- 每源使用原中心512 ROI，所有相交原生1024窗保持完整序列中的原索引。

在完整原生uint8 RGB上施加均匀Gaussian blur，再裁窗；sigma为0、2、4原生像素，
边框reflect，不缩放、不改光照、不叠新随机噪声。两档是诊断强度，不能从其结果宣称覆盖全部真实模糊。
sigma0逐值复现既有N0拼接ROI才能继续；不允许用容差或修改seed让其通过。
所有模式同窗口使用同一实际Philox噪声，保存身份回执。模型/封存源码前后核验不变。

## 观察与验收

| 检查 | 解释边界 |
| --- | --- |
| 原响应≥0.65中，模糊后<0.45的像素 | 响应丢失密度，不是实际漏界率 |
| 原响应<0.2中，模糊后≥0.45/0.65的像素 | 新增响应，不默认都是假线 |
| 原闭合低响应区域及其邻接对是否合并 | 相对原N0的拓扑变化，不是GT准确率或正式面积项 |
| 幅值、位置、线宽及同色标全8源图 | 区分全局变暗、错位与实际连续线缺段，不只报MSE |
| 现有两版补边器在同配对上的输出（如执行） | 只比较配对恢复，不当作完整部署/官方收益 |

若差异主要来自噪声/裁窗边缘、均匀幅值漂移，或只在极少源/极端模糊下才有可用缺段，
不直接开训。若有跨源、形态合理的原线→缺段配对，才考虑相同预算的随机初始化短训。
是否再加入RGB输入另作独立消融，不同时叠Mixup、CutMix和多个拓扑损失。

私有产物根目录为`output/boundary_rgb/`，服务器run同名。工具为
`tools/probe_boundary_rgb.py`和`tools/analyze_boundary_rgb.py`；以实际完成回执为准，
本节不把在写工具或已排队运行当作完成结果。

### 排除纯幅值解释

另做私有一维对照，不改采集/分析工具：每源按原响应固定64箱，棋盘偶数像素拟合单调
`g(原响应)→模糊响应`，奇数像素计算变化能量解释率。
sigma2/4源中位解释率仅3.50%/2.76%，IQR分别2.08%–5.30%/2.44%–4.51%。
该对照各源均未产生原强响应跌至0.45以下，故当前变化不支持主要归于统一幅值重标定。
但173中的单个区域合并也可被该幅值映射单独触发：总体解释能量小，不代表每次粘连都是空间重画。
原来就在阈值附近的薄弱位置，少量幅值变化也可能改变整块区域连通。
这是所测映射族的诊断，不是任意单调函数的数学最优界；棋盘像素不是独立图像验证，
也不是拟议的反向部署修正、测试调参或新数据留出。

## 本轮结论与下一轮优先级

1. 此处确有空间性响应变化，不能说模糊对后端没影响；但8个中心ROI、两档均匀模糊尚未产生丰富的欠分割配对。
   不以两档/八源排除更强模糊、非均匀模糊或真实新测试域，也不为了凑合并数量继续无边界地加重模糊。
2. 当前证据不支持直接把这批配对用于新五轮主训练，更不支持恢复旧补边器部署。
3. 下一轮更有区分力的最小实验是沿用真实自损伤控制，只给补边器增加原RGB上下文。
   固定目标、损伤、32源采样、预算、上游、读出与loss；其余不同时叠加。检验的是输入信息是否有用，
   不是预先认定单通道已达上限。架构参数不同需明示，公共层可对齐随机初始状态，不谎称全部参数完全相同。
4. 若执行，仍随机初始化五轮，复用已有真实e5控制，保留e0/e1/e3/e5过程图；
   同时看真实漏口、已有线误改、双线和内部小块，不能仅凭RGB配对MAE晋级。
5. MALIS式部署匹配连通目标随后研究，Mixup/CutMix作为辅助增强后置。

上述RGB输入消融仅形成方案，本轮没有实现或启动该训练。当前N0和所有已有控制组保持。
