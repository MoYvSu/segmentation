同一数值0.45目前有两种含义：**支撑阈值**判断种子内部是否有N1低响应像素；
**marker低阈值**控制弱边重建可传播的范围。它们必须是分开的参数，不能一起改。
语义概率冻结不保证最终类别不变：重划实例会改变参与投票的像素集合。

**实现前置项：当前生产wrapper的`_supported_readout`仍从
`config.marker_boundary_low_threshold`同时读取这两个阈值。** 离线扫参入口必须显式拆成
`reference_support_low`与`marker_low`并分别传参，记录各自实际值。不能直接修改原配置的
`marker_boundary_low_threshold`，却把S组或L组宣称为单变量。
拆分后的两个参数都取0.45时，必须先精确复现当前生产主控制，再运行任一候选。

## 分阶段预算与停止条件

1. **缓存与控制验收。** 复用8源并核对输入、NAF、两路语义与源文件摘要；主控制最终PNG及
   解析后的类别应精确复现既有NAF_filtered。全150缓存已验收，但新扫参入口仍需先复现其主控制。
2. **先看种子分布。** 保存每个种子原N1概率最小值/分位数、低响应数量和比例、最大连通块、
   保留决定。原始概率保留，不能改称“语义正确概率”或校准后的可信度。
3. **最多8候选×8源CPU读出。** 只重放种子和既有完整分水岭；N1、N1_filtered和NAF未滤结果
   作为参考复用，不重新跑模型。若种子未变，不重复运行相同分水岭。
4. **少量固定对比图。** 所有候选保存数值报告，只有不同输出的候选生成固定同位置全图/局部；
   另列变化最大的案例，不能用它们替代原固定样本。
5. **至多1—2个完整候选。** 只有不同机制、风险可解释的候选才考虑扩大到150图和出包；
   无有意义变化可全部暂缓。黑盒由用户提交，不自动上传或替换主线。

已有8源四臂完整CPU分析为400.07秒，包含32次最终读出、验证、GT诊断和画图，
不是纯分水岭耗时。8个新候选的读出数量约为其两倍；建议预留**30—90分钟**完成小网格及报告，
这只是量级估算，需用实际首批计时修正。全150缓存重放、传输与压缩另计，不能用这个时间
冒充全链模型推理速度。若CPU细化或连通分析成为瓶颈，先减少重复计算，不改变算法精度。

本轮不以占满GPU为目的开训练；CPU小网格可以让GPU保持空闲。未来若有明确训练假设，

## 客观拒绝、去重与风险门槛

| 检查 | 处理 |
| --- | --- |
| 有正种子但候选全部撤销，或产生空图 | 明确拒绝；不静默留下一个种子或自动回退来掩盖失败 |
| 尺寸、单通道uint16、ID<=65535、类别映射或保存重载契约失败 | 技术拒绝，不进入图像比较 |
| 旧实例出现大片无人接管区域 | 暂缓并追踪原因；分水岭既有1像素窄缝单列，不能要求新增0绝对为0 |
| 原标可信内核出现新的主体级误合并/误切 | 暂缓并核对逐对象重叠；微小残留不能写成整粒误并，GT漏标/未知不能判错 |
| 固定弱界、细通路、小粒或完整边界明显普遍受损 | 暂缓，定位在哪一级产生，不用总体数量减少抵消风险 |
| 规范化ID后，8源最终分区和类别完全相同 | 直接去重；近乎相同者报告影响范围，不为凑候选占黑盒 |
| 仅实例数减少、F预测均面积变大，或热图更锐 | 不视为精度通过条件；保留为分布观察 |

原标可信内核不覆盖所有真实细通路，两张训练源也参加过训练；通过这些门槛只说明没有发现
对应风险，不是泛化证明。填补区域单列、未知忽略。测试图没有GT，不能把可疑块自动命名为FP。

逐候选至少保存：F/P数量、F像素、预测平均F面积、类别翻转、大小分层、被撤销种子去向、
新0区域的面积/内切半径、旧实例到新实例的重叠关系；500px等分层只展示，不参与筛选。
不同分辨率的像素面积不等于相同物理尺寸。

## 黑盒回分后的方向调整

- 当前研究用N1作局部零噪声参照，不将N2极小的总分优势解释成质量突破；三包身份和分项
  保留在[半决赛噪声回分](SEMIFINAL_NOISE_SCORES_20261026.md)。
- 若筛选包主要降低FP且保持TP，再检查支撑分布能否区分失败种子；仍不自动升级核心门槛。
- 若FP降低同时TP明显受损，说明原N1支撑约束可能排斥真粒，应收缩这条路线，而非继续强删。
- 若NAF原样与筛选包均无净收益，停止围绕NAF密扫小参数，回到真实断口、监督覆盖或读出失效
  的新机制假设；不能用不断调阈值代替补边能力。
- 总分、mIoU、面积项和TP/FP/FN分别报告。小幅单次回分不证明稳定机制，任何晋级以相同赛段
  完整输出及正式回分为准；不把预测分布当分数，也不拟合期望实例数或平均面积。
