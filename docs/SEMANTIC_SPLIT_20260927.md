## 复现与诊断量

1. 每组先在自身保存的最终轮廓上调用原投票函数，逐实例复现类别、均值、硬分类比例、区域面积；
   第一张另完整重跑后处理，核对最终uint16实例图和类别。所有图比较三组affinity概率。
2. 固定LoRA轮廓后比较整体分数、硬分类比例、0.4–0.6像素占比。
   类别用部署原float32均值，float64描述均值另外保留。
3. 根据距实例边缘的距离分为5层；外围取距离底部30%分位，核心取顶部40%分位。
   同距离像素全部保留，因此比例不是强制等面积。薄小／核心不足区域不报告核心翻转。
   图像外部按边缘处理，图外组织结构未知，贴边实例需结合原图解释。
4. 强预测定义为铁素体分数≥0.8和≤0.2。两者最大8连通块均≥32像素且各占实例≥10%，记为混合预测。
   再排除距离≤max(2像素,最大内部距离15%)外缘，以内部面积为分母统计内部混合。
   这些阈值固定用于描述，不是测试标签或新部署阈值。
5. 在整张原尺寸图复现高阈值0.65、低阈值0.45有限8步重建、bridge1、骨架带1、seal2、面积50的实际种子。
   连通域必须在整图计算再裁切，避免漏掉裁块外的连接路径。内部两个强预测分量各≥90%位于同一正种子，
   才记录为共用种子；不足则标记未确定。该结果只能定位预测聚合发生的阶段，不能证明组织真值不同。

## 内部混合与种子阶段

最新LoRA在固定轮廓内有466个内部混合预测实例，占8668实例的5.38%。
其中460例两个相反强预测分量各≥90%位于同一个已有种子；其余6例因覆盖不足无法按该规则确定，
没有达到“两侧充分覆盖、但分属不同种子”条件的例子。

这表明这些预测冲突大多在生成种子阶段就已装入同一个区域；最终整实例投票会选一种类别，
无法把区域重新切成两个实例。局部图确有内部边界响应仅残留一截、marker修复后仍相通的案例，
与用户提出的通道／缺边假设相符。

不能将466或460直接称为真实漏分数：语义预测可能错误，同一种组织也可能存在外观变化；
当前种子算法本就由连通核心形成种子，统计定位了聚合发生阶段，尚未证明缺口的真实边界位置。
不据此把语义分界强制当作晶界。后续仅在私有诊断目录生成改变marker的反事实输出，主线保持原样。

## 分隔在哪一步丢失

`tools/probe_semantic_channels.py --records outputs/semantic_split_checked/instances.jsonl`
对84图的全部466例内部混合对象，固定原先两类预测分量的代表点，按整图连通域追踪：

| 阶段 | 两点相通 | 两点分开 | 至少一点落入障碍 |
| --- | ---: | ---: | ---: |
| 高阈值边界 | 230 | 60 | 176 |
| 有限步弱边重建 | 114 | 50 | 302 |
| 桥接后、骨架化前 | 98 | 50 | 318 |
| 骨架化后 | 466 | 0 | 0 |
| 膨胀及最终seal2后 | 466 | 0 | 0 |

**50例在骨架化前分开、之后相通，且50例全部贴边，分布于35图。**
其余blocked→connected不能按同等证据称为分隔丢失。466例来自混合输出条件筛选，
最终全部相通也部分由筛选／种子定义决定，不能将50/466外推全测试漏分率。

服务器OpenCV为5.0.0，无`ximgproc.thinning`，实际使用skimage回退。
合成粗线验证了机制：触边粗线抽细后末端内缩，仍是一条连通线，但两侧背景可绕过端点；
后置2像素封边不足以接回。更精确的说法是“没有保留与图框的接触约束”，
不能泛称骨架化违反了其自身前景连通性保证。此结论限于查明的贴边情形。

当前没有中心头，种子由反相边界带的8连通域整片编号。
两侧一旦共用同一编号，后续分水岭不会自行发明第二个编号；
即使逐像素语义已区分两侧，最后平均投票仍强制整片选一个类别。

## 整体优化顺序

1. **先保留模型已经给出的分隔。** 处理骨架化／种子读取丢失，独立于语义重训；
   前置封边是机制探针，若新增碎片明显则不直接部署。更保守方向是用骨架化前已有的
   独立内部区域支持新种子，拒绝仅因新封边凭空形成的小腔，保留原种子作为回退。
2. **再定位剩余缺边。** 按原生短程top2、长程融合、尺寸恢复、marker阶段逐级查看。
   当前gated融合为归一化加权平均，较弱长程响应可压低短程峰值；若边在融合后才消失，
   先做读出消融。长程距离2/4的负连接天然占带宽，宽响应并不全等于定位错误。
3. **需要训练时单独更新affinity。** 接续现V e115，保留Stage1/joint-v3来源；
   冻结D5a、simple及独立语义LoRA。先选择已定位的一项变化：D5a域适配，或按GT实例对
   采样造成连通错误的位置；不同时叠加新结构、新GT、全局难负边增权和多种增强。
   兼顾跨实例错误连接与同实例错误断开，避免漏分改善靠普遍碎分换取。
4. **两头协作放在证据约束下。** 相反且高置信语义可提示需要检查的大连通区，但几何
   必须提供分隔支持；同相晶粒仍由affinity处理。不要将所有明暗／语义分界强制切成晶界。

后续短训练默认20轮、保留过程缩略monitor、不留出人工图；全32人工图参与训练，
但当前V历史使用旧26图，切换至全32／新GT必须显式记录为共同条件变化，不能伪称只改loss。
1000源可做合规外观一致性，新增SAM2几何候选仍受来源上限与人工审核约束。
新affinity与新marker用2×2只读推理区分贡献，完全相同的旧控制不重训。
历史G6尾部惩罚、G7简单高分辨残差、共享中心辅助头的负面记录仍有效，
不把它们改名当作未经尝试的新方案。本轮未启动训练、未提交黑盒、未替换默认部署。

### 下一步种子恢复的具体设计（后续已落实）

恢复核心及用户要求的全实例、自适应面积过滤已在[后续实验](MARKER_RESTORE_20260927.md)落实。
下面保留的是恢复阶段本身的设计；统一面积过滤仍可删除原有小种子，不受旧ID保留限制。

原弱边重建＋bridge后的粗边界反相，在整图计算参考区域R，不加新框。
对每个原正种子M，分别取它与各R交集的最大连通块；仅当至少两个不同R各自提供
达到既有50像素门槛的核心时，才拆这个M。最大核心继承原ID，其余分配新ID，
该M剩余位置释放给原分水岭生长。未满足条件的M全部像素原样保留，禁止按同R合并旧种子。
这避免直接用粗边界反相图替代全体marker，后者可能吞掉原有小晶粒。

实现门槛：未触发种子逐像素相等、全部旧ID仍存在、新增ID有两个以上原独立区域支持；
网络／真实barrier／阈值／投票不变。全量报告最终拆合、碎片、释放面积和实际切线位置。
即使这些检查通过，原affinity也可能已有错误纹理小腔，不能把原分隔当成GT；
不通过在测试图上连续调门槛追求好看的实例数。若这一保守版本仍普遍碎分，退回原marker，
保留诊断结果并转向缺边来源分析。
