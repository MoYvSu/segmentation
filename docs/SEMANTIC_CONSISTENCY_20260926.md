## 共同外观增强与可靠目标

分布检查发现，现有合成模糊能覆盖修复后的细节强度，却基本不改变偏亮、
高对比的训练外观。因此A/B共同在D5a前以50%概率加入全局仿射：
`output = contrast × input + offset + channel_shift`。
contrast范围0.5–1.0，offset为0–0.15，三通道偏移先在±0.03抽取再减去通道均值。
正斜率保留各通道像素的明暗次序，不移动边界；限定有效内容被截断的像素不超过1%，
必要时向恒等变换缩减幅度。填充区不参与该比例计算，且不读取GT已知区作为光度统计范围。
这是一组宽泛采集条件模拟，不对测试图做逐图匹配，也不保证完全消除分布差异。

B的教师是原simple e60语义头的冻结副本，共享始终冻结的编码器：

1. 较清晰原图与最多±0.02的轻微亮度变体分别经过冻结D5a，使用同一修复噪声种子。
   小变体截断预算0.5%；回退为恒等时如实记录，不能宣称所有样本均有非零弱扰动。
2. 两视图置信度均≥0.9、同类且铁素体概率相差≤0.05才成为候选。
   分别将两类可靠区向内收缩一个原生语义格点，排除类别交界与填充。
3. 学生读取同源、同翻转/旋转的模糊＋共同外观模拟输入，再经过D5a。
   在可靠区学习教师两次概率的均值；使用按接受像素数平均的soft BCE，
   不硬化概率、不额外指定类别占比，不生成SAM2实例伪标签。
4. 每次先反传人工监督，再在独立随机流中反传加权一致性，最后只做一次优化器更新。
   教师不采用随学生更新的EMA，避免本轮同时引入教师反馈变化。

训练池跨轮持续置乱：前1000次恰好遍历1000源，然后进入下一轮随机顺序。
20轮共1280次读取，包含968张此前simple监督流未使用的来源；
32张人工源也属于这1000图，不能把两者相加为1032个独立来源。
人工图曾重编号，无标签流不按人工文件同名排除，也不读取其标签。
日志分别记录读取源数、产生可靠监督的源数及两类接受像素，
这些类别计数来自教师预测，不代表真实组织比例。

学习率1e-5，2轮预热，余弦下降至第20轮1e-6；两组完全相同。
一致性权重前5轮从0.02增加到0.1，其后保持0.1。训练seed为20260927；
D5a正式推理仍使用314159加原全量排序索引。

### 无标签监督实际提供的信号

- 全1000源均被读到且均有可靠像素；1280次抽样意味着训练池仅遍历约1.28次。
  这里的20轮按32张有标签图、每轮重复2次计数，不是1000张各训练20遍。
- 可靠区域占有效内容像素75.88%，不是监督掩码几乎为空；教师预测铁素体／珠光体分别保留
  82.15%／59.22%，累计接受像素组成约78.67%／21.33%。这些比例不是GT类别比例。
- 可靠区域教师平均置信度0.999912；学生在强输入上的铁素体概率与教师平均绝对差仅0.0003856，
  每次采样均值的中位数0.0001060、90分位0.0004659。1280次中只有57次该均差超过0.001，
  5次超过0.01。初始第1轮该均差约0.000189，说明信号在早期就偏小。
- 全程平均未加权一致性loss为0.001052，加权后约0.0000923，为同期人工监督loss总量的
  0.1567%；这是损失数值比，**不能当作梯度贡献比**。正式日志只测了首次非零U梯度，
  短测又存在明显样本间梯度波动，不能从首次梯度推断全程梯度比例。
- B的强外观实际施加648／1280次，弱视图非恒等727／1280次；模糊输入1037次，
  其中空间模糊528次、端点增强258次。不是无标签数据没有走增强分支。

当前证据更符合：高置信、稳定、内缩后的监督区域多数已能被学生复现，
额外loss主要要求维持已有判断。这里的“自洽”不等于真实正确；固定教师也没有为其共同错误
提供新的标签信息。低置信和类别交界区域被过滤，恰好可能是测试中的困难部分，但本轮未直接验证该因果。
目前不建议直接把同一配方延长到60轮；同时不能宣称模型已饱和、无标签数据无用，
或把本结果推广为所有半监督方案无效。若继续语义研究，先在允许的训练源上检查
“教师稳定且学生确有分歧”的像素是否有足够覆盖，再决定难例采样／加权及每轮无标签预算；
不能只降低置信门槛或扩大总权重后就假定引入了正确的新信息。本轮未实施该候选。

### affinity宽带问题：代码定位与后续候选

当前V头从SAM2最高256网格特征构造512网格的8方向／距离响应，部署采用gated＋top2，
再将融合标量图双线性放大到原图。100张图中31张为1224×1024、47张1244×1044、
22张2448×2048；一个512网格格点约对应原图2.39–4.78像素。
距离4的轴向关系对应约9.56–19.13原图像素，它监督的是两点是否属于同一实例，
并不直接监督光学黑线的物理宽度。长程融合又在短程响应的膨胀邻域中加入支持，
所以最终热图宽带可能混合了特征分辨率、方向／距离关系和插值的影响。
代码依据：`models/affinity_geometry.py`、`utils/affinity_loss.py`、
`utils/affinity_fusion.py`、`utils/affinity_deployment.py`。

后处理会把阈值边界骨架化，再形成分水岭种子；单纯响应较宽不必然导致最终轮廓同样宽。
更应关注密集处不同边界是否提前粘连、产生错误支路或失去间隙；已有粘连不能依靠缩细显示线宽修正。
本轮affinity冻结，训练没有针对这个问题提供新监督，也没有测定真实边界宽度比。

后续优先做一次固定模型诊断：同一位置比较原生512短程、加入长程后的融合图、放大图及
阈值／骨架／种子，区分模型定位与读出处理的来源。在已有训练GT上可量化定位偏移、
边界带宽和近邻混并；这些训练内诊断不作为泛化代理或留出集。
若原生短程已混合，再讨论保留Stage1/joint-v3的局部高分辨率监督；若混合主要发生于融合后，
先做读出单变量对照。用户本轮仅要求考虑，未启动affinity改造或训练。
历史G7高分辨率短程残差已试过且有欠分割加重的记录，见README及
`docs/AFFINITY_G7_HIGHRES_SHORT_20260829.md`，不能把简单加1024输出重新称为未试新方案。

私有复核产物：服务器`outputs/semantic_consistency/analysis/{summary,per_image}.json`及日志副本；
本地`output/semantic_consistency_analysis/`包含分析脚本、训练曲线、原8图比较与新增两图比较。
逐图类别／概率、掩码和图册均仅保留在被忽略目录。以上没有官方新得分，不晋级候选。

## 解释边界

两组直接差异是额外的可靠语义一致性分支。共同的新外观增强和接续训练均不同于
历史simple原训练，因此不能把A相对历史simple的任何变化单独归因于增强。
固定教师的高置信预测仍可能出错；收缩可靠区也可能减少细小珠光体的监督。
本轮不训练affinity，且不以分布距离、训练损失或无标签图上的翻转数替代官方完整输出得分。
