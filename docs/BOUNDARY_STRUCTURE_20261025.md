## 连续路径监督

“有若干亮点”不能代表边界连续。本轮先按处理后GT的异实例共享界面生成候选走廊，
再用动态规划选择一条逐像素相连、修改代价较小的路径，沿路径施加正响应监督。
选路本身不反传梯度；选中路径上所有弱响应位置正常反传，不只惩罚单个瓶颈。

1. 两侧都要有原始覆盖提供的深部内核，最小64像素。训练保护内核采用33×33方形侵蚀，
   即`core_radius=16`，区别于前轮诊断的radius4；这样给原GT约10像素的落点偏移留出空间。
2. 在原有效监督域内追踪完整无分叉界面链，最少8个位置；不人为切成8–64像素短段。
   每点沿局部法线允许±12原生像素，得到25个整数候选，只允许两实例known并域、
   原有效区且不穿过受保护深部。unknown、padding不参与。
3. 相邻位置的实际候选像素必须八邻接或同像素。仅保留能参加完整合法路径的候选，
   没有合法整程路径则明确跳过，不跨未知补齐。
4. 闭环固定clean N0中最强合法响应≥0.65的锚点，检查末首八邻接；
   这是固定锚条件下的选路，不宣称全局最优闭环。无强锚则跳过，不拆环伪装成功。
5. 裁窗／原有效域截断的开放链明确标为局部替代监督，不能直接认定整晶粒已分开。

选路代价为路径上`relu(0.70-p) + 0.01*relu(p-N0)`之和。
主代价严格相同时优先复用更强的N0，再选靠候选中心的位置，避免固定向一侧偏移。
其中0.01项仅是停止梯度的选路启发，不增加可微损失项。

实际附加损失为：

```text
0.25 × [ 所选路径所有位置的mean(relu(0.70-p))
       + 0.05 × 自由走廊内mean(relu(p-N0)) ]
```

第二项惩罚走廊整片抬亮。路径分母为完整有效batch全部路径位置数，
质量惩罚分母为自由像素数；微batch累积不改变有效batch归一。
与新目标冲突的旧N0逐像素监督，仅在可行走廊且N0<0.65处让位；
同步调整valid/gap/noise，原目标和输入不变。N0≥0.65仍受原损失约束。
它是损失保护，不保证共享卷积参数更新后强线逐像素不变。
不施加同GT内部强制连通，不清除原内部线，不把filled落点当精确人工真值。

小于约32像素宽、或侵蚀后原标内核不足64像素的细通路／小晶粒不加入这项结构监督，
但仍参加原自损伤任务，没有删图或删实例。当前配方的释放阈值明确固定为0.65。

### 为什么优先处理损失而不是学习率或轮数

路径项鼓励合法界面上的弱响应变强，mass项则惩罚自由走廊中的新增响应。
后者用于防止整片泛亮，但本实现也处罚了允许新增的路径位置；有效梯度强弱不能由
0.05这个系数或两个loss标量大小直接推断。e5抽查中，加权path参数梯度范数
为0.0223–0.0466，mass为0.0658–0.1100，且两者反向。
单独沿当前合计结构梯度的下降方向走足够小的一步，在八批中都会提高路径缺额。

总梯度与旧base方向余弦0.999197–0.999993。全局梯度裁剪同乘各项，不改变相对比例；
全部320步裁剪前范数大于1，也不能单独解释成“学习率失效”。
本次base/path在e5抽查中反而同向，不能声称旧base普遍与补线冲突。
有效路径点没有被输出clamp截断屏蔽，未发现该原因。

人工损伤输入中，原强线被擦掉部分的路径缺额总和从242.485降至0.0604；
自然输入的路径缺额却为e0/e1/e3/e5的98.808／89.072／99.470／95.805。
这说明320次更新已经能明显学习人工恢复，不能以“所有任务更新都太少”概括。
也未证明模型完全收敛；只是原样延长尚缺少针对天然漏界的依据。
e1更低不作为按测试效果挑epoch的依据，正式比较仍用e5。

16源317条路径全部为开放链；全训24,052次路径曝光中仅6次闭环曝光。
沿局部链提高响应也不保证两端接续或最终两颗晶粒分开，后续仍须保留完整读出验收。
