## 目的与固定项

D5a的空间增强改善了强弱共存退化，但16步仍差于首步。本轮检验一种可能原因：
原训练状态由清晰图直接合成，推理中的后续状态则来自模型自身预测；模型需要练习修正自己的误差。
这仍是待验证假设，不预先宣称已找到多步退化原因。

候选复用D5a网络和增强参数，从随机初始化训练，全1000张原图、无留出、无代理选优。
60轮、batch 4、15000次优化器更新，seed 42，学习率2e-4余弦下降至2e-6，原局部任务日程不变。
保持kappa 0.03、16步时间表、终点50%抽样及RGB L1＋0.2梯度L1。
不加载D4或D5a权重，不加入边界头、连接性损失或后端微调。

## 唯一训练改动

`config/train/rgb_diffusion_d5b.yaml`在D5a配方上加入：

```yaml
train:
  short_chain:
    enabled: true
    probability: 0.25
    extra_steps: 2
    loss_weight: 0.25
```

原主步训练保持不变。在25%的批次中，从当前预测按现有随机后验公式生成下一状态，
再额外预测至多两次清晰图；时间步到1即停止。条件始终是最初退化图，目标始终是清晰训练图。
不把中间状态或原始预测截断到[0,1]，桥接运算保持FP32。

每次状态转移先detach，即不通过前一个预测继续反向求梯度；各次损失依次反向传播，
最后只执行一次优化器更新。这样不用保存整条多步计算图，各后续预测仍能训练网络参数。
主步权重保持1，辅助损失按实际有效的“图像×步骤”数量平均，再乘0.25；
没有可用后续步骤的批次不贡献辅助损失。不强制每一步误差单调下降，避免鼓励输出停滞。

短链选择与后验噪声使用独立随机流，原源图顺序、主步时间采样和主步噪声不受影响。
启用短链的checkpoint保存额外随机状态及统计，恢复时严格检查；
未启用的旧checkpoint仍可按原配方加载与续训。

日志分开保存原任务loss、原始辅助loss、加权辅助loss，以及短链批次数、有效图像步骤数、
额外网络调用、耗时和峰值显存。总loss不同不能直接解释为重建误差变好。
同15000优化器更新不等于同计算量：按25%的抽样概率、每次最多额外两次前向/反向，
期望额外网络训练计算量约不超过50%；实际抽样比例可能更高，尤其在短测中。
实际开销以短测及正式运行统计为准。
