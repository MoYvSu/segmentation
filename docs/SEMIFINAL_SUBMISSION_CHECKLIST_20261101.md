# 半决赛提交材料清单

核对日期：2026-11-01；时间均为北京时间。适用赛题：低碳钢金相图像无监督相区分割。

本清单记录提交内容、现有材料入口和剩余工作。最终交付须绑定半决赛排行榜最高分对应的结果、权重、代码和配置。本次核对官网公开要求与本地材料，平台最高分记录和材料提交回执待登记。

## 1. 截止时间与提交入口

| 项目 | 截止时间 | 提交内容 |
|---|---|---|
| 赛题结果文档 | **2026-11-01 20:00** | 模型预测结果，提交至报名系统的赛题结果入口 |

## 2. 专项附件明确要求的材料

以下项目来自[半决赛作品提交要求](https://www.aicomp.cn/wp-content/uploads/2026/10/附件2：AIC产业命题赛道（AI＋钢铁）半决赛作品提交要求.pdf)第2页“低碳钢金相图像无监督相区分割”条目；单代码版本要求见第3页。

| 材料 | 要求 | 本项目交付内容 |
|---|---|---|
| 测试集预测结果 | PNG实例图与对应JSON类别文件；使用排行榜最高分对应结果 | 150张图各一对文件，共300个预测文件；保留该次正式提交包 |
| 技术报告 | **PDF，至少1000字** | 说明架构、创新、实验、标注筛选与数量及用途，并分析半决赛测试集表现 |
| 模型文件 | 已训练权重，格式不限，支持复现 | 图像恢复网络、共享编码器与两个任务头、边界纠错网络，以及实际加载的必要资源 |
| 完整代码 | 覆盖预处理、训练和推理，具备详细注释 | 最终采用的一套源码、配置、数据构建和后处理实现 |
| README | 提供运行说明 | 环境安装、资产位置、训练与推理命令、输入输出及结果复现说明 |

结果与代码材料均以最高分版本为准；**只提交一个代码版本**。多阶段训练可以在同一工程中保留各阶段脚本，由一个明确入口按顺序调用。

### 预测结果格式

依据[赛题官网](https://www.aicomp.cn/tracks/tracks-6/4185.html)的结果格式及[半决赛数据记录](SEMIFINAL_DATA_20261025.md)：

- 编号覆盖 `test_169` 至 `test_318`，文件名为 `test_XXX_inst.png` 与 `test_XXX_class.json`。
- PNG与原图同尺寸，单通道、16位，实例编号在0至65535之间，0表示背景或忽略。
- JSON键覆盖PNG内全部非零实例ID；类别只含 `0=Pearlite（珠光体）`、`1=Ferrite（铁素体）`。
- ZIP内无重复结果、损坏成员或越界路径。评测ZIP采用最终正式入口实际接受的组织方式；完整作品另按下述网盘目录组织。

### 技术报告内容核对

- [ ] 总体方案与输入处理路径，说明各模块的输入、输出及分工。
- [ ] 无标签训练图的使用，以及人工标注的选择、数量、处理和监督用途。
- [ ] 无类别几何候选、教师监督与标签优化的生成和使用方法。
- [ ] 训练步骤、主要参数、初始化来源和模块衔接；详细谱系可置于附录。
- [ ] 半决赛最高分结果与代表性分析；历史赛段实验注明各自数据范围。
- [ ] 代表性可视化及主要失败情形，重点围绕标注质量、训练视野和真实模糊干扰。
- [ ] 执行环境、推理耗时与复现方法。

工作稿继续使用可编辑文档；内容定稿后再导出官方要求的提交格式。报告计划见[写作规划](REPORT_PLAN_SEMIFINAL_20261101.md)，素材入口见[报告来源索引](REPORT_SOURCE_INDEX.md)。

## 3. 官网另列材料与复现配套

### 答辩PPT

[赛题官网](https://www.aicomp.cn/tracks/tracks-6/4185.html)“复赛、半决赛提交内容”列出**不超过10页的答辩PPT**；本轮半决赛专项附件未单列该项。按官网先纳入待准备材料，具体上传位置与答辩安排按平台及组委会通知执行。报告配图的可编辑PPTX源文件另行保管。

### 环境与训练资产

以下内容作为完整代码和复现说明的配套整理：

- 固定版本的 `requirements.txt`；使用额外执行引擎时，补充对应依赖、构建命令和硬件条件。官网开发环境章节明确要求完整依赖清单。
- 训练所用自主标注、类别映射、标签优化参数及生成脚本、无类别几何候选与源图清单。
- 代码实际读取的初始化权重、固定教师或中间训练资产：随包提供，或提供可执行的生成步骤，并写清来源。
- 官方训练图的目录对应和校验方法；数据与标注仅通过授权赛事材料渠道交付，保存在本地私有目录。
- 若最高分来自编译引擎，保留其原权重、构建配置、执行依赖和实际运行命令；引擎文件按部署需要提供。

训练说明应分别写清历史采用权重的生成流程与当前统一重训流程，包括已执行范围和初始化资产。复现配套按实际依赖收齐，避免遗漏必要权重、标注或数据转换步骤。

## 4. 网盘文件夹组织

根目录名称按专项附件统一为：

```text
参赛团队编号-团队名称-半决赛-队长姓名/
├── 参赛团队编号-技术方案.pdf
├── 参赛团队编号-模型文件/
├── 参赛团队编号-代码与数据/
│   ├── README.md
│   ├── requirements.txt
│   ├── 训练与推理源码、配置/
│   └── 标注、监督资产与数据说明/
├── 参赛团队编号-赛题结果文档/
│   └── 最高分对应的正式结果包.zip
└── 参赛团队编号-答辩材料/
    └── 答辩.pptx
```

根目录命名为官方要求；子目录沿用附件示例并按内容细分。答辩材料按上一节的官网条目备齐。

官方推荐百度网盘、分享链接自动填充提取码，链接可设为永久有效。完成上传后检查评审方可访问、文件可下载、压缩包可解压，再向报名系统提交链接。当前整理阶段不执行上传或平台提交。
