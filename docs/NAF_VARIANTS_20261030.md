# 旧最高NAF与NoGAN：真实配方及单轮输出对照

本轮先厘清恢复器身份和图样差异，暂不开展读出消融。只读服务器真实checkpoint、
已有单轮缓存和已提交ZIP；没有训练、模型前向、分水岭重算或修改参数。

## 两套模型相差四项主要配方

| 项目 | 旧最高20a59 | 当前NoGAN8eb |
| --- | --- | --- |
| 四级上采样 | 卷积＋PixelShuffle像素重排 | 低分辨率投影＋双线性放大 |
| 显式擦断输入训练 | 关闭 | 开启，概率.5，擦1–2段，长度16／24／32／40px |
| 法向填谷监督 | 无 | normal_hull_v1，权重.1，抑制边界带内暗槽 |
| GAN损失权重 | .01 | 0 |
| 恢复器参数 | 17,632,273 | 16,457,233 |

“NoGAN”只相对其直接前驱GAN＋填谷组8ae39216是单变量消融，
不能把它与更早20a59的全部差异归因于GAN。演进为：
旧最高→加入显式擦断→改双线性上采样→加入填谷→去GAN。
上采样属于NAF内部网络，和分水岭后处理中的扩宽不是同一环节。
判别器只在训练使用；两个恢复器推理都不加载判别器。

共同条件经checkpoint资产身份核对：同32张处理后GT、同N1输入缓存与前端权重、
同16000 draw、1000更新、有效batch16和FP32。两者都是**单通道边界输入，没有RGB**，
同T8规范化与256原生窗口、同推理合同；相同seed不代表完整初态相同，
代码保持公共骨干初态，但上采样模块及完整模型初态不同。
前面的D5a、SAM2、affinity和语义模型均固定，变化位于affinity之后的边界恢复器。

## 单轮图样的显著差异

固定同一原N1、同一语义、S0及读出，双方final50，未叠加200；只读取已验收r1缓存。

| 检查方法 | 观察 | 判断边界 |
| --- | --- | --- |
| 原始浮点热图同坐标、固定[0,1]色标，另作最近邻像素放大 | 旧版呈密集点阵／棋盘式响应带；NoGAN主要为连续主脊，仍有平行肩线及交汇小圈 | 原始响应表示确实不同，不能仅凭更平滑判准确率更高 |
| 相同S0最终轮廓 | 169交汇和完整弱边处常接近，旧轮廓比其原热图规整得多 | 读出能明显改变原热图的表现形式；不是所有旧点阵都成为最终错误 |
| 116预登记缺口 | 旧单轮未分开，NoGAN单轮已产生分隔 | 有局部实际分区收益，但该图不属于当前150评分集且无GT |
| 101细通路及557弱线 | NoGAN热图更连续，最终轮廓差异小于热图差异；557上方弱线两者都未明显恢复 | 不支持NoGAN全面解决弱边、细通路问题 |

## 当前判断

旧版保留作已评分控制；NoGAN保留作读出适配的研究对象。
后者热图更连续、部分分隔确有收益，但同一读出下产生更多F分区，面积代价超过小幅mIoU收益。
下一步应分别检查两种响应如何经过连接、细化、扩宽形成种子，不预设同参数最适合两者。
本轮先完成身份、图样和正式分数对齐，不启动这项消融。

语义网络接收的RGB／特征未改变；最终类别变化可来自实例重划后对同一raw概率重新投票，
不能将当前两恢复器差异直接归因于语义头输入不适配。
