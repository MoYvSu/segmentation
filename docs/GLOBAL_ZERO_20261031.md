## 改动与当前入口

`tools/infer_zero.py`是独立入口，格式`all_zero_restoration_inference_v1`，实际噪声协议为`explicit_zero_v1`。
全图及每个局部窗口均显式执行`q_sample(..., noise=zeros_like(input))`后再运行原D5a首步恢复；
初态必须与条件图逐值相同。预测期间调用固定Philox生成器、`torch.randn/randn_like/normal`会报错，
不能生成随机噪声再乘零，也没有绕过恢复器。

固定项：原D5a、原backend、旧20a59 NAF、原生1024、NAF256/kernel8、S0、high .65/low .45、
reflect32、seed50、raw概率投票、final200 neighbor_merge_v1。唯一预测变化是全图恢复噪声从固定值改为零。
未叠加768、双输入NAF或其它读出。旧入口及已评分包保留原字节，不将它们的成绩记给全零方案。

新入口仍接受历史N1/final200源配置做参数核验，保存`baseline_config/runtime`；
实际`config/runtime`、`all_zero_restoration`和逐次调用回执均明确记录全图/局部zero。
源码中旧入口的“全图固定噪声”约定仅属于旧对照，不能作为继续使用噪声的推荐。

调用方式：

```text
python tools/infer_zero.py --input-dir <最新150图目录> --output-dir <全新目录> --config <N1与final200配置> --model-dir <原模型目录> --naf-checkpoint <旧20a59文件> --dataset semifinal_150 --global-noise zero --only <固定图名>
```

## 数据、对照与方法

仅从最新`test_169–318`的150图抽取12张，不使用测试GT或生成测试训练目标。
三种原图尺寸各4张，保留此前169/226/302/313；其余按`SHA256(20261031:source)`排序补齐，推理前封存。
名单为169、172、174、207、211、226、237、258、277、280、302、313，共30,262,464原图像素。
这是均衡分层并包含指定案例的小样本，不代表150图总体准确性。

旧对照为`semifinal_support200.zip`，SHA256：
`cc346f8c4ab7f510fdc6be712baa7c45aa32f394672cda8adbe34266761567c8`。
直接复用该包，不重新生成带噪预测。全零路径用两个独立进程各推理12张。

最终类别像素翻转将背景0与类别P=0分开：实例ID为0单独作为背景；
仅统计前后均为有效实例的F→P及P→F，同时分别报告全图像素和共同前景两个分母。
背景进出及编号无关的轮廓/空间拆并另列，不把ID重编号算成翻转。
稳定实例对应要求同一交集覆盖旧、新实例各至少90%；这只是预测之间对应，不是GT匹配。
