结束时并列：182区域错相及118原正确退步、F→P与P→F、GT原标域／类无关匹配、

### 原标粒度风险，不是处理程序漏读

train873预测113（10933px）和train874预测166（3826px）是暗纹理区域内的亮色小岛，
均全部由原始LabelMe父P多边形覆盖，任何原始F多边形与其重叠均0。
重新栅格化原标与处理后original ID／coverage全图逐值一致，排除了这两例completion覆盖F或漏读已有F标注的解释。
873父GT22原标面积72433，岛占15.09%；若用完成面积75075作分母是14.56%，不要混用。
874父GT37原标88033，岛占4.35%。

B把874亮岛由F改P后更符合现GT；873仍判F而仍记GT分歧。
这不能证明亮岛物理上必须是F，也不能证明B物相判别改善。
“严格原标覆盖／GT类别纯”只保证监督来源完整、记录类别一致，不保证父多边形内每个局部组织都独立标注。
同样，train172最大F目标改善1008px是亮色晶粒内的小暗斑，A／B都改成GT的F，不能只归因于区域增项。
