因此跨卡检查隔离局部恢复与几何链，不冒充全图路径重新计算的完整工程验收。

## 确定性与跨卡参考线

同机固定batch1实际路径，两独立进程的连续边界、实例数组及类别必须精确相同；
恢复器另检查无效seed变化及严格重载。当前部署不batch化，不要求跨batch算法逐位一致。

跨4090／5060不要求逐位相同。以下逐图工程参考线在前向前固定，不按结果放宽：

| 检查 | 参考线 |
| --- | --- |
| 铁素体实例数量 | 两卡精确相等 |
| 最终三态类别像素变化 | 全原图背景／珠光体／铁素体三态分歧≤0.05%（5e-4） |
| 铁素体均面积相对差 | 以4090同模型结果为分母，绝对值≤0.01%（1e-4） |
| 连续边界MAE | 概率0–1尺度，全原图平均≤1e-4 |

另报恢复RGB MAE／P99、边界P99、共同覆盖区类别变化、覆盖差、空间配对实例IoU、
均值与最差图。实例ID任意，不对实例ID图做MSE。
这组参考线仅为三图工程容差，不是统计显著性、竞赛准确率或任意GPU保证。
旧报告类别变化使用共同覆盖区，不能与本轮全图三态直接比；本轮旧D5a同协议输出才是配对参照。
若C在容差内但比旧参照残差更大，应同时说明，不能称为已证明更稳。

## 恢复质量的独立检查

既有四源073／125／210／970的固定配对均未匹配32人工源，原梯度指标不能直接证明真实晶界。
本轮按文件SHA确认两有标注训练源，对处理GT仅使用可信原覆盖邻域，排除filled／unknown。
记录真实晶界附近的恢复误差、梯度与方向保持，以及可信内部新增强边缘；清晰输入漂移单列。
可信支持不足时不扩为伪GT，不从测试图推断答案。
新增两源是已见训练图的机制检查，不是独立留出验证；原有512／原生1024固定恢复指标继续分栏。

质量判断与工程确定性分开：全图MSE较低不能抵消可信弱晶界损伤，输出间MSE较低不能代替准确性。
即使小范围工程容差通过，仍不自动晋级竞赛主线。

## 实测结果：同卡与跨卡

验收已完成。RTX4090与RTX5060 Laptop各运行三独立进程，共18个局部几何链终态；
另完成12次有清晰参考的恢复前向，无新增训练。预设参考线未按结果调整。

| 分析方案 | 实测结果 | 可得结论 |
| --- | --- | --- |
| 同卡两独立进程，逐数组比较 | 两卡各三图的恢复RGB、连续边界、实例和类别全部精确相同 | 固定batch1下重复推理通过 |
| 实际q_sample及改变无效seed | C全部实际噪声为零、state逐值等于condition；首窗改seed仍精确 | 局部C首步不依赖随机种子 |
| 4090反验旧产物 | C对原e5缓存、旧D5a对原缓存，三图全部精确 | 本次读入与既有部署链一致 |
| 跨卡逐图检查最终输出 | C三图全部通过预设四条参考线 | 所测两卡的局部链工程复现可接受 |
| 有GT清晰／模糊配对 | C较A的模糊MSE与法线误差小降，但弱点响应覆盖未增，清晰改动略增 | 质量有取舍，未证明整体结构非劣或比赛收益 |

## 实测结果：有清晰参考的质量检查

按SHA核对manual001→pool782、manual659→pool501，原生中心1024裁窗，无缩放；
空间模糊为原生sigma0.8→4.5的固定平滑水平过渡。两图均参加过训练。
可信域为original-covered且非filled／unknown，再腐蚀3×3并排除裁窗外沿16像素。
可信GT边界仅1523／19754（7.71%）、656／22526（2.91%），低响应子集分别609／263点。
“低响应”按清晰参考上GT法线响应的20–60%分位定义，不能代表所有肉眼极弱或缺失晶界。

| --- | ---: | ---: |
| 可信域RGB MSE×1e4 | 2.12988／2.05506／2.02111 | 3.93787／3.83496／3.79380 |
| GT法线梯度MAE×1e3 | 15.0596／14.8137／14.6048 | 12.6810／12.2075／11.8719 |
| 低响应GT法线MAE×1e3 | 14.7321／13.9827／13.9491 | 11.0741／10.6424／10.3439 |
| 低响应点达到半参考响应 | 96.8801%／97.3727%／97.3727% | 90.1141%／89.3536%／89.3536% |
| 可信实例内部新增强图像边缘像素 | 474／485／490 | 224／218／209 |

C较A的MSE逐源下降1.652%／1.073%，GT法线误差下降1.410%／2.749%；
但达到半参考响应的比例完全相同，不能说C补回更多晶界。
相对旧模型，001多3个、659少2个低响应点达到半参考，方向不一。
法线强度保留约1.10–1.13，存在增强过头可能，不能把响应越强当越好。
内部新增强图像边缘可能涉及遗漏标注或已有弱纹理增强，不直接命名为假晶界。

清晰配对的RGB MAE×255，A→C为001的0.05066→0.07232、659的0.02593→0.03143；
内部新增强图像边缘69→140、7→9。绝对漂移很小，但两个源均比A多改动，不能判无代价。
补充两图清晰输入漂移小，不覆盖原四源尾部：旧四源原生清晰C的RGB MAE×255为
1.373／1.046／0.034／0.083，等权均值0.634；不能宣称每源或每像素都低于1灰度。
既有四源的原生／训练512指标已复用、分栏存入`quality/cached_quality_floor.json`，没有重复推理。

## 决策、产物与未完成项

1. C5零噪声保留为研究候选；局部路径同卡确定性与所测两卡工程容差通过。
   旧固定Philox也通过相同跨卡参考线；零噪声的直接作用是去除局部恢复的种子自由度，
   不是消除所有GPU浮点差异，更不是证明旧带噪预训练无用。
2. 本轮没有证据要求立即调整affinity或继续扩训恢复器。后续可以固定候选的零噪声条件，
   单独检查尺度；正式精度比较仍保留最高旧链控制，不把稳定性作为自动晋级依据。
3. 有GT机制检查未见明显边界响应塌缩，模糊误差有小幅改善，但尚未证明整体结构非劣，
   未证明真实缺失边界补全、测试mIoU或F面积收益。无独立留出或新增黑盒分数。
4. 全图两份语义缓存冻结，因此本轮不覆盖全图旧恢复器重新运行的跨卡差异，
   也未完成整个云盘包替换候选后的独立验收。最高reflect与原云盘工程保持不变。

源码／模型／输入／固定map前后SHA通过；212文件推理快照和448文件质量快照均独立封存。
