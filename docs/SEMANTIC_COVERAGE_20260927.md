# 大窗口补充灰度监督

## 本轮范围

用户授权先解释窗口并实施。保留独立语义LoRA、simple头、Stage1/joint-v3来源、冻结D5a与affinity，
只尝试补充清晰训练原图上的可靠灰度目标。训练预算仍20轮／1280更新、全32人工与1000训练源、无留出。
候选若通过预检查，使用与`semantic_lora`相同的原simple e60及复制LoRA初始化；不接续其e20，
完整控制直接复用`outputs/semantic_lora/candidate/`，不重训。

配置：`config/train/semantic_coverage.yaml`，预计正式输出`outputs/semantic_coverage/`。
控制末轮SHA256：`23b23d1f0cecb268091943610ceddffd1dffc4371ca548ce725639e2dfc4068b`。

## 窗口规则

先用既有letterbox图像映射到256×256分析网格。原规则的128×128窗口每64格滑动，
从各窗口内部与全图提取可靠明暗参照。窗口是生成监督的统计范围，不是模型输入裁块。

新增192×192、步长64的大窗口，仅补小窗口没有任何可靠支持的位置。
仍要求全图与所有覆盖该点的有效大窗口同类、高置信（0.9），概率跨度≤0.15，
明暗模式分离／谷值检查和内部收缩规则保持不变。原可靠目标及数值逐点保留，
已有局部冲突、已知GT、padding和证据不足位置不借大窗口改写。

先验从清晰原图生成；增强与D5a只作用于学生输入。大窗口不使用模型预测选择类别，
也不把近单相区域直接强制赋成铁素体。

## 一次性预检查

入口：`python tools/probe_semantic_coverage.py --config config/train/semantic_coverage.yaml`。
输出：`outputs/semantic_coverage_probe/`；训练源诊断图全部私有，不进入Git。

- 全32已有人工GT只核验固定规则在可靠内部的冲突，不训练、不拟合阈值、不移走训练样本。
  该诊断暂关闭GT排除以便比较标签；正式无标签流继续排除全部已知GT区域。
- 重放已完成LoRA的全部1280次无标签源／增强选择；核对旧接受数量、原标签不变及增强参数。
- 固定已完成的LoRA e20、FP32前向，分别统计新增两类覆盖、未达置信门槛位置、类别分歧和连续分歧块。
- 保存清晰图／D5a后输入／旧监督／新增监督／预测／新增冲突的缩略图，忽略位置单独标灰。

预先约定：若新增监督几乎没有可学分歧，或明显存在错误目标，则不消耗20轮训练。
覆盖增加、与先验更一致均不等于测试准确率改善；没有测试标签或官方新分数。

## 预检查结果：不启动20轮训练

已完成全1000源、原训练全部1280次视图重放，旧目标逐点不变、输入／增强核对通过，
无优化器或权重更新。FP32诊断使用完整LoRA e20，实际循环348.40秒。
41项针对性CPU检查通过，包括旧路径兼容、两类补充、局部／全局冲突保护及GT／padding排除。

“局部零支持”只统计全图明暗参照有效、且不属已知GT的候选位置；并非全部忽略域。
旧接受位置的60%覆盖增加到60.07776%，不足以代表其余约40%忽略位置都得到了处理。
计数是在256网格且含重复视图，不能当作独立原分辨率像素或测试准确率。

全32人工源的固定规则检查中，只有1源新增可视区域。新增可靠GT内部格点2962，
真实铁素体2936／珠光体26，均与先验一致。旧接受内部918286格点有191处冲突。
这里直接比较固定规则与GT，不使用模型预测，也不拟合阈值；GT样本及新增珠光体覆盖有限，
不能据此证明所有无标签新增目标都正确。

此前固定monitor中的矩形缺口获得2033格补充（2031铁／2珠），但已完成模型在这些位置上
原本就同类且满足0.9置信门槛。它解释了本次停止理由：规则确实补上了位置，几乎没有提供尚未学会的目标。

**决定：不启动正式候选训练，不重训控制，不产出新的候选checkpoint或黑盒包。**
这是执行原先约定的信号门槛，不是资源阻塞；GPU在预检查完成后释放。
配置现用于该只读预检查，未扩展正式训练协调器。新增规则默认关闭，旧实验逻辑保持兼容。

结论只覆盖本次“128→192窗口、仅零局部支持补充”。从同一初始化再训练仍可能改变优化轨迹，
本检查不证明其数学上绝无作用；也不否定其他忽略域、目标可靠性或真实退化分布存在问题。
但当前证据不支持把20轮预算继续投给这一具体补缺口方案。

应修正先前假设：接受mask有空洞不代表模型对应区域不会分类，补覆盖必须同时有可靠且未满足的监督。
后续若继续定位，应检查原有局部意见冲突／低置信区，或实例内语义混合；本次未放宽阈值、
更改投票或扩展额外实验。
