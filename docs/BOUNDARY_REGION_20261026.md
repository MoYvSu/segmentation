## 完整训练分析

### 训练质量与实际监督覆盖

## 监督如何构造

从原标覆盖实例内收缩4像素，取至少64像素的可信连通内核；未知区、padding及不可靠边缘
不作为监督。只要求不同GT内核分开，不强制同一GT所有位置连通，避免把GT漏标当作合并依据。

在距已知GT边界12像素的带内寻找完整分隔像素集：把当前热图当作可通行空间，寻找增强后
能够堵住两侧所有绕行路径的一整组位置，再向这些位置反向传播。选位置本身不求导。
使用8邻接，且把窗口外沿共同连接到一个外部节点，防止裁框替模型封口；未知区仍能通行，
不能通过删掉未知区制造分隔。非法/不完整分隔整对拒绝，不将其残片训练成成功样例。

三个独立归一的损失各权重1：

| 损失 | 作用 |
| --- | --- |
| 保线 | 输入骨架距GT边界≤4像素且已知的位置保持高响应 |
| 保内部 | 距输入骨架>4、GT边界>12像素的可信内部保持低响应 |
| 完整分隔 | 增强可编辑带内的完整分隔集，目标响应0.9以上 |

保内部仅对尚未满足`p<0.1`的位置归一，避免大量已正确背景稀释少数异常高点。
内核身份不随预测重划，种子被模型涂成墙不算成功。没有任意抹去测试图内部线或强制实例数。
