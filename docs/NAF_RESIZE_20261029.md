## 唯一结构变化

```text
旧：低分辨率Conv1x1(C→2C) → PixelShuffle(2)
新：低分辨率Conv1x1(C→C/2, bias=False) → 双线性放大2倍，align_corners=False
```

新模式显式命名`upsampling='project_bilinear_v1'`；不改下采样、skip、decoder、输出跳连或损失。
