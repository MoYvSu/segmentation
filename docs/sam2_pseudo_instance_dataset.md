# SAM2 无分类伪实例数据规范

## 作用域

该数据层只为亲和力、边界或其他不需要相区类别的实例监督服务，不参与铁素体/珠光体语义损失。首轮亲和力 G0/G1 不启用该数据层，先隔离验证架构本身。

## 合规硬约束

- 数据源只能来自赛方提供的无标签训练图像，禁止使用测试图像和任何外部金相数据。
- 纳入伪实例数据集的不同源图像严格少于 250 张，即最多 249 张；生成脚本应在达到 250 时直接失败。
- SAM2 输出不附加铁素体/珠光体类别，类别监督始终记为 `ignore`。
- 若进行人工修订，仍计入这 249 张额度，不另开数据口径。
- 保存源图像文件名和 SHA256，防止重复图像以不同文件名绕过数量限制。

## 建议目录与清单

```text
data/pseudo_instances_sam2/
  manifest.jsonl
  masks/
  labelme/
```

每条清单至少记录：源文件、SHA256、SAM2 checkpoint、生成参数、原始 mask 数、去重后 mask 数、过滤原因、生成时间和 `class_label: null`。

## 质量控制

- 对高重叠 mask 做 IoU 去重，不允许同一区域被重复实例覆盖。
- 过滤极小碎片、几乎覆盖整图的 mask 和明显越过强边界的 mask。
- 每张图最多保留 255 个实例；超限时记录并拒绝静默截断。
- 同一伪 mask 内生成正亲和边；经过置信度过滤、去重和互斥仲裁后的不同伪 mask 之间允许生成负亲和边，不因其来自 SAM2 而一刀切禁用。人工与 SAM2 负边需保留独立数据源标识，便于分别消融或降低伪标签权重。未被任何 mask 覆盖的区域仍设为 `ignore`，不能自动当作边界或背景。
- 人工标注 GT、SAM2 伪实例和无标签图像必须使用独立 dataset key 和 loss mask，保证复现时可分别关闭。

## 局部高覆盖裁剪候选

当前 64 张 G2 伪实例的平均覆盖率约为 0.894；18 张低于 0.85，31 张低于
0.90，而仅 4 张达到 255 个实例上限。低覆盖因此不只是实例上限造成。

- 保留整图样本作为尺度和全局形貌监督，不直接删除难样本。
- 仅从同一批源图像额外抽取原生尺度局部窗口，不增加独立源图像计数。
- 候选窗口要求伪 mask 覆盖率不低于 0.92，并包含足够多实例及实例间负边；
  不能只选择一个大实例占满的“容易窗口”。
- 未覆盖像素继续为 `ignore`，裁剪不能把缺失区域改成背景或负边。

该策略解决的是监督密度和原生尺度问题，不保证补回 SAM2 漏检实例。应作为
独立 G3 消融，仅替换部分 SAM2 伪样本批次，不改动当前可复现的 G2 基线。
