# 主线双头信息交流：20 轮结果与判断

## 结论

**跨头交流相对等预算自身修正有小幅几何收益，但当前完整方案不晋级。** cross 比 self 多匹配
10 个实例，五图中四图的漏检计零 IoU 更高；但相对原 E10a + G4b，五图全部下降。覆盖率仍
维持约 98.75%，没有出现直接掩码路线的大面积空缺。代理总分上涨主要来自面积项，不能据此
宣布几何超过主线或保证官方成绩提高。

追加的推理拆分表明：关闭 affinity 修正后，两组的有效匹配都恢复到主线的 715，几何退步
主要与本轮 affinity 修正有关；语义单独修正则使铁素体平均面积误差变大，也不建议独立部署。
本轮不延长训练、不改变主线；保留交流结构作为候选，下一步需要处理训练目标与最终实例输出
之间的偏差，不能仅凭更低的像素/连接损失或更大的交流模块继续推进。

## 原始输出与推理拆分

| 诊断，固定相同网格与 GT 有效域 | 主线 | self | cross |
| --- | ---: | ---: | ---: |
| 1024 网格语义像素 mIoU | 0.91457 | 0.93811 | 0.93783 |
| 粒内平均 affinity | 0.76185 | 0.79709 | 0.79702 |
| 跨晶粒平均 affinity，越低越好 | **0.07400** | 0.09154 | 0.09237 |
| 跨晶粒 affinity >0.5 的比例 | **0.876%** | 1.633% | 1.649% |
| 同类别、不同晶粒的平均 affinity | **0.08534** | 0.10437 | 0.10856 |

上述 affinity 统计覆盖全部8方向/距离通道，端点都是已知 GT；不是正式边界召回率。
共同训练让粒内更容易连接，同时跨界也更容易连接。同类晶粒分界尤其需要保护，语义相同
不能推出同一个实例。另一方面，cross 的跨界均值略差于 self，最终几何却略好，也说明
**均值不能替代具体断点、方向和空间连续性**，不能把全部差距归因于这一平均数。

原始像素语义改善没有充分传递给最终实例输出。最终预测在已知 GT 上的类别正确像素比例
为主线95.40%、self94.29%、cross95.05%（未分配算错）；它受整个实例被赋同一类别及区域
划分影响，和直接阈值化语义概率是不同指标。

为区分两项修正，固定同一 e20 权重，分别只启用语义修正、保留 G4b 原 affinity，并重跑
完整主线后处理。语义仍同时影响分水岭地形与区域投票，没有偷偷改成只换最终类别的实验。

关闭 affinity 修正后恢复715个匹配，支持“完整修正导致的匹配退步主要与 affinity 改动
有关”。这不是精确加法分解，两头经过分水岭有非线性交互。只启用语义时，净增27个区域
被判为铁素体，铁素体平均面积进一步偏小；即便原始语义像素更准，也没有形成提交口径的
净收益。拆分仅作因果诊断，没有据此重新选择 epoch 或修改主线。详见
[ablation.json](../output/20260911_cross_head_results/ablation.json)。

## 后续判断

1. **保持 E10a + G4b。** 完整 cross 在五图均低于主线几何，仅语义修正也没有净收益。本轮
   没有足够依据晋级，也不建议只延长当前配置。
2. **信息交流并非完全无用。** self→cross 的4/5图漏检计零 IoU改善及10个额外匹配，支持
   保留这一小型结构继续研究；一个种子、五图不能证明普遍有效，也不能否定其他耦合方法。
3. **优先检验共同训练目标与原边界行为的相容性。** 两组都使连接变强，问题并不专属于
   cross。若继续，合理的小对照是针对已知跨实例负连接增加修正保护，检查能否避免边界
   变弱，并同时观察最终区域分类和铁素体面积；已有负连接加权和整实例语义池化均已开启，
   不能把简单重复这些已有损失描述为新方案。保护约束尚未实现或验证，不保证有效。
4. 本轮没有证明需要重训 SSL、解冻 LoRA、扩大模型或否定新 GT。两头虽读取对方信息，
   仍分别按原任务损失优化，最终分水岭也没有参与梯度训练；“能互相读取”尚未解决提交
   目标与训练目标的偏差。后续应保留同预算对照与固定部署评价，避免继续叠加复杂训练链。
