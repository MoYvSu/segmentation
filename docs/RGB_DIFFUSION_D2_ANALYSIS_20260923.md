# D2前20轮分析：低噪声输出接近原图，优先检查起点学习

2026-09-23。承接[D2启动记录](RGB_DIFFUSION_D2_K003_20260923.md)与[D1完整60轮分析](RGB_DIFFUSION_ALL60_ANALYSIS_20260923.md)。

## 当前结论

用户观察到“几乎没有区别”与量化结果一致：D2完成16步采样后接近原始模糊输入，
并未表现出有意义的去模糊改善。同样20轮预算下，D1首步已有明显重建改善，D2首步几乎没有。
因此，本轮把噪声系数从0.1降至0.03的尝试没有达到目标，不推进到提交，也不自动续训剩余40轮。

现有结果支持“0.03对当前训练配方过弱”这一解释，但不能推出噪声越大越好，
也不能断言D2训练20轮已经绝对收敛。新的受控诊断更具体地指向：
模型擅长利用训练状态中已有的清晰线索，却没有充分学会从真实部署起点恢复图像。
这是得到证据支持的机制假说，仍不是已排除其他解释的因果结论。

- D2耗时686.08秒，约11.43分钟；峰值已分配显存7751.20 MiB。自动保存6个节点、48张过程缩略图。
- 下表使用FP32重新推理，固定采样种子314159；另以271828、161803重放，结论一致。
  这三项是采样种子，不是三个独立训练重复实验。

## 同预算重建误差

固定4张**已参与训练**的原图与合成模糊配对。表中数值为平均重建误差除以平均输入误差，
1表示与不修复相当，越低越好。RGB为颜色绝对误差；梯度误差观察局部边缘变化；MSE为平方误差。
这些数值不是留出集表现、真实测试GT指标或分割黑盒分数。

| 配方与输出 | RGB误差比 | 梯度误差比 | MSE误差比 |
| --- | ---: | ---: | ---: |
| D1 κ=0.1，e20首步 | 0.704030 | 0.942592 | 0.489587 |
| D1 κ=0.1，e20完整16步 | 0.810927 | 1.116058 | 0.663622 |
| D2 κ=0.03，e20首步 | 0.989766 | 1.003287 | 0.983830 |
| D2 κ=0.03，e20完整16步 | 1.003360 | 1.000692 | 1.002160 |

D1首步RGB误差比输入低约29.6%，完整采样仍有额外边缘误差；D2首步只改善约1.0%，
完整采样基本回到原图。不能将D2梯度误差低于D1完整采样解释为去模糊成功：
几乎不改输入，同样能避免制造新的边缘误差。

三个采样种子下，D2完整采样RGB误差比在1.003358至1.003361之间，
梯度误差比在1.000687至1.000692之间。FP32结果与训练中BF16过程图相符，
这次观察到的近恒等输出不是仅由某个采样种子或过程图精度导致。

D2训练内部的损失仍在改善：第11–15轮至16–20轮的平均RGB误差下降3.49%，
梯度误差下降1.66%，MSE下降4.91%。因此不能声称20轮已完全饱和；
但继续降低随机训练状态下的误差，并不保证实际完整采样会开始修复。

## 受控状态诊断：清晰线索在哪里

模型的训练状态为：

```text
xt = (1 - eta_t) * clean + eta_t * blurry + kappa * sqrt(eta_t) * noise
```

在t=8时，`eta=0.24369`，状态中仍保留75.6%的清晰目标成分。
D2噪声标准差仅0.01481，比D1更容易保留、读取这些已有线索。
真正部署从`t=16`的`blurry + kappa * noise`开始，此时清晰目标的系数为0。

保持同一个模型、条件图、时间步和标准高斯噪声，额外比较两个输入：
正常训练状态`q(clean, blurry, t)`，以及移除清晰线索后的`q(blurry, blurry, t)`。
下面为4个训练配对的平均RGB绝对误差，使用未裁切的清晰图估计：

| 状态 | D1 e20 | D2 e20 |
| --- | ---: | ---: |
| t=8，正常训练状态 | 0.016577 | 0.009832 |
| t=8，移除清晰线索 | 0.038608 | 0.039054 |
| t=16，实际部署起点 | 0.027430 | 0.038560 |
| 不修复的模糊输入 | 0.038954 | 0.038954 |

D2在带清晰线索的状态下明显更容易预测目标；去掉线索后几乎回到不修复水平。
t=16本身也缺乏改善，说明问题已经出现在完整采样的第一步，不能只归因于后续反复加噪。
D1同样依赖中间状态中的清晰线索，但它在t=16已经学到一部分真正的恢复能力。

限制：t<16时移除清晰线索是在故意改变模型原训练输入分布，用来检查依赖关系，
不是一种合法替代采样，也不是可直接部署的提升方案。该诊断支持“起点恢复能力不足”，
不能单独区分模型容量、训练预算、任务权重与优化路径的贡献。

代码依据：[`q_sample`](../models/rgb_diffusion_restoration.py)构造含清晰目标的训练状态，
同文件`forward`从模糊输入加噪开始；[`take_update`](../train_rgb_diffusion_restoration.py)
均匀抽取1至16时间步。真实部署起点目前仅占期望训练样本的1/16。

## 下一步建议：单独加强部署起点的训练

建议新建一个待验证对照，保留D2的`kappa=0.03`，唯一改变是时间步抽样：
**50%抽t=16，另50%均匀抽其余15步**。直观上，让模型更多练习真正需要完成的
“从模糊图开始修复”，而不是主要练习处理已经混入清晰信息的中间状态。

- 仍从零训练，固定seed42、1000张全量训练、同一架构、损失、在线退化和局部遮挡课程。
- 仍采用60轮学习率日程，先执行相同20轮、5000次更新；保留同一组自动过程缩略图。
- 推理噪声、16步采样和下游分割保持不变，不同时提高κ、修改结构或调整SAM2。
- 以D2 e20为直接对照，检查t=16首步是否恢复、完整采样是否保留改善，再检查固定真实图。
- 采样分布改变后，训练平均loss对应的任务混合也改变，不能直接拿其大小判断胜负。

50%是用于区分机制的工程起点，尚未证明最优，也不是原论文给出的推荐。
若首步得到改善而完整采样继续恶化，再单独研究采样轨迹与训练状态之间的差距。
分析时仅提出方案，未启动新训练或续训D2；后续用户已授权
[D3起点强化实验](RGB_DIFFUSION_D3_TERMINAL50_20260923.md)，已从零发起同预算前20轮。

原始[ResShift论文](https://proceedings.neurips.cc/paper_files/paper/2023/file/2ac2eac5098dba08208807b65c5851cc-Paper-Conference.pdf)
§4.2也报告过过大、过小的κ都可能使结果变平滑。但其经验区间来自压缩特征空间，
不能直接搬到本项目的0–1 RGB像素空间；本文建议的起点抽样实验是基于本项目证据提出的假说。

## 下游适应假说与证据边界

用户提出“修复改变输入后，分割模型或后处理没有适应”的可能仍成立，尤其值得用于解释v6黑盒下降。
不过本轮D2的问题在进入SAM2之前已经可见，修复器本身几乎不改变输入，
当前结果不能靠调整下游来解释为重建有效。两项问题应独立检验。

本轮没有新的完整分割部署评估或复赛黑盒分数，不推断语义或面积项收益。
既有v4、v6的官方结果与回退依据见[D1分析](RGB_DIFFUSION_ALL60_ANALYSIS_20260923.md)，
不与初赛分数直接横向比较。
