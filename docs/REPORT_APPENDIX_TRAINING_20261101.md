# 附录A 完整训练流程与权重来源

2026-11-01实跑补证：[教师GT监督链结果及计时](TRAINING_RESULT_TEACHER32_20261101.md)。当前13阶段在既有SSL/D5a基础上完成重训与导出，单卡阶段墙钟训练合计5小时33分、端到端5小时46分23秒；不含原SSL/D5a重训，不作为历史已评分C的训练实测时间，也不冒称新模型已获官方分数。

2026-11-01更新：默认入口已完成V6删减，以下为当前13阶段流程。历史已评分模型的V6训练事实保留于A4，当前新GT重训仍在进行；[等价核验与接续记录](V6_ELISION_20261101.md)单独列明验证范围。

训练链由多个阶段的实验逐步累积形成。最终部署模块与中间训练模块并不一一对应：部分中间头用于训练共享特征或提供固定教师，不随最终模型部署。本附录记录实际权重传递和训练预算；各阶段均保留，不代表其独立必要性均已通过消融证明。

最终部署包含图像恢复器D5a、共享编码器及语义与affinity双头、独立NAF边界纠错器。语义头预测铁素体与珠光体概率，affinity头预测像素对是否属于同一实例。NAF接收边界图并进行纠错，不承担相别分类。

## A1 数据与初始化

官方SAM2编码器作为基础特征提取器，骨干参数冻结，LoRA作为少量可训练参数用于调整特征。任务解码器由本项目构建，未载入SAM2原生Mask Decoder权重。原SSL LoRA通过1000张训练图的遮挡RGB重建学习；D5a通过同一训练图集合的自监督恢复学习，两者不依赖分割GT。

本轮教师GT演习复用原SSL LoRA及D5a，在允许的32张训练源上用已评分C的完整输出生成新实例与类别监督，保留原64源SAM2无类别几何数据。其余监督模块在新运行内依次训练，不加载旧C的监督任务权重。

下文区分两种教师：生成32份固定GT的是旧C；S-align训练中的固定语义教师则直接复制本轮joint已经学到的旧语义。

## A2 分阶段训练与参数去向

| 阶段 | 预算 | 初始化与更新范围 | 后续用途 |
|---|---|---|---|
| SSL | 本轮导入原30轮结果 | 复用原RGB重建LoRA | 提供Stage1初始LoRA；重建头不部署 |
| Stage1 | 100轮 | 语义头、直接边界头随机初始化；与LoRA共同更新，官方骨干冻结 | 双头及LoRA进入joint |
| Stage1边界缓存 | 1000源 | 固定Stage1推理，不训练 | 提供joint无标签边界目标 |
| joint | 100轮 | 接续Stage1，同时更新双头与LoRA | 提供共享特征、S-align固定旧语义教师及affinity初始化所需的边界特征 |
| S-align | 20轮 | 先复制固定教师，再随机重置完整学生语义路径；只训练新语义头 | 新语义头进入最终backend；固定教师不部署 |
| V affinity | 120轮，3120次计划更新 | 边界特征融合部分从joint继承，新的上采样和8通道输出随机初始化；只更新affinity | 选定的V权重进入R1 |
| D5a | 本轮导入原60轮结果 | 固定原RGB恢复模型 | 参与R1输入恢复及最终推理 |
| R1 | 20轮，1280次更新 | 组装joint共享特征、S-align语义、V affinity及D5a；只更新affinity | 提供最终affinity权重 |
| backend与restorer导出 | 不训练 | 严格组装并导出本轮权重 | 为N1缓存提供模型 |
| 局部N1缓存 | 32源 | 以新backend与D5a执行零噪1024滑窗、重叠拼接边界 | 仅作NAF输入 |
| NAF | 1000次更新 | 生成器和判别器随机初始化，目标来自固定教师GT边界 | 仅生成器进入最终推理 |
| NAF导出与三模型验收 | 不训练 | 检查模型身份、参数预算及部署合同 | 得到backend、restorer及NAF生成器 |

早期有标签图采用1024等比缩放后512裁块，无标签语义一致性采用整图1024。S-align损失包含GT语义监督、实例组织的语义损失，以及固定旧教师在无标签图上的概率蒸馏；教师置信度门槛为0.9，蒸馏权重在前12轮由0.12降至0.03。

R1每轮包含32次整图视野与32次原生1024视野更新，使用32源实例监督与64源SAM2几何。编码器、LoRA、语义和D5a冻结，仅affinity更新。S-align语义未在该阶段接受D5a域微调。

NAF目标由固定GT独立构造，不能把N1输入边界当作训练答案。当前教师GT中，语义与affinity继续忽略ID0；只有明确的轴向单像素A－0－B且A、B为不同正实例ID时，才将零线派生为边界正监督，实例与类别数组保持不变。

## A3 affinity初始权重的具体来源

affinity解码器分为特征融合部分、上采样部分和8通道关系输出部分。特征融合采用FPN，即将编码器不同层次、不同尺度的特征组合起来。

| 参数部分 | V训练起点 |
|---|---|
| `geometry_fpn.*` | 严格复制本轮joint模型的`decoder.boundary_fpn.*` |
| `upsample.*` | 按固定种子随机初始化 |
| `affinity_head.*` | 随机初始化，末层卷积权重标准差0.001、偏置0 |
| 共享编码器与LoRA | 从本轮joint继承并冻结，不属于上述新affinity输出层 |

因此，affinity不是整个头随机训练，也没有直接加载现成的旧affinity结果；它借用joint已学到的边界特征，再学习像素对关系。旧边界头的单通道预测层不复制到8通道affinity输出层。

```text
Stage1边界特征 → joint边界特征
                         ↓ 复制FPN
                 V affinity初始模型
                 上采样与输出层随机
                         ↓ 120轮训练
                 本轮V选定权重
                         ↓ R1接续1280更新
                 最终backend的affinity
```

当前统一入口明确设置`reference_checkpoint=<本轮run>/joint/best_model_stage2.pth`、`geometry_init_mode=reference_boundary_fpn`及`geometry_init_checkpoint=null`。其中`init_from_v6_boundary_fpn`是沿用的兼容字段名，实际复制对象由reference指定，不能凭字段名解释成加载了V6。

历史已评分链和本轮演习采用相同的模块传递形式，但checkpoint分别来自各自的运行；本轮R1继承本轮V的权重，不复用历史已评分V/R1监督权重。

## A4 中间模块的作用与已移除的V6

当前旧语义头通过语义损失更新LoRA，并在S-align中担任固定教师；历史V6链还曾用它生成中间边界目标，该缓存现随V6移除。学生语义头随机重置不意味着旧语义知识完全退出后续训练。最终导出只保留新语义头。

旧直接边界头的特征融合部分经joint到V的初始化保留，其单通道预测层不进入最终backend。历史V6新训练的边界权重没有当前最终模型的消费者：V从joint初始化，S-align只蒸馏语义，最终backend也不包含直接边界预测头。旧入口只读取V6 e9，第10至60轮的权重没有下游读取。

按上述权重传递关系，V6没有向最终模型提供任何新训练的有效参数。所谓e9“载体”仅指旧代码从该文件读取joint已经训练好的语义和LoRA，不表示需要先执行V6才能获得这些权重。该历史文件依赖现已从默认入口清除，不能据此解释其训练必要性。

当前默认入口已由joint直接提供S-align固定语义教师与共享特征，affinity继续从joint边界FPN初始化，删除V6及未消费的语义边界缓存。该判断来自参数冻结及消费者关系，与GT版本无关。已完成的合成输入CPU/GPU抽查只用于排除实现接错，不能当作新GT训练质量或完整训练轨迹的证明，也不作为接续门槛。原joint继续，完成后核来源与严格加载再接续，完整最终输出尚未验收。

旧入口固定e9是历史载体索引，没有根据新GT重新评选，不能表述为本轮最优。V6语义/LoRA冻结，教师语义不会随V6轮次改善；新默认链已无该索引。joint仍按本轮验证的`0.2×语义像素mIoU＋0.8×边界IoU`选best，S-align按验证loss最低选best。joint综合最优不保证教师语义单项最优，这些内部指标不代表官方成绩。

## A5 训练工况与结果版本

R1恢复保留历史带种子随机加噪的first-x0训练工况；当前N1缓存和最终推理使用显式零噪声。训练随机增强与推理零噪声应分别记录，不能写成全链训练均无噪声。

历史已评分C使用当时的人工及处理后GT，具体阶段来源与采用epoch见训练参数表。当前教师GT32演习仍是独立新运行，其完整训练、最终部署输出及官方成绩尚未验收。旧C成绩只能归属于旧C，不能作为本轮新GT重训效果。
