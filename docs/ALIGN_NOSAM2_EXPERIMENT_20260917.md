### 语义坐标修复

新配置 `semi_supervised.shared_spatial_augmentation: true`：先采样一次学生空间变换，
让教师输入共享变换后的图像副本；外观增强和patch masking仍只用于学生。
已有离线边界缓存仅按原来的参数变换一次，mask在最终坐标生成，避免目标重复旋转。
随机数消耗和学生输入保持与旧实现相同。

历史配置默认 `false`，用于原S和既有实验复现；后续语义一致性实验应继承aligned配置。
关闭开关保留的是已确认存在错位的历史行为，不能作为新一致性方法的正常起点。
即使修复后的黑盒成绩下降，也不应据此把坐标错误保留到后续研究；原S仍可作为成绩参照。

CPU回归已验证16组翻转/旋转、边界缓存同坐标、外观/遮挡只作用学生、历史学生输入及随机行为不变。
调用实际 `compute_unsupervised_loss`，对严格空间等变的合成模型，旧模式产生错位惩罚，
共享坐标模式归零；测试关闭温度锐化以隔离空间因素，正式训练保留原锐化温度。
新测试及现有semantic GT、AMP回归合计32项通过。

### 去SAM2必须保持总优化预算

原V每轮按人工/SAM2各50%的概率抽52次，并非每轮严格各26次。
仅关闭SAM2开关会使默认epoch长度从52降至26、总更新减半，无法区分监督来源与训练不足。
本组显式设置 `samples_per_epoch: 52`，由26张人工图有放回抽取，保持26步/轮、120轮。

这一做法必然增加人工样本曝光次数。无法同时保持总预算和人工曝光次数不变；
本实验回答的是：**相同总优化预算下，更多人工重采样能否替代SAM2几何监督**。
若持平，支持在当前链路中省去该监督来源；不能推导SAM2在所有预算和任务下均无用。

## 黑盒前的决策（历史记录）

1. 保留正确的语义空间对齐作为后续研究起点，制作S-align e13 + L黑盒包，与原S比较；
   当前证据支持修复监督矛盾及保持相近最终表现，不宣称已经提高官方成绩。
2. 原V/SAM2几何保留为当前基线，尚不接受去SAM2消融成功。
   V-noSAM2 e77 + E10a单独上黑盒核验召回/面积取舍；即便总分上涨，也同时报告两分项与内部结构损失。
3. 黑盒回来前不追加训练、不调阈值、不换epoch、不把S-align和noSAM2合成一个新包。
   之后语义EMA与affinity一致性仍分别做单变量对照；如noSAM2无法保持质量，affinity一致性先保留SAM2监督。
4. 若要定量证明无标签任务监督的价值，还需要“正确对齐固定教师 / 无该一致性项”的对照；
   本轮错误对齐→正确对齐不能替代这个实验。是否先做此对照或EMA，应结合用户后续研究优先级决定。
