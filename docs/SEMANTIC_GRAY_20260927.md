## 灰度目标

入口`data/semantic_gray.py`。在增强前、几何已对齐的清晰训练RGB上计算Lab L*，
面积下采样至256语义网格。原图与重叠128格窗口分别估计明暗两组：

1. Otsu只初始化两组；均值差至少0.12（L*归一到0–1）、组间分离至少2.5个合并标准差，
   每组至少5%，且平滑直方图两峰之间的谷不高于较小峰的60%，否则忽略该区域。
2. 用明暗均值的中点和组间距离生成软概率。整图和所有有效局部窗口需同类、
   置信度至少0.9、概率跨度不超过0.15；内部按类别收缩1格，忽略边界混色。
3. 全部阈值事先固定，不按GT准确率或测试图选择。不要求先验与学生类别一致。
   先验概率是规则产生的软分数，并未校准为真实正确率；明暗双峰只是外观假设，
   不保证对应两种相区，因此本轮仍是候选实验。
4. 人工目录曾重编号，通过文件内容匹配32源；对应已知GT覆盖只用于排除灰度监督。
   一个256格点只要含任何已知GT像素，就不接受额外灰度目标。人工GT仍由相同监督流负责。
5. 学生读取同内容的在线退化、外观变化、D5a首步输出；强视图不重新生成目标。
   亮/暗可靠区域各自取平均BCE，再对存在的类别取平均，不强制面积或类别数量相等。

附加损失系数在前5轮由0.02增加到0.10，之后固定0.10。保留逐轮首步的监督/先验梯度范数，
并记录实际加权先验梯度、两类接受数、拒绝比例、先验与学生分歧方向及概率差。
不能由这些量或训练loss直接推断竞赛收益。

### 训练学到了什么

| 诊断 | 结果 | 解释边界 |
| --- | ---: | --- |
| 额外监督源 | 遍历1000，实际接受988 | 12源未通过明暗双峰条件，不是数据漏读 |
| 接受像素占有效内容 | 60.00% | 可靠内部覆盖，不代表正确率 |
| 接受位置的先验／学生类别分歧 | 17078／37552131，0.04548% | 累计训练抽样，含重复源；不是独立像素数 |
| 灰度要求铁、学生判珠 | 16772 | 训练前向时的分歧方向，不是已纠正数量 |
| 灰度要求珠、学生判铁 | 306 | 同上 |
| 加权先验／GT梯度范数比 | 20个逐轮首步均值35.04%，范围3.05%–72.69% | 分支确有更新力度；未测梯度夹角或全步均值 |
| 先验BCE，前5／末5轮均值 | 0.29448／0.19523 | 下降33.70%，不代表准确率提高 |
| 先验／学生概率差，前5／末5轮均值 | 0.02771／0.02762 | 没有随BCE同幅下降 |
| GT监督loss，A／B末5轮均值 | 0.05693／0.06177 | B约高8.5%；是目标间取舍信号，不是测试退步证明 |

额外分支并非权重太小、数据没见到或反向传播没生效。更准确的判断是：独立来源的灰度目标
在本轮接受域里依然与学生类别高度一致；独立监督来源并不自动等于大量新的类别知识。
这些结论不依赖训练GT准确率，不能因已见GT拟合充分而否定测试泛化空间。

部署侧也符合“多数变化落在置信度上”的解释：7233／8668个对应实例（83.44%）的铁素体分数
更靠近0.5；A原判铁素体的实例平均变化−0.00647，原判珠光体的平均变化+0.00112。
43个改判中35个原分数距0.5不超过0.05，40个不超过0.10；没有证据将置信度回落称为校准改善。

当前目标是拟合固定软概率，而不是只约束类别方向。例如规则给铁素体概率0.95，学生已有0.999，
软目标BCE仍会推动它向0.95下降。这由[BCE公式](https://docs.pytorch.org/docs/2.8/generated/torch.nn.BCEWithLogitsLoss.html)
可直接推导，代码见`data/semantic_gray.py::gray_prior_loss`。本轮现象与这种作用一致，
但尚未将灰度损失分解为“同类降置信度”“同类升置信度”“异类纠偏”的实际梯度贡献，
不能把所有测试变化唯一归因于这一机制。

### 下一步判断

1. 保留A/B e20作为完整候选，不据此晋级或判定灰度先验无效；无测试GT及新黑盒，不能给出准确率结论。
   如检验竞赛收益，比较本轮A/B的同一完整部署输出，不能只拿B对训练前模型，否则混入共同接续收益。
2. 不建议立即将原配方扩成60轮。无标签池仅见约1.28遍，不能说饱和；但增加轮数也会继续强化当前的
   软概率拟合方向。优先候选是只改变先验损失：可靠亮区的铁素体概率达到要求后停止处罚，
   可靠暗区的铁素体概率低于要求后同样停止处罚；只对不满足证据方向或置信要求的位置施加约束。
   这能避免将0.999机械拉回0.95，但是否有收益须另做短对照，不能由本轮直接证明。
3. 保持先验接受域、GT、初始化、训练预算、D5a、编码器及affinity不变；暂不同时放宽灰度阈值、
   加大权重或解冻上游。若新目标仍缺乏足够冲突样本，再单独讨论困难区域的采样与监督覆盖。
