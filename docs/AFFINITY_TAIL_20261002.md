short的已见GT轮廓收益不能推广为官方收益，详见[short记录](AFFINITY_SHORT_20261002.md)。

但完整匹配数不增加、内部响应上升，100图铁素体数量增加4.445%、汇总均面积下降4.117%。
其名义最难10%被256个位置的上限截为极端子集，内部实际中位仅0.163%。
下一轮只检验扩大困难尾部的代表性是否有利，不同时增加权重、改融合或后处理。

| 项目 | 旧FUSED e20 | TAIL e20 |
| --- | --- | --- |
| 真分界选位 | 最弱 `min(ceil(.1N),256)` 点 | 先取完整最弱 `ceil(.1N)`，再等距选最多256个响应秩 |
| 深内部选位 | 最强 `min(ceil(.1N),256)` 点 | 先取完整最强 `ceil(.1N)`，再等距选最多256个响应秩 |
| 初始化 | 原共同初始化 | 同一原共同初始化，不继承旧FUSED |
| 附加项 | `0.1 × relu(.1 + 内部响应 − 分界响应)` | 不变 |
| 其他训练与部署 | 现有mixed balance链 | 不变 |

响应秩表示按模型的边界强度排序后的位置。设尾池有M点、选K点，使用
`floor(i × (M−1)/(K−1))`，包括两端；未触及上限时与旧选位、loss和梯度逐值相同。
正式上限仍为256；单点预算只供通用函数测试，规则预设取中位秩。
这里的代表性仅指响应排序，不能保证空间、实例大小或类别均衡。
采样不引入随机流，原图序、视野与增强随机状态保持不变。

### 决定与下一步

本轮正常完成，代表性采样减轻了旧FUSED的极端取舍，但未证实优于最高分mixed控制。
**暂缓TAIL与旧FUSED黑盒，不原样扩轮或增加排序权重；mixed balance87.015保留最佳及回退。**
这不是证明所有排序监督无效或后端饱和，而是当前目标改善未可靠传到最终实例划分。
下一步优先在处理后新GT的可信完整对象中逐例定位仍未分开的接触界面与新增误切，
同时记录珠光体匹配损失，区分界面漏开、内部误切、划分种子和区域投票变化。
先用冻结输出干预验证所选正确相邻关系经实际融合／后处理能否改变真实最终错误，
不能把融合图诊断目标直接强制为1。只有多个源上的最终划分收益通过后，才规划对应的单变量监督。
跨相短距关系加权只是候选：当前新增跨相计数受unknown／图框限制，尚不足以直接开训。
从最佳原配方出发，不默认叠加TAIL，不同时改变语义、D5a、融合、阈值或后处理，不推断SAM2候选类别。
目前未开新训练或打比赛包。
