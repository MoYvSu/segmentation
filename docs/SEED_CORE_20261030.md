# 种子内缩与分水岭语义底图：两项独立结构对照

2026-10-30，13例、39份最终输出完成。**两项都实际改变了划分，但没有形成稳定改善证据，保持原部署。**
本轮找到的明确机制是：固定网络输出和分类概率，分水岭的输入表示仍会带来方向性的F面积偏移。
不把该偏移等同于纠错，也不据此认定旧高分来自错误抵消。

## 实验定义

沿用上一轮预封的当前9／历史2／已见GT2，全部复用已有NAF、原N1、语义与raw概率。
恢复器仍为旧`20a59`、step1000、单轮T8，公共配置与权重均不变。
不重跑模型、不训练、不跑150图、不生成提交包。

| 方案 | 唯一改变的逻辑 | 固定项 |
| --- | --- | --- |
| C | 无，引用上一轮已核验C，不重算或复制大数组 | 原NAF、原种子与WS、legacy50→raw投票→外置200邻接合并 |
| K1 | 各种子按原ID向内收缩1像素，释放其周边位置 | 原种子ID集合、实际WS输入图、原概率与最后分类投票 |
| F0 | WS用的语义底图统一为128，取消原P/F的128／200差异 | 原C完整种子、NAF二值防线位置、原概率与最后raw分类投票 |

K1与F0分别从C出发，没有叠加。K1的“1像素”明确为3×3椭圆十字核：
逐标签检查上下左右，不对整数标签图直接取腐蚀最小值。缩后为空、断成多个8连通组件，
或原来已不连通的ID，完整保留该ID原种子，不选最大块、不造点、不删ID、不重新编号。

S0资格继承原C按原N1≤.45筛出的ID，不对缩后种子再次施加S0或50像素门槛。
缩后实际低响应支撑另行审计，不能把原S0支撑记录冒称缩后也全部满足。
底层WS区域50过滤、原raw投票和末端200合并仍照旧；保留种子ID不保证最终实例数不变。

F0使用独立几何语义输入零logit，使WS底图恒为128；原模型语义预测及最终raw投票数组逐值不变。
它同时消除语义灰度阶跃、改变两类区域边界带的灰度对比，不能窄归因为“只删除了错误语义边”。

## 为什么检查语义底图

当前实现并非只在终态投票时使用语义：先把P/F底图写成128／200，再把NAF强边防线写255，
按.7／.3混合。语义跳变为72灰度，而防线让P区约增加38、F区约增加16。
因此“固定分类网络”不等于“分类信号不影响几何”。

这是灰度特征输入，三通道是灰度复制，没有RGB纹理。OpenCV官方实现按邻接通道差排队，
不能将“把概率复制成三通道交给cv2.watershed”当成真正的标量概率高程实验。
代码阅读依据为[OpenCV官方分水岭实现](https://github.com/opencv/opencv/blob/4.x/modules/imgproc/src/segmentation.cpp#L141)。
本轮仍使用实际环境的OpenCV5.0.0和原算法，不新增标量分水岭或额外图结构。

## 方法与结论

| 分析方法 | 观察 | 结论 |
| --- | --- | --- |
| K1保留身份、只释放种子边缘，核对实际WS图不变 | 当前9图释放549329像素，种子占整图95.84%→93.42%；11个ID保护回退 | 种子位置确实参与轮廓定位，但这次没有得到稳定定位收益 |
| F0保留完整C种子，只改变语义底图 | 当前9图F数逐图不变，但F平均面积全部下降0.1106%–0.3428% | 输入表示引入类别相关的几何／投票偏移，去除耦合不自动意味着更准确 |
| 按图统计，而非只看总F数 | K1九图F数合计仍733，实际由一图+1、另一图−1抵消 | 总数不变不能推出实例身份或逐图平均面积稳定 |
| 原标与填补GT核分层 | 原标多分对象均24；填补C66、K166、F068，存在少量拆并交换 | 没有足够证据晋级；不完整已见GT只能定位机制 |
| 检查GT相邻接口附近真实预测分隔 | 不同图、容差与原标／填补分层有升有降 | 没有跨条件稳定的定位改善，不能只挑一个容差判胜 |
| 同坐标原生ID描边目检 | 226／309／169主要是轻微移边，K1局部有新增小钩，既有环未稳定消失 | 两项均未解决主要结构问题；固定ID实验本来也不会主动删掉错误种子 |

当前9图K1内缩后有1个ID不再包含原N1≤.45像素，本轮只记录、不重筛；
历史2图／已见GT2图分别4／1个。不能据本次结果直接替换字面要求“实际core仍有低支撑”的生产合同。

一个当前样例中，C与K1过滤前同为183区／119个F，K1多一个F落到200像素以下，
末端合并后F数由116变115。可见保留种子身份仍会通过下游面积门槛间接合并小实例，
但不能把这种变化称为网络识别了假边，或据此判断该小块应当删除。

## 单独补充的定位诊断

只在两张已见GT中收录不同已知正ID直接接触的接口，不从GT正／0边界推断新晶界。
预测必须是不同正ID直接接触，或恰好一像素零缝两侧为不同ID；同ID零孔、宽空洞与未知区不能作匹配。
比较原尺寸半像素接口面之间的距离，没有修改任何输出或新造GT。

原标双侧共有11701个接口面、283个标签对计数（跨图相加）；涉及填补的接口面119180个。
接口面不是晶界条数，同一像素可贡献不同方向的面。

## 下一步研究边界

种子内缩只释放位置，F0只改变传播输入；二者都保留原有起始身份，不能凭空补出缺失起点，
也不会主动删除错误起点。因此本轮进一步检查**起始区域的连通定义与生成逻辑**，
不继续围绕同一批大种子做小数阈值或边缘厚度扫描，结果见下。
已有小环是否应删除仍需独立证据，不能仅凭尺寸、F数量或预测平均面积设目标。
