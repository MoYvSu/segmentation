## 风险检查结果

| 分析方法 | 观察 | 结论边界 |
| --- | --- | --- |
| 实际终态空间交集对应 | 五例共撤17核心，未发现>=500基线区域的主体raw投票翻类 | 小块仍可能被异类接管，不能仅看大区域 |
| 两训练源GT向内缩4px的可信核，原标/填补分开 | 所检验的90%主体内核对无新增共占；新0共41px，原标32/填补9 | 向内缩会排除细结构，不能以此宣称无误伤；unknown忽略 |
| 薄F中心线及固定16px局部锚点→全图8连通复核 | 五例未发现原F组件被割断或整组件消失 | 仅预测连通，不证明材料拓扑正确；分界和相别仍可变化 |
| train001相别及标签来源 | thin4 F→P30px，29落填补P对象46、1落填补F对象107；全是filled | 填补标签非精确真值，不能把整处变化都叫改对或误伤 |
| train001可信核新0 | 21px均GT F，原标19/填补2；其中4px在原thin4中心线 | 不是全都可概括为旧0线轻微平移，虽未割断所检预测F路径 |
| train557小P的最终归属 | P→F174px中151落GT P对象53（原标38/填补113），另23未知；101在r4核 | 这是明确需保留的相对已有标签的类别损伤风险，不是大主体翻类 |

train557对应旧region198面积289、seed186面积211且仅2个原N1低响应像素。
5%会撤它，但200规则不会把289px区域列为小区；两种策略不能混称同一种去噪。
原图可见小结构归属变化。原N1低支撑只说明预测冲突，不能直接等同该区域应消失。
撤种后区域由谁接管及raw投票同样重要；无新GT核共占不排除部分区域相别损伤。

**本轮结论：比例候选能去掉部分交汇微环，但尚未通过足以直接推广的保护检查。**
保留5%诊断候选，不修改默认、不生成其150图包、不叠加新规则或训练。
先由用户提交旧最高＋200独立包；NoGAN仍保留独立候选，不因本次检查删权重或判整个路线无效。
