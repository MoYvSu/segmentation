# Affinity 双向连通性短周期适配

## 范围与假说

不补标，不留出训练图，不改变语义。沿用 Stage1/joint-v3 → V e115 affinity 与 S-align e13，
固定 D5a e60 首步恢复、共享编码器及全部 LoRA。S-align 历史称 e13，权重内 epoch 字段为12。
对照部署是恢复图产生实例、原图语义仅最终复投票，
对应历史黑盒 0.8445 / 0.8679。恢复图的语义仍参与原分水岭，不能提前替换为原图语义。

普通逐边分类损失可能把大量容易的内部边学好，却仍留下足以连通两个晶粒的少量漏口。
本实验从当前模型的完整原尺寸部署结果定位错误关系，再增加原有 affinity 边的监督：

- 不同 GT 实例被同一预测实例覆盖：降低可信端点间的 affinity。
- 同一 GT 实例被分到不同预测实例：提高可信端点间的 affinity。

这是最终实例引导的困难边 BCE，不是 MALIS、可微分分水岭或拓扑保证。
只采用原人工覆盖且 offset 整段可信的关系；自动补缝仍进入普通 BCE，但不被额外放大。
未标注、padding、预测端点为零的边忽略。SAM2 只保留原普通几何监督。

## 固定项与唯一变量

control 与 candidate 各20轮，每轮64更新；每次一份人工图和一份 SAM2 图，
全部32张人工图各2次、原64源 SAM2 各1次。两组相同初始权重、退化、抽样、D5a噪声、
AdamW、2e-5初始学习率、余弦下降、伪标权重0.5。只训练 affinity decoder，FP32。
共同进行 D5a 输入适配；因此需要新的几何 control，不能把已有语义 control 当作同一对照。

唯一差异是 candidate 额外损失：每4更新一次，最多8个关系、每关系16条困难边；
错误合并与错误拆分分别平均后等权。前2轮线性升至0.1；附加项对输出 logits 的梯度范数
最多为普通人工 BCE 的25%。这不是对参数梯度的保证，实际比例进入日志。
负 affinity 门槛0.3，正门槛0.7；监督完全来自训练 GT，不使用测试 GT。

输入仍为整图等比1024、affinity网格512。先在网格融合边界，反转在线几何增强、去padding、
还原原尺寸，经原完整后处理形成实例，再映回训练网格；不以裁图连通分量冒充部署输出。
本轮不新增尺度变量，也不启用 marker restore、面积过滤、graph/RAG 或新类别规则。
G3 原生裁块与 G7 高分辨率残差已有历史，不把这些当作未尝试的新方法。

### 边界是否变细

检查6张原monitor＋固定种子20260928随机另选4张（074、087、121、162），
对三套模型重新FP32推理，并逐图复现既有完整实例图／类别，共30次全部一致。
在原尺寸、统一0.65阈值下，用响应带面积／单像素骨架长度估计带宽：

- control相对训练前，逐图带宽变化中位−9.01%，范围−12.58%到−4.97%；
- candidate为−8.98%，与control几乎相同；两组骨架处中位直径的相对变化也相同；
- test101带宽估计12.84→11.57／11.59像素；test116为18.85→17.91／17.92像素。

这是预测响应带的宽度，受分支、交汇和阈值影响，不是真实边界宽度，也不能证明补齐了缺口。
图上可见局部轮廓收窄，同时有新细小环状区域；不能单凭边界更细或实例更多认定分割更准。

### 为什么附加项影响小

末5轮candidate普通人工BCE比control仅低0.0104%，SAM2 BCE高0.0256%，曲线基本重合。
附加损失在320／1280步启用，双方向实际选边合计19289／18470；没有出现空监督。
但名义权重0.1被输出logits梯度上限压到0.000555–0.002429，中位0.001301。

进一步在candidate e20上固定回放本轮第20轮8个人工视图，只求梯度、不执行优化：
输出梯度比均为25%，可训练affinity头的实际附加／人工BCE参数梯度比却只有1.93%–3.38%，
中位2.20%。8个方向余弦0.124–0.544，没有整体反向抵消，但附加作用偏弱且只每4步出现一次。
这与两组最终输出近似一致相符；不是对全1280步参数梯度的追溯，也不能确认弱强度是唯一原因。

判断：共同适配使边界响应变窄；本轮保守附加监督没有形成明显额外作用。
尚不能据此否定连通性监督，也不能声称增权必然带来官方收益。不优先原样延长训练。
若继续，先将额外预算改为按实际可训练参数梯度校准（初试人工BCE的10%–20%，保持有上限），
其他输入／抽样／初始化／每4步频率不变，只训练新candidate，复用此次control。
如测黑盒，先用control判断共同affinity适配是否真正有益；暂不为近乎相同的两组消耗两次名额。
这些是下一步建议，本轮没有执行新训练，也没有平台提交。
