# 种子核心门槛与最终实例门槛的独立检查

日期：2026-10-27。用户授权先从简单种子方案开始，先解释当前后处理；
D5a任务适配和选种网络保留为后续思路，本轮不启动相关训练。

## 实际N1后处理

1. 全图／局部连续affinity边界拼回原图，模型、D5a和融合固定。
   N1仅取消局部D5a的推理注入噪声；全图仍为旧固定噪声协议。
2. 边界高阈值0.65得到真实分水岭障碍；另以低阈值0.45、最多8步在强边附近
   重建弱边，只用于生成种子，不改变真实障碍。
3. 种子边界先bridge=1，再reflect扩展32像素，骨架化后裁回原图，膨胀1像素，封边2像素。
4. 对边界带取反，找8连通内部核心。每个保留核心整片成为一个种子，并非中心头预测的点。
   旧门槛为核心面积至少50个原生像素。
5. 真实OpenCV分水岭在固定的语义灰值＋高阈值骨架带上竞争扩张；高程不是连续边界B。
6. 最终区域面积小于50仍过滤，再进行既有编号及类别流程；末端使用固定raw语义概率复投票。
   固定语义概率不代表重新划分后类别不变。

生产入口在真实watershed调用处注入reflect种子；仅修改post_process中的普通种子分支并不能
改变实际reflect部署。因此本轮采用独立离线候选，不修改生产入口或默认配置。

## 唯一变化与解释边界

| 组别 | 核心门槛 | 最终区域门槛 | 其余条件 |
| --- | ---: | ---: | --- |
| 复用N1控制 | 50 | 50 | 原真实边界／高程／语义／reflect及全部后处理 |
| 候选 | 25 | 50 | 与控制相同 |

假说：部分核心被宽响应侵蚀到25–49像素，但扩张后可形成正常实例；旧门槛过早移除了种子。
这不是已确认原因。较小核心也可能来自假闭环；新增种子、保留面积或减少未匹配预测均不能单独
证明官方mIoU提升。区域类别变化也会影响铁素体均面积。

本轮只使用既有8源冻结缓存：典型旧测试、固定随机非monitor半决赛测试与两个已见训练源。
同一原尺寸reflect核心图生成两组种子；50门槛必须逐值复现旧种子、最终PNG及类别。
两组真实watershed高程哈希必须相同，最终uint16、ID上限及类别字典逐图验证。
原标、filled、unknown分开统计；GT仅作已见训练域机制定位，未知不推断标签。
没有模型前向、新训练、本地代理评分、全150图推理或出包；不覆盖旧控制。

工具：utils/marker_core_area.py与tools/probe_marker_core_area.py。
配对输入缓存只读复用，不复制约4.6GB数组；新输出仅保存小样本终态、缩略图和回执。
所有逐图产物留在忽略目录output/seed_core及服务器对应私有运行目录。

## 阶段结果

8源检查已完成，CPU实际读出225.06秒，没有GPU前向。34项核心选择测试通过。
原50/50设置在8源的种子、最终PNG／类别全部逐值复现旧N1；候选真实高程哈希不变。
另独立重读16份终态PNG／类别，验证uint16、ID上限、类别对应和最终区域均至少50像素；
原尺寸已在逐图控制回验中核对，全部输入／封存源码哈希运行后仍一致。

| 分析方法 | 实测结果 | 可支持的结论 |
| --- | --- | --- |
| 同一reflect核心图，仅门槛50→25 | 纳入23个25–49像素核心，21个扩张后保留，2个最终不足50而被删除 | 两级门槛确实不同；保留最终50不能阻止新增小核心先争夺像素 |
| 新核心去向追踪 | 21个最终区域全部52–123像素；净新增19个P、2个F | 本样本未找回较大区域，不能把新增区域当新增TP |
| 最终输出统计 | 总实例1798→1819；F 1053→1055；P 745→764；F像素28014588→28013311 | 主要变化是微区域；少量F变化也可能影响面积项 |
| 逐图F平均预测面积 | 相对变化为0至−0.765%，多数远小于0.1% | 仅描述变化，不是官方面积得分或安全保证 |
| 两张已见新GT可信内核 | 新增1次内核碎分、原正内核18像素变0；无新增跨GT内核合并或原0内核恢复 | 出现风险，未形成可靠的结构收益证据；GT仍可能遗漏 |
| 固定断口及目检 | 既有关切断口图结果完全不变；新增区域多处在宽响应小夹缝及触框附近 | 核心门槛不是该断口的原因，不推广为所有漏检的结论 |

因此保留独立候选，不修改默认N1，不扩大150图、不出包、不追加过滤网络训练。
本轮结果不否定所有种子调整；后续若继续，另行研究弱边重建的单变量，不把失败候选叠加上去。

## 保留的后续思路

### D5a：冻结后端的结构保护

- 继续使用现有D5a架构和零噪声首步，保留RGB L1＋0.2梯度L1；不简单扩轮C5。
- 清晰训练图经过冻结后端产生参考几何响应；同图退化后经恢复器和同一后端，
  增加小权重结构一致性，只更新恢复器。参考预测不是GT，需要检查是否继承教师错误。
- 原则上先五轮，沿用全部1000训练源，不新增holdout，保留e0/e1/e3/e5缩略monitor。
  C5只有在输入、源序、预算与配方严格匹配时才能作为直接控制，不能随意更换视野后继续复用。
- 冻结后端仍需向恢复器传递输入梯度，正式预算前测量吞吐与显存；不承诺等于原重建训练耗时。
- 模糊后叠加轻微成像噪声是另一项退化候选，不与结构一致性同时加入。
  它不同于扩散推理注入噪声，也没有被确认为真实测试退化。
- 新恢复器固定后再考虑几何专属LoRA适配；不重启已否定的共享LoRA与双头60轮配方，
  不移除现有Stage1／joint-v3谱系。

### 选种网络：候选生成与选择分开

- 先看简单核心门槛和弱边重建是否提供有价值的候选，再决定是否训练。
- 输入候选附近RGB、连续B、核心掩码及上下文，判断保留／撤销；从随机初始化小网络开始。
- 如果只筛原有种子，不能解决缺少种子的漏分；必须先有候选生成机制。
- 不以小面积或浅盆地直接充当错误标签。新GT存在遗漏，监督限于可信片区，未知保持忽略。
- 固定模型、语义和真实分水岭，不强制实例数或平均面积；测试图不生成或修改GT。

这两项本轮仅保存设计，不实现、不训练、不自动排队。
