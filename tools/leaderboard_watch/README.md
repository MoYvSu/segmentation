# AIC 排行终端

> 2026-10-26 使用状态：按用户本轮指示，自动采集和本地服务已停止，代码与历史记录保留。
> 尚未确认平台允许自动轮询；“无需登录即可读取”只说明当时技术上可访问，不代表获得采集授权。
> 当前保持停用，不因网页刷新或后续界面验证自行恢复采集。

在本机观察指定 AIC 公开排行榜，默认每 5 分钟读取一次。半决赛、复赛、初赛分别记录，
队伍列表默认展示全部参赛队伍。

## 使用

双击本目录的 `start.cmd`，会打开 <http://127.0.0.1:8876/>。再次启动会复用现有采集器。
双击 `stop.cmd` 停止采集。也可在仓库根目录运行：

```powershell
python tools/leaderboard_watch/app.py serve
python tools/leaderboard_watch/app.py stop
```

只需要现有 Python，使用标准库，没有新增训练环境依赖。关闭网页后，后台采集仍继续；
电脑关机、休眠或采集器停止时不会记录数据，也不会补造缺失时段。未安装开机自启任务。
重新运行后续写已有数据库。

## 看板内容

- 全部队伍的官方名次、公开分数、提交与打分时间；可搜索、排序、收藏关注队伍。
- 外汇交易终端风格的布局：左侧行情、中央交互走势、右侧队伍详情，下方切换排行、动态与区间分析。
- 最多 5 队的分数、名次或距当时榜首分差的走势；支持 1H、6H、1D、1W、ALL 时间快捷范围。
- 原始数值、区间变化、分数百分比三种比较方式；纵轴按可视数据自动定标，也可手动缩放。
- 每支队伍距榜首、距前一名、所选时间内的最高观测分数。
- 分数与名次变化、新出现队伍、暂时消失的队伍、公开时间变化的动态记录。
- 基于当前数据的分差、榜首与竞争接近程度分析；不推测未来成绩或晋级概率。
- 当前阶段的观测记录 JSON 导出。
- 可选择开启桌面通知：需要浏览器许可，网页打开时提醒当前阶段的新变化。
  页面关闭后仍采集，但不发送桌面通知，也不向聊天、邮箱等发送消息。

表格中的变化相对**上一版不同的公开榜单**。首次记录只是基线，不能当成一次涨分。
网页每 15 秒读取本地数据，不会以这个频率访问官网；官网采集由独立后台线程执行。
“立即检查”有 60 秒冷却时间，正在采集时不能再启动一次并行采集。

## 走势操作

- 在主图上滚动鼠标滚轮，围绕鼠标所在时间放大或缩小；按住拖动可回看历史。
- 底部是完整的已加载历史概览。拖动选区可平移，拖动两侧边缘可扩大或缩小时间范围。
- 拖动右侧纵轴，或在右轴滚动滚轮，手动调整垂直尺度；`Shift + 滚轮` 也可调整纵轴。
- `自动 Y` 让纵轴跟随当前可视区间的数据。已去掉原先固定至少 0.2 分的留白，刻度精度随波动调整。
- `区间变化 Δ` 把各队的区间起点对齐到 0，避免不同队伍之间的绝对分差淹没细小变化。
  分数模式显示增加了多少分；名次模式显示提高了多少名；距榜首模式显示差距缩小了多少分。
- `区间涨幅 %` 仅用于分数。起点为 0 时显示无法计算，不用无穷大或 0 代替。
- 比较基准是可视区间起点处可以延续的阶梯值；该处无有效值时，采用区间内首个有效观测。
  区间起止统计可能沿用相邻有效检查间的阶梯值，但“有效观测次数”只统计实际落入区间的检查。
- `单队聚焦` 暂时只显示当前队伍，适合观察很小的分数变化；点击其他队名可重新加入比较。
- 拖动回看历史后，新检查不会夺走当前位置；点击 `最新` 可恢复跟随，`重置视图` 恢复全部范围和自动纵轴。
- `⛶` 展开图表，`Esc` 返回。主图获得键盘焦点后，`+` / `-` 缩放、左右方向键平移、`0` 重置、`A` 自动纵轴、`R` 跟随最新。

图表继续使用实际观测的阶梯线。顶部“始、高、低、末”统计当前队伍在可视区间的观测数值，
不把离散榜单记录当作逐笔成交或额外补写价格。

## 数据范围与准确性

来源是用户指定的[官方排行榜](https://reg.aicomp.cn/special/phb/detail?id=4839619591879659587&rwId=4839619548191789112&stbh=4839619562087518304)，
读取页面前端同样使用、当时无需登录即可访问的 `/third/jsphb` 数据接口，不读取账号、模型或比赛图片。
此处未取得自动化访问的明确许可，也未确认平台的访问频率限制或风控配置。
只保存榜单中显示的必要字段，不保存阶段接口中的后台操作者资料。

历史从首次成功采集开始。公开的提交或打分时间不等于我们观察到榜单变化的时间；
不根据它们回填过去的分数曲线。接口的 `createTime` 会随读取重新生成，不能当作发布时刻，
也不参与榜单变化判断。接口配置包含整点更新时间，但没有据此宣称官方逐秒实时更新。
5 分钟只是本程序的检查间隔，实际变化可见时间还受官方发布速度影响。

官网前端传入 `pageNo=0,pageSize=20`。现场核验发现复赛返回了完整的 39 队、初赛完整的 40 队，
`20` 不是只能读取 20 队的限制。每次仍严格核对返回行数与 `total`；若接口改为分页或返回残缺内容，
本程序报错并保留上一份有效榜单，不会把第一页冒充全部数据。

未知分数保持空值，不能变成 0；并列顺序和名次采用官方字段，不自行重排名。
失败检查单独记录，不覆盖上一份有效榜单，不计作成绩变化。连续失败延长重试间隔，最长 30 分钟。
图上的阶梯线连接正常间隔内的有效观测；失败、休眠或明显超时的间隔留空。
历史图最多显示最近 5000 次检查，超出时页面标明截断；数据库保留记录。

## 本地文件与停止方式

默认数据目录为被 Git 忽略的 `output/leaderboard_watch/`：

- `history.sqlite3`：持久化观测记录；运行时可能有 SQLite 的 `-wal` / `-shm` 伴随文件。
- `watch.log`：采集日志。
- `stdout.log`、`stderr.log`：通过启动脚本运行时的进程输出。

所有采集数据留在本地，不提交或推送 Git。只监听 `127.0.0.1`，局域网其他设备不能直接访问。
浏览器不需要第三方 CDN、字体、脚本或 API 密钥。看板脚本仅与本机采集器通信。

需要更换端口或频率时，先停止现有进程，再用命令行启动：

```powershell
python tools/leaderboard_watch/app.py serve --port 8877 --interval 300
python tools/leaderboard_watch/app.py stop --port 8877
```

启动脚本固定使用默认端口 8876；自动检查间隔最短为 60 秒，推荐保持 300 秒。
工具没有创建 Windows 定时任务或云端定时任务。
